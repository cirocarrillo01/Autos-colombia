# Parches SQL — Auto Colombia

Este documento registra los cambios aplicados a `backend/Script/parqueadero.sql` y las migraciones incrementales no incluidas en el esquema base.

---

## 1. Parches aplicados a `backend/Script/parqueadero.sql`

### 1.1. Eliminación de depuración final (antes líneas 318-321)

Se eliminaron las líneas de depuración que se ejecutaban al importar el script:

```sql
USE autos_colombia;

SELECT *
FROM vehiculos;
```

**Impacto:** Ninguno en el esquema ni en los datos. Solo se evita salida innecesaria en la consola del cliente MySQL al crear la base.

---

### 1.2. Actualización de comentarios obsoletos ("celda fija")

El modelo de negocio es de **celdas rotativas** (cada ingreso elige una celda libre del mismo tipo), no celdas fijas asignadas por vehículo. Se corrigieron los comentarios:

| Línea antes | Contenido anterior | Contenido nuevo |
|-------------|-------------------|-----------------|
| 8 | `Cada vehículo mensual tiene una celda fija asignada.` | `Cada ingreso elige una celda libre rotativa del mismo tipo del vehículo.` |
| 21 | `vehiculos: placa + propietario + celda_fija + tipo` | `vehiculos: placa + propietario + tipo` |
| 214 | `id_celda ... -- toma de vehiculos.id_celda_fija al ingresar` | `id_celda ... -- celda asignada en el ingreso (rotativa)` |

**Nota:** La tabla `vehiculos` nunca tuvo columna `celda_fija`; el comentario anterior era factualmente incorrecto.

---

### 1.3. Índices adicionales

Se agregaron dos índices con `IF NOT EXISTS` (idempotentes):

```sql
CREATE INDEX IF NOT EXISTS ix_acceso_fecha_ingreso ON accesos_vehiculos (fecha_ingreso);
CREATE INDEX IF NOT EXISTS ix_la_fecha ON login_attempts (fecha_intento);
```

- `ix_acceso_fecha_ingreso`: mejora consultas de historial filtradas solo por rango de fechas.
- `ix_la_fecha`: mejora purgas masivas de `login_attempts` por antigüedad.

---

### 1.4. Evento programado de purga (comentado por seguridad)

Se agregó como SQL **comentado** un evento programado para purgar `login_attempts` y `audit_log` antiguos (más de 90 días):

```sql
-- CREATE EVENT IF NOT EXISTS ev_purga_login_attempts
-- ON SCHEDULE EVERY 24 HOUR
-- DO
--   DELETE FROM login_attempts WHERE fecha_intento < DATE_SUB(UTC_TIMESTAMP(), INTERVAL 90 DAY);
```

**No está activado por defecto** porque:
- Borra datos irreversiblemente.
- Requiere `event_scheduler = ON` en el servidor MySQL.
- La política de retención debe definirse con el negocio y validarse en staging antes de activarse.

---

### 1.5. `refresh_tokens.token` guarda SHA-256

La columna `refresh_tokens.token` ya es `VARCHAR(128)`, suficiente para almacenar un hash SHA-256 hex (64 caracteres). El código backend (`refreshTokenRepository.js`) ya guarda `hashToken(token)` en lugar del token en claro.

**Impacto operativo:** Los refresh tokens existentes en la base de datos (guardados en claro antes de este cambio) dejarán de validar. Los usuarios deberán volver a iniciar sesión una vez tras el despliegue.

---

## 2. Migraciones incrementales (`backend/migrations/`)

| Archivo | Descripción |
|---------|-------------|
| `001_initial_schema.sql` | Esquema inicial (tablas base). |
| `002_add_sesion_activa.sql` | Agrega `sesion_activa` y `fecha_sesion_activa` a `usuarios`, más índice `ix_usuario_sesion_activa`. |
| `003_add_mantenimiento_hasta.sql` | Agrega `mantenimiento_hasta` a `celdas`. |
| `004_create_audit_log.sql` | Crea tabla `audit_log`. |
| `005_create_revoked_tokens.sql` | Crea tabla `revoked_tokens` (JTI revocados). |
| `006_create_refresh_tokens.sql` | Crea tabla `refresh_tokens`. |
| `007_audit_log_accion.sql` | Modifica `audit_log.accion` de `VARCHAR(60)` a `VARCHAR(50) NOT NULL` para codificar rechazos (`entrada_rechazada`, `salida_rechazada`, etc.). |

---

## 3. Archivo suelto: `backend/Script/migracion_sesion_activa.sql`

Existe un archivo duplicado de la migración 002 en `backend/Script/migracion_sesion_activa.sql`. Contiene el mismo `ALTER TABLE` que `backend/migrations/002_add_sesion_activa.sql` más un `SELECT` de confirmación. No está versionado como migración incremental; se mantiene como referencia para bases creadas con `parqueadero.sql` antes de que las columnas existieran.

**Recomendación:** Usar `backend/migrations/002_add_sesion_activa.sql` como fuente de verdad. El archivo en `backend/Script/` puede eliminarse una vez confirmado que no se referencia en ningún proceso de despliegue.

---

## 4. Cómo aplicar las migraciones

Desde `backend/`:

```bash
# Verificar migraciones pendientes (según el entorno)
mysql -u root -p autos_colombia < backend/migrations/007_audit_log_accion.sql
```

Siempre tomar un backup (`mysqldump`) antes de aplicar cualquier migración en producción.

import { createPool } from "mysql2/promise";
import { env } from "./envLoader.js";

export const pool = createPool({
  host: env.DB_HOST,
  port: env.DB_PORT,
  user: env.DB_USER,
  password: env.DB_PASSWORD,
  database: env.DB_NAME,
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0,
  charset: "utf8mb4",
  timezone: "Z",
});

/** Consulta parametrizada; devuelve solo las filas. */
export async function query(sql, params = []) {
  try {
    const [filas] = await pool.query(sql, params);
    return filas;
  } catch (err) {
    console.error("Error en consulta SQL:", err.message, "\nSQL:", sql);
    throw err;
  }
}

/**
 * Ejecuta `trabajo(conn)` dentro de UNA transacción real (misma conexión).
 * Commit si termina bien, rollback si lanza.
 */
export async function conTransaccion(trabajo) {
  const conn = await pool.getConnection();
  try {
    await conn.beginTransaction();
    const r = await trabajo(conn);
    await conn.commit();
    return r;
  } catch (err) {
    try {
      await conn.rollback();
    } catch {
      /* conexión ya cerrada */
    }
    throw err;
  } finally {
    conn.release();
  }
}

// Funciones puras para leer y validar variables de entorno (testeables sin tocar disco).

/** Parsea el contenido de un .env. Soporta comillas y comentarios `# ...` en línea. */
export function parseEnv(contenido) {
  const out = {};
  for (const linea of String(contenido).split(/\r?\n/)) {
    const texto = linea.trim();
    if (!texto || texto.startsWith("#")) continue;
    const igual = texto.indexOf("=");
    if (igual === -1) continue;
    const clave = texto.slice(0, igual).trim();
    let valor = texto.slice(igual + 1).trim();
    if (valor.length >= 2) {
      const primera = valor[0];
      const ultima = valor[valor.length - 1];
      if ((primera === '"' || primera === "'") && primera === ultima) {
        valor = valor.slice(1, -1);
      } else {
        valor = recortarComentarioEnLinea(valor);
      }
    } else {
      valor = recortarComentarioEnLinea(valor);
    }
    out[clave] = valor;
  }
  return out;
}

/** Elimina un comentario en línea "# ..." precedido de espacio en blanco. */
function recortarComentarioEnLinea(valor) {
  const inicio = valor.indexOf("#");
  if (inicio > 0 && /\s/.test(valor[inicio - 1])) {
    return valor.slice(0, inicio).trimEnd();
  }
  return valor;
}

/** Convierte a entero o devuelve el valor por defecto. */
export const entero = (valor, porDefecto) => {
  const n = Number.parseInt(valor ?? "", 10);
  return Number.isFinite(n) ? n : porDefecto;
};

/** Construye la configuración tipada. Lanza Error si falta algo obligatorio. */
export function construirEnv(src = process.env) {
  const obligatorias = ["DB_USER", "DB_NAME", "JWT_SECRET"];
  const faltantes = obligatorias.filter((k) => !src[k]);
  if (faltantes.length) {
    throw new Error(
      `Faltan variables de entorno obligatorias: ${faltantes.join(", ")} (modelo en backend/.env.example)`,
    );
  }
  const NODE_ENV = src.NODE_ENV || "development";
  if (NODE_ENV === "production" && src.JWT_SECRET.length < 32) {
    throw new Error(
      "JWT_SECRET debe tener al menos 32 caracteres en producción",
    );
  }
  const origenes = (
    src.CORS_ORIGIN || "http://localhost:5173,http://localhost:5174"
  )
    .split(",")
    .map((s) => s.trim())
    .filter(Boolean);
  return {
    NODE_ENV,
    PORT: entero(src.PORT, 3000),
    DB_HOST: src.DB_HOST || "localhost",
    DB_PORT: entero(src.DB_PORT, 3306),
    DB_USER: src.DB_USER,
    DB_PASSWORD: src.DB_PASSWORD ?? "",
    DB_NAME: src.DB_NAME,
    CORS_ORIGINS: origenes,
    TRUST_PROXY: src.TRUST_PROXY ?? "0",
    JWT_SECRET: src.JWT_SECRET,
    JWT_EXPIRES_IN: src.JWT_EXPIRES_IN || "8h",
  };
}

import * as authService from "../services/authService.js";
import { validarDatosUsuario } from "../middleware/validation.js";
import { responder } from "../utils/responseHelper.js";
import { MSG } from "../utils/messages.js";

export const register = async (req, res) => {
  try {
    // Antes: `req.body` sin `?? {}` -> TypeError (500) si el cliente no enviaba JSON.
    const { claveAdmin, ...datos } = req.body ?? {};
    if (!claveAdmin) return responder(res, 422, MSG.CAMPOS_OBLIGATORIOS);

    if (!req.user) return responder(res, 401, MSG.TOKEN_REQUERIDO);

    const auth = await authService.verificarClaveUsuario({
      usuario_login: req.user.usuario_login,
      clave: claveAdmin,
    });
    // 403 y no 401: el front interpreta 401 como "sesión vencida" y cerraba la sesión del admin
    // cada vez que se equivocaba al escribir su clave.
    if (auth.status !== 200)
      return responder(res, 403, "Clave de administrador incorrecta");

    const invalido = validarDatosUsuario(datos);
    if (invalido) return responder(res, 422, invalido);

    const r = await authService.registrar(datos, req.user);
    responder(
      res,
      r.status,
      r.mensaje || r.error,
      r.body || (r.usuario ? { usuario: r.usuario } : {}),
    );
  } catch (err) {
    console.error(err);
    responder(res, 500, MSG.ERROR_INTERNO);
  }
};

// Autenticación JWT (HS256) + estado del usuario.
import jwt from "jsonwebtoken";
import crypto from "node:crypto";
import { env } from "../config/envLoader.js";
import { query } from "../config/db.js";
import * as revokedTokenRepository from "../repositories/revokedTokenRepository.js";
import { responder } from "../utils/responseHelper.js";
import { MSG } from "../utils/messages.js";

const ALGORITMO = "HS256";

export const generarToken = (idUsuario) =>
  jwt.sign(
    { id_usuario: idUsuario, jti: crypto.randomUUID() },
    env.JWT_SECRET,
    {
      expiresIn: env.JWT_EXPIRES_IN,
      algorithm: ALGORITMO,
    },
  );

export const verificarToken = (token) =>
  jwt.verify(token, env.JWT_SECRET, { algorithms: [ALGORITMO] });

/** "Bearer xxx" -> "xxx" | null */
export function extraerBearer(header = "") {
  const partes = String(header).split(" ");
  if (partes.length !== 2 || partes[0].toLowerCase() !== "bearer" || !partes[1])
    return null;
  return partes[1];
}

export const autenticar = async (req, res, next) => {
  try {
    const token = extraerBearer(req.headers.authorization);
    if (!token) return responder(res, 401, MSG.TOKEN_REQUERIDO);

    const decoded = verificarToken(token);
    if (
      decoded.jti &&
      (await revokedTokenRepository.estaRevocado(decoded.jti))
    ) {
      return responder(res, 401, "Token revocado o sesión cerrada");
    }

    // Incluye email y telefono: /auth/me los devolvía siempre como undefined.
    const [u] = await query(
      `SELECT id_usuario, usuario_login, rol, nombres, apellidos, email, telefono, estado
       FROM usuarios WHERE id_usuario = ?`,
      [decoded.id_usuario],
    );
    if (!u) return responder(res, 401, "Usuario no encontrado");
    if (u.estado !== "activo") {
      return responder(res, 403, "Usuario inactivo. No puede iniciar sesión.");
    }

    req.user = { ...u, nombreCompleto: `${u.nombres} ${u.apellidos}` };
    next();
  } catch (err) {
    if (err.name === "TokenExpiredError") {
      return responder(res, 401, MSG.SESION_EXPIRADA);
    }
    if (err.name === "JsonWebTokenError" || err.name === "NotBeforeError") {
      return responder(res, 401, "Token inválido");
    }
    next(err);
  }
};

export default { autenticar, generarToken, verificarToken, extraerBearer };

// Validación de cuerpo para rutas de usuarios (única fuente; authService ya no la repite).
export const REQUIRED_USER_FIELDS = [
  "rol",
  "tipo_documento",
  "documento",
  "nombres",
  "apellidos",
  "usuario_login",
  "clave",
];
export const VALID_ROLES = ["administrador", "operador"];
export const VALID_TIPOS_DOCUMENTO = ["cc", "ce", "nit", "pasaporte"];
const EMAIL = /^[^\s@]+@[^\s@.]+\.[^\s@]+$/;

export const validarClave = (clave) =>
  !clave || String(clave).length < 4
    ? "La clave debe tener al menos 4 caracteres"
    : null;

export const validarDatosUsuario = (body, { requiereClave = true } = {}) => {
  if (!body || typeof body !== "object") return "Cuerpo de solicitud inválido";
  const obligatorios = requiereClave
    ? REQUIRED_USER_FIELDS
    : REQUIRED_USER_FIELDS.filter((c) => c !== "clave");
  for (const campo of obligatorios) {
    const v = body[campo];
    if (v === undefined || v === null || String(v).trim() === "")
      return `El campo "${campo}" es obligatorio`;
  }
  if (!VALID_ROLES.includes(body.rol))
    return "Rol no reconocido. Los valores permitidos son: 'administrador' u 'operador'.";
  if (!VALID_TIPOS_DOCUMENTO.includes(body.tipo_documento)) {
    return "Tipo de documento no reconocido. Use: 'cc', 'ce', 'nit' o 'pasaporte'.";
  }
  const doc = String(body.documento).length;
  if (doc < 5 || doc > 20)
    return "La longitud del documento debe estar entre 5 y 20 caracteres.";
  if (String(body.usuario_login).length < 3)
    return "El usuario de acceso debe tener al menos 3 caracteres.";
  if (requiereClave) {
    const e = validarClave(body.clave);
    if (e) return e;
  }
  if (body.email && !EMAIL.test(String(body.email)))
    return "El correo electrónico no tiene un formato válido";
  return null;
};

export async function listarConFiltros({
  q,
  estadoFiltro,
  tipoFiltro,
  hoy,
  limit,
  offset,
}) {
  const cols = await vehiculoRepo.getColumnasVehiculos();
  const extras = vehiculoRepo.buildAliases(cols);
  const extrasSql = extras.length ? `, ${extras.join(", ")}` : "";

  const { sql: searchSql, params: searchParams } = vehiculoRepo.buildSearchSql(
    q,
    cols,
  );
  const orderBy = vehiculoRepo.getOrderBy(cols);

  let estadoCond = "";
  let estadoParams = [];
  if (estadoFiltro === "Al día") {
    estadoCond = "AND ma.id_mensualidad IS NOT NULL";
  } else if (estadoFiltro === "En mora") {
    estadoCond = "AND ml.fecha_fin < ? AND ml.estado = 'activa'";
    estadoParams = [hoy];
  } else if (estadoFiltro === "Pendiente") {
    estadoCond = "AND ml.fecha_inicio > ?";
    estadoParams = [hoy];
  } else if (estadoFiltro === "Sin mensualidad") {
    estadoCond = "AND ml.id_mensualidad IS NULL";
  }

  const baseParams = [
    hoy,
    hoy,
    ...searchParams,
    ...(tipoFiltro ? [tipoFiltro] : []),
    ...estadoParams,
  ];

  const sql = `
    SELECT v.*${extrasSql},
      tv.codigo AS tipo_codigo, tv.nombre AS tipo, tv.tarifa_mensual,
      ma.id_mensualidad AS id_activa, ma.fecha_inicio AS inicio_activa,
      ma.fecha_fin AS fin_activa, ma.valor AS valor_activa,
      ml.id_mensualidad AS id_ultima, ml.fecha_inicio AS inicio_ultima,
      ml.fecha_fin AS fin_ultima, ml.valor AS valor_ultima
    FROM vehiculos v
    INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
    LEFT JOIN mensualidades ma ON ma.id_mensualidad = (
      SELECT id_mensualidad FROM mensualidades
      WHERE id_vehiculo = v.id_vehiculo AND fecha_inicio <= ? AND fecha_fin >= ?
      ORDER BY fecha_fin DESC LIMIT 1
    )
    LEFT JOIN mensualidades ml ON ml.id_mensualidad = (
      SELECT id_mensualidad FROM mensualidades
      WHERE id_vehiculo = v.id_vehiculo
      ORDER BY fecha_fin DESC, id_mensualidad DESC LIMIT 1
    )
    WHERE v.activo = TRUE
      AND ${searchSql}
      ${tipoFiltro ? "AND tv.codigo = ?" : ""}
      ${estadoCond}
    ORDER BY ${orderBy}
    LIMIT ? OFFSET ?
  `;

  const countSql = `
    SELECT COUNT(*) AS total FROM vehiculos v
    INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
    LEFT JOIN mensualidades ma ON ma.id_mensualidad = (
      SELECT id_mensualidad FROM mensualidades
      WHERE id_vehiculo = v.id_vehiculo AND fecha_inicio <= ? AND fecha_fin >= ?
      ORDER BY fecha_fin DESC LIMIT 1
    )
    LEFT JOIN mensualidades ml ON ml.id_mensualidad = (
      SELECT id_mensualidad FROM mensualidades
      WHERE id_vehiculo = v.id_vehiculo
      ORDER BY fecha_fin DESC, id_mensualidad DESC LIMIT 1
    )
    WHERE v.activo = TRUE
      AND ${searchSql}
      ${tipoFiltro ? "AND tv.codigo = ?" : ""}
      ${estadoCond}
  `;

  const [filas, [{ total }]] = await Promise.all([
    query(sql, [...baseParams, limit, offset]),
    query(countSql, baseParams),
  ]);

  return { filas, total: Number(total) };
}

/**
 * @fileoverview Acceso a datos de movimientos (accesos_vehiculos).
 * SQL parametrizado; sin reglas de negocio.
 * La resolución de puerta es tolerante: si la columna es NULL-able se inserta NULL,
 * y si es NOT NULL sin default se lanza un error claro cuando no hay puerta activa.
 */

import { query } from "../config/db.js";

// -------------------- Historial --------------------

export async function historial(filtros) {
  const { where, params } = construirWhereHistorial(filtros);
  const orderBy = "a.fecha_ingreso DESC, a.id_acceso DESC";
  const offset = (filtros.page - 1) * filtros.limit;

  const rows = await query(
    `SELECT a.id_acceso, v.placa, v.propietario_nombre, v.propietario_documento,
            tv.nombre AS tipo, tv.codigo AS tipo_codigo,
            c.codigo AS celda, a.fecha_ingreso, a.fecha_salida,
            ui.nombres AS operador_ingreso, us.nombres AS operador_salida
     FROM accesos_vehiculos a
     INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
     INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
     LEFT JOIN celdas c ON c.id_celda = a.id_celda
     LEFT JOIN usuarios ui ON ui.id_usuario = a.id_operador_ingreso
     LEFT JOIN usuarios us ON us.id_usuario = a.id_operador_salida
     ${where}
     ORDER BY ${orderBy}
     LIMIT ? OFFSET ?`,
    [...params, filtros.limit, offset],
  );

  const [{ total }] = await query(
    `SELECT COUNT(*) AS total FROM accesos_vehiculos a
     INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
     INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
     ${where}`,
    params,
  );

  return { rows, total: Number(total) };
}

function construirWhereHistorial(f) {
  const conds = [];
  const params = [];
  if (f.placa) {
    conds.push("v.placa LIKE ?");
    params.push(`%${String(f.placa).toUpperCase()}%`);
  }
  if (f.celda) {
    conds.push("c.codigo LIKE ?");
    params.push(`%${String(f.celda).toUpperCase()}%`);
  }
  if (f.operador) {
    conds.push(
      "(ui.nombres LIKE ? OR ui.apellidos LIKE ? OR us.nombres LIKE ? OR us.apellidos LIKE ?)",
    );
    const like = `%${f.operador}%`;
    params.push(like, like, like, like);
  }
  if (f.estado === "adentro") conds.push("a.fecha_salida IS NULL");
  if (f.estado === "fuera") conds.push("a.fecha_salida IS NOT NULL");
  if (f.fecha_desde) {
    conds.push("DATE(CONVERT_TZ(a.fecha_ingreso, '+00:00', '-05:00')) >= ?");
    params.push(f.fecha_desde);
  }
  if (f.fecha_hasta) {
    conds.push("DATE(CONVERT_TZ(a.fecha_ingreso, '+00:00', '-05:00')) <= ?");
    params.push(f.fecha_hasta);
  }
  return {
    where: conds.length ? `WHERE ${conds.join(" AND ")}` : "",
    params,
  };
}

     FROM accesos_vehiculos a
     INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo

     LEFT JOIN celdas c ON c.id_celda = a.id_celda

export function buildAliases(cols) {
  const extras = [];
  const add = (target, actual) => {
    if (actual && actual !== target) extras.push(`v.${actual} AS ${target}`);
  };
  add("documento", cols.documento);
  add("tipo_documento", cols.tipo_documento);
  add("nombres", cols.nombres);
  add("apellidos", cols.apellidos);
  add("nombre_completo", cols.nombre_completo);
  add("telefono", cols.telefono);
  add("email", cols.email);
  add("color", cols.color);
  add("modelo", cols.modelo);
  add("anio", cols.anio);
  add("nombre_modelo", cols.nombre_modelo);
  return extras;
}

export function buildSearchSql(q, cols) {
  if (!q || q.trim() === "") return { sql: "TRUE", params: [] };
  const qLike = `%${q.trim()}%`;
  const parts = ["v.placa LIKE ?"];
  const params = [qLike];
  const tryAdd = (col) => {
    if (col) {
      parts.push(`v.${col} LIKE ?`);
      params.push(qLike);
    }
  };
  tryAdd(cols.documento);
  tryAdd(cols.nombres);
  tryAdd(cols.apellidos);
  tryAdd(cols.nombre_completo);
  return { sql: `(${parts.join(" OR ")})`, params };
}

  if (activo !== null) {
    activoCond = "AND v.activo = ?";
    activoParams = [activo];
  }

  const baseParams = [...searchParams, ...tipoParams, ...activoParams];

     FROM vehiculos v
     INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
     WHERE ${searchSql}
       ${tipoCond}
       ${activoCond}
     ORDER BY ${orderBy}
     LIMIT ? OFFSET ?`,

     INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo

    Object.entries(cols).map(([key, val]) => [val, key])

  const sets = [];
  const params = [];

    if (v === undefined) continue;

  if (!sets.length) return;
  params.push(idVehiculo);

// Autenticación: login, registro, restablecer clave, logout y refresh.
import bcrypt from "bcryptjs";
import { generarToken, verificarToken } from "../middleware/authMiddleware.js";
import * as userRepository from "../repositories/userRepository.js";
import * as refreshTokenRepository from "../repositories/refreshTokenRepository.js";
import * as revokedTokenRepository from "../repositories/revokedTokenRepository.js";
import * as auditRepository from "../repositories/auditRepository.js";
import { MSG } from "../utils/messages.js";

export const MAX_INTENTOS_FALLIDOS = 5;
export const VENTANA_INTENTOS_MINUTOS = 15;
// Hash falso para gastar el mismo tiempo cuando el usuario no existe (evita enumerar usuarios por latencia).
const HASH_FALSO = bcrypt.hashSync("clave-falsa-para-igualar-tiempos", 10);

/**
 * IP del cliente. Se usa req.ip (respeta TRUST_PROXY). Antes se confiaba ciegamente en el
 * header X-Forwarded-For, así que cualquiera esquivaba el bloqueo por IP cambiándolo.
 */
export const obtenerIp = (req) =>
  req.ip || req.socket?.remoteAddress || "desconocida";

const errorAuth = () => ({ status: 401, error: "Usuario o clave incorrectos" });
const perfil = (u) => ({
  id_usuario: u.id_usuario,
  usuario_login: u.usuario_login,
  rol: u.rol,
  nombres: u.nombres,
  apellidos: u.apellidos,
  nombreCompleto: `${u.nombres} ${u.apellidos}`,
  estado: u.estado,
});

export const login = async (req, { usuario_login, clave } = {}) => {
  const login = String(usuario_login ?? "")
    .trim()
    .slice(0, 40);
  if (!login || !clave)
    return { status: 422, error: "Usuario y clave son obligatorios" };

  const ip = obtenerIp(req);
  const intento = (exitoso) =>
    userRepository.registrarIntento({
      usuario_login: login,
      exitoso,
      ip_address: ip,
    });

  const [porUsuario, porIp] = await Promise.all([
    userRepository.contarFallidosRecientes({
      usuario_login: login,
      minutos: VENTANA_INTENTOS_MINUTOS,
    }),
    userRepository.contarFallidosRecientes({
      ip_address: ip,
      minutos: VENTANA_INTENTOS_MINUTOS,
    }),
  ]);
  if (porUsuario >= MAX_INTENTOS_FALLIDOS || porIp >= MAX_INTENTOS_FALLIDOS) {
    // No se registra otro intento: antes cada intento bloqueado ampliaba el bloqueo indefinidamente.
    return {
      status: 423,
      error:
        "Acceso bloqueado temporalmente por múltiples intentos fallidos. Intente más tarde.",
    };
  }

  const usuario = await userRepository.findByLogin(login);
  const coincide = await bcrypt.compare(
    String(clave),
    usuario?.clave_hash ?? HASH_FALSO,
  );
  if (!usuario || !coincide) {
    await intento(false);
    return errorAuth();
  }
  if (usuario.estado !== "activo") {
    await intento(false);
    return { status: 403, error: "Usuario inactivo. No puede iniciar sesión." };
  }

  await intento(true);
  await userRepository.registrarUltimoAcceso(usuario.id_usuario);

  // Seguridad: Revocar sesiones previas al iniciar sesión para garantizar sesión única
  await refreshTokenRepository.revocarRefreshTokensUsuario(usuario.id_usuario);
  await userRepository.cerrarSesionActiva(usuario.id_usuario);

  await userRepository.registrarSesionActiva(usuario.id_usuario);
  const token = generarToken(usuario.id_usuario);
  const refresh_token = await refreshTokenRepository.crearRefreshToken(
    usuario.id_usuario,
  );
  await auditRepository.registrarAudit({
    id_usuario: usuario.id_usuario,
    usuario_login: usuario.usuario_login,
    accion: "LOGIN",
    recurso: "auth",
    detalle: "Inicio de sesión exitoso",
    ip_address: ip,
  });
  return {
    status: 200,
    body: { token, refresh_token, usuario: perfil(usuario) },
  };
};

/** Campo que provocó el duplicado (antes podía quedar vacío: "ese ."). */
export function campoDuplicado(dup, datos) {
  if (
    dup.tipo_documento === datos.tipo_documento &&
    String(dup.documento) === String(datos.documento)
  )
    return "documento";
  if (
    String(dup.usuario_login).toLowerCase() ===
    String(datos.usuario_login).toLowerCase()
  )
    return "usuario de acceso";
  if (
    datos.email &&
    dup.email &&
    dup.email.toLowerCase() === String(datos.email).toLowerCase()
  )
    return "correo";
  return "dato único";
}

/** Crea el usuario. La validación de campos ya la hizo validarDatosUsuario en el controlador. `actor` = admin que lo crea. */
export const registrar = async (datos, actor = null) => {
  const dup = await userRepository.findDuplicate({
    tipo_documento: datos.tipo_documento,
    documento: datos.documento,
    usuario_login: datos.usuario_login,
    email: datos.email || undefined,
  });
  if (dup)
    return {
      status: 409,
      error: `Ya existe un usuario registrado con ese ${campoDuplicado(dup, datos)}.`,
    };

  const clave_hash = await bcrypt.hash(String(datos.clave), 10);
  const { insertId } = await userRepository.create({ ...datos, clave_hash });

  // Antes el audit se guardaba a nombre del usuario recién creado, no de quien lo creó.
  await auditRepository.registrarAudit({
    id_usuario: actor?.id_usuario ?? null,
    usuario_login: actor?.usuario_login ?? null,
    accion: "CREATE_USER",
    recurso: "usuarios",
    detalle: `Usuario creado: ${datos.usuario_login} (${datos.rol})`,
  });
  const c = await userRepository.findById(insertId);
  return {
    status: 201,
    body: {
      id_usuario: c.id_usuario,
      usuario_login: c.usuario_login,
      rol: c.rol,
      nombres: c.nombres,
      apellidos: c.apellidos,
      email: c.email,
    },
  };
};

export const restablecerClave = async ({ idUsuario, claveNueva, adminId }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (!usuario) return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };

  await userRepository.cambiarClave(
    idUsuario,
    await bcrypt.hash(String(claveNueva), 10),
  );
  await refreshTokenRepository.revocarRefreshTokensUsuario(idUsuario);
  await userRepository.cerrarSesionActiva(idUsuario);

  const admin = adminId ? await userRepository.findById(adminId) : null;
  await auditRepository.registrarAudit({
    id_usuario: adminId ?? null,
    usuario_login: admin?.usuario_login ?? "sistema",
    accion: "RESET_PASSWORD",
    recurso: "usuarios",
    detalle: `Clave restablecida y sesiones revocadas para ${usuario.usuario_login}`,
  });
  return {
    status: 200,
    body: {
      mensaje: `Clave restablecida para el usuario ${usuario.usuario_login}. Sesiones activas cerradas.`,
    },
  };
};

/** Re-autenticación (step-up). Si `clave` falta devuelve 422 sin llamar a bcrypt con "undefined". */
export const verificarClaveUsuario = async ({ usuario_login, clave }) => {
  if (!clave) return { status: 422, error: "La clave es obligatoria" };
  const usuario = await userRepository.findByLogin(usuario_login);
  if (!usuario) return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };
  if (!(await bcrypt.compare(String(clave), usuario.clave_hash)))
    return { status: 400, error: "La clave es incorrecta" };
  return { status: 200, body: { ok: true } };
};

export const logout = async ({ idUsuario, token }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (token) {
    try {
      const d = verificarToken(token);
      if (d?.jti && d?.exp) {
        await revokedTokenRepository.revocarToken({
          jti: d.jti,
          id_usuario: idUsuario,
          expires_at: new Date(d.exp * 1000),
        });
      }
    } catch (e) {
      console.warn("LOGOUT: no se pudo revocar el token:", e.message);
    }
  }
  await refreshTokenRepository.revocarRefreshTokensUsuario(idUsuario);
  await userRepository.cerrarSesionActiva(idUsuario);
  await auditRepository.registrarAudit({
    id_usuario: idUsuario,
    usuario_login: usuario?.usuario_login ?? null,
    accion: "LOGOUT",
    recurso: "auth",
    detalle: "Cierre de sesión",
  });
  return { status: 200, body: { ok: true } };
};

export const refresh = async ({ refresh_token }) => {
  if (!refresh_token) return { status: 422, error: "Refresh token requerido" };
  const row = await refreshTokenRepository.validarRefreshToken(refresh_token);
  if (!row) return { status: 401, error: "Refresh token inválido o expirado" };

  // Se valida al usuario ANTES de rotar (antes se emitía y revocaba tokens de usuarios inactivos).
  const usuario = await userRepository.findById(row.id_usuario);
  if (!usuario || usuario.estado !== "activo")
    return { status: 403, error: "Usuario inactivo" };

  await refreshTokenRepository.revocarRefreshToken(refresh_token);
  const nuevo = await refreshTokenRepository.crearRefreshToken(
    usuario.id_usuario,
  );
  return {
    status: 200,
    body: {
      token: generarToken(usuario.id_usuario),
      refresh_token: nuevo,
      usuario: perfil(usuario),
    },
  };
};

export default {
  login,
  registrar,
  restablecerClave,
  verificarClaveUsuario,
  logout,
  refresh,
};

const FILTROS_ESTADO = {
  inactiva: "c.activa = FALSE",
  "en mantenimiento": "c.activa = TRUE AND c.en_mantenimiento = TRUE",
  ocupada: SQL_OCUPADA,
  libre: `c.activa = TRUE AND c.en_mantenimiento = FALSE AND NOT ${SQL_OCUPADA}`,
};

export const listar = async (query) => {
  await liberarMantenimientosExpirados();
  const { page, limit, offset } = paginar(query);
  const conds = [], params = [];
  
  if (query.tipo === "carro" || query.tipo === "moto") {
    conds.push("tv.codigo = ?");
    params.push(query.tipo);
  }
  if (query.bloque) {
    conds.push("c.letra = ?");
    params.push(String(query.bloque).toUpperCase());
  }
  if (query.estado) {
    const filtro = FILTROS_ESTADO[String(query.estado).toLowerCase()];
    if (!filtro) throw new ErrorNegocio(400, MSG.FORMATO_INVALIDO("Estado"));
    conds.push(filtro);
  }

  const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";
  const [rows, [{ total }]] = await Promise.all([
    celdaRepo.listar(where, params, limit, offset),
    celdaRepo.contar(where, params)
  ]);
  return { rows, total: Number(total), page, limit };
};

};

export const bloques = async () => {
  await liberarMantenimientosExpirados();
  const filas = await celdaRepo.celdasPorBloque();
  const mapa = new Map();
  for (const f of filas) {
    if (!mapa.has(f.letra)) mapa.set(f.letra, []);
    mapa.get(f.letra).push(f);
  }
  return [...mapa.entries()].sort(([a], [b]) => a.localeCompare(b)).map(([bloque, celdas]) => ({ bloque, celdas }));
};

export const crear = async (body) => {
  const error = validarCrearCelda(body);
  if (error) throw new ErrorNegocio(422, error);
  
  const [tipo] = await celdaRepo.getTipo(body.id_tipo_vehiculo);
  if (!tipo) throw new ErrorNegocio(422, MSG.FORMATO_INVALIDO("Tipo de vehículo"));

  const max = limiteCeldas(tipo.codigo);
  if (max !== null) {
    const [{ total }] = await celdaRepo.contarPorTipo(tipo.id_tipo_vehiculo);
    if (Number(total) >= max) throw new ErrorNegocio(400, MSG.LIMITE_ALCANZADO(max, tipo.codigo));
  }

  try {
    const r = await celdaRepo.insertar({ ...body, letra: String(body.letra).trim().toUpperCase() });
    const [celda] = await celdaRepo.buscarPorId(r.insertId);
    return { celda };
  } catch (err) {
    if (err.code === "ER_DUP_ENTRY") throw new ErrorNegocio(409, MSG.DUPLICADO("Celda (Letra + Número)"));
    throw err;
  }
};

export const actualizarTipo = async (idRaw, idTipo) => {
  const id = Number(idRaw);
  const idT = Number(idTipo);
  if (!Number.isInteger(idT) || idT < 1) throw new ErrorNegocio(422, "El tipo de vehiculo es obligatorio");

  return conTransaccion(async (conn) => {
    const [celda] = await celdaRepo.buscarParaEstado(id);
    if (!celda) throw new ErrorNegocio(404, MSG.NO_ENCONTRADO("Celda"));
    if (celda.ocupada) throw new ErrorNegocio(400, "No se puede cambiar el tipo de una celda ocupada");

    const [tipo] = await celdaRepo.getTipo(idT);
    if (!tipo) throw new ErrorNegocio(422, MSG.FORMATO_INVALIDO("Tipo de vehículo"));

    if (celda.id_tipo_vehiculo !== idT) {
      const max = limiteCeldas(tipo.codigo);
      const [{ total }] = await celdaRepo.contarPorTipo(idT);
      if (max !== null && Number(total) >= max) throw new ErrorNegocio(400, MSG.LIMITE_ALCANZADO(max, tipo.codigo));
    }
    await celdaRepo.actualizarTipo(id, idT);
  });
};

export const intercambiarTipo = async (id1, id2) => {
  const a = Number(id1), b = Number(id2);
  if (!Number.isInteger(a) || !Number.isInteger(b) || a < 1 || b < 1) throw new ErrorNegocio(422, "Ambos IDs de celda son obligatorios");
  if (a === b) throw new ErrorNegocio(422, "Debe elegir dos celdas distintas");

  return conTransaccion(async (conn) => {
    const filas = await celdaRepo.buscarParaIntercambio([a, b]);
    if (filas.length !== 2) throw new ErrorNegocio(404, "Una o ambas celdas no existen");
    const [c1, c2] = [filas.find(f => f.id_celda === a), filas.find(f => f.id_celda === b)];
    
    if (c1.ocupada || c2.ocupada) throw new ErrorNegocio(400, "No se pueden intercambiar tipos de celdas ocupadas");
    if (c1.id_tipo_vehiculo === c2.id_tipo_vehiculo) throw new ErrorNegocio(400, "Las celdas ya son del mismo tipo");
    
    await celdaRepo.actualizarTipo(c1.id_celda, c2.id_tipo_vehiculo);
    await celdaRepo.actualizarTipo(c2.id_celda, c1.id_tipo_vehiculo);
  });
};

export const actualizarEstado = async (idRaw, body) => {
  await liberarMantenimientosExpirados();
  const id = Number(idRaw);
  const [celda] = await celdaRepo.buscarParaEstado(id);
  if (!celda) throw new ErrorNegocio(404, MSG.NO_ENCONTRADO("Celda"));

  const { activa, en_mantenimiento } = body;
  const sets = [], params = [];

  if (typeof activa === "boolean") {
    if (activa === true && celda.activa === 0) {
      const [tipo] = await celdaRepo.getTipo(celda.id_tipo_vehiculo);
      const max = limiteCeldas(tipo.codigo);
      if (max !== null) {
        const [{ total }] = await celdaRepo.contarPorTipo(tipo.id_tipo_vehiculo);
        if (Number(total) >= max) throw new ErrorNegocio(400, `No es posible habilitar: capacidad máxima de ${max} alcanzada.`);
      }
    }
    sets.push("activa = ?"); params.push(activa);
  }
  
  if (typeof en_mantenimiento === "boolean") {
    sets.push("en_mantenimiento = ?"); params.push(en_mantenimiento);
    if (en_mantenimiento) {
      const min = Number(body.minutos_mantenimiento ?? body.duracion_minutos ?? 60);
      if (!Number.isFinite(min) || min < 1) throw new ErrorNegocio(422, "Duración inválida");
      sets.push("mantenimiento_hasta = DATE_ADD(UTC_TIMESTAMP(), INTERVAL ? MINUTE)"); params.push(min);
    } else {
      sets.push("mantenimiento_hasta = NULL");
    }
  }

  const vaInactiva = typeof activa === "boolean" ? !activa : !celda.activa;
  const vaMant = typeof en_mantenimiento === "boolean" ? en_mantenimiento : !!celda.en_mantenimiento;
  if ((vaInactiva || vaMant) && celda.ocupada) throw new ErrorNegocio(400, "No se puede deshabilitar una celda ocupada.");

  await celdaRepo.ejecutarUpdate(sets, params, id);
};

export const eliminar = async (idRaw) => {
  const id = Number(idRaw);
  const [celda] = await celdaRepo.buscarParaEliminar(id);
  if (!celda) throw new ErrorNegocio(404, MSG.NO_ENCONTRADO("Celda"));
  if (celda.ocupada) throw new ErrorNegocio(409, "Celda ocupada");
  if (celda.historial) throw new ErrorNegocio(409, "La celda tiene historial de accesos");
  
  await celdaRepo.eliminar(id);
};

// -------------------- Listado --------------------

export async function listar(filtros) {
  const hoy = hoyBogota();
  const { page, limit } = paginar(filtros);
  const q = String(filtros.q ?? "").trim();

  const estadoRaw = String(filtros.estado ?? "").trim();
  const estadoFiltro = estadoRaw
    ? (ESTADOS_MENSUALIDAD_MAP[estadoRaw.toLowerCase()] ?? estadoRaw)
    : "";
  const tipoFiltro =
    filtros.tipo === "carro" || filtros.tipo === "moto" ? filtros.tipo : "";

  const { filas, total } = await mensualidadRepository.listarConFiltros({
    q,
    estadoFiltro,
    tipoFiltro,
    hoy,
    limit,
    offset: (page - 1) * limit,
  });

  const rows = filas.map((f) => mapFilaListado(f, hoy));

  const resumen = await construirResumen(hoy);

  return { rows, total, page, limit, resumen };
}

function mapFilaListado(f, hoy) {
  const ultima = f.id_ultima
    ? {
        fecha_inicio: toFecha(f.inicio_ultima),
        fecha_fin: toFecha(f.fin_ultima),
      }
    : null;
  const activa = f.id_activa
    ? {
        fecha_inicio: toFecha(f.inicio_activa),
        fecha_fin: toFecha(f.fin_activa),
      }
    : null;
  const prox = calcularPeriodo({
    hoy,
    ultimaMensualidad: ultima,
    tarifa: Number(f.tarifa_mensual),
  });
  return {
    documento: f.documento ?? "",
    propietario: nombrePropietario(f),
    nombres: f.nombres ?? "",
    apellidos: f.apellidos ?? "",
    nombre_completo: f.nombre_completo ?? "",
    tipo_documento: f.tipo_documento ?? "",
    telefono: f.telefono ?? "",
    email: f.email ?? "",
    color: f.color ?? "",
    modelo: f.modelo ?? "",
    anio: f.anio ?? "",
    nombre_modelo: f.nombre_modelo ?? "",
    placa: f.placa,
    tipo: f.tipo,
    tipoCodigo: f.tipo_codigo,
    estadoMensualidad: derivarEstado({ hoy, activa, ultima }),
    id_mensualidad: f.id_ultima ?? null,
    fecha_inicio: toFecha(f.inicio_ultima),
    fecha_fin: toFecha(f.fin_ultima),
    valor:
      f.valor_ultima != null
        ? Number(f.valor_ultima)
        : Number(f.tarifa_mensual),
    proximoPeriodo: prox,
  };
}

async function construirResumen(hoy) {
  const filasResumen = await mensualidadRepository.resumenPorTipo(hoy);
  const resumen = {
    carro: {
      alDia: 0,
      pendiente: 0,
      enMora: 0,
      sinMensualidad: 0,
      total: 0,
      ocupados: 0,
      capacidad: CAPACIDAD.carro,
    },
    moto: {
      alDia: 0,
      pendiente: 0,
      enMora: 0,
      sinMensualidad: 0,
      total: 0,
      ocupados: 0,
      capacidad: CAPACIDAD.moto,
    },
  };
  for (const r of filasResumen) {
    const bucket = resumen[r.tipo];
    if (!bucket) continue;
    const ultimaV = r.ultima_inicio
      ? {
          fecha_inicio: toFecha(r.ultima_inicio),
          fecha_fin: toFecha(r.ultima_fin),
        }
      : null;
    const activaV = r.activa_inicio
      ? {
          fecha_inicio: toFecha(r.activa_inicio),
          fecha_fin: toFecha(r.activa_fin),
        }
      : null;
    const est = derivarEstado({ hoy, activa: activaV, ultima: ultimaV });
    bucket.total++;
    if (est === "Al día") {
      bucket.alDia++;
      bucket.ocupados++;
    } else if (est === "Pendiente") {
      bucket.pendiente++;
      bucket.ocupados++;
    } else if (est === "En mora") {
      bucket.enMora++;
      bucket.ocupados++;
    } else bucket.sinMensualidad++;
  }
  return resumen;
}

export async function obtenerPorPlaca(placaRaw) {
  const placa = normalizarPlaca(placaRaw);
  if (!tipoDePlaca(placa)) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  const hoy = hoyBogota();
  const cols = await vehiculoRepository.getColumnasVehiculos();
  const extras = vehiculoRepository.buildAliases(cols);
  const extrasSql = extras.length ? `, ${extras.join(", ")}` : "";

  const filas = await mensualidadRepository.buscarVehiculoPorPlaca(
    placa,
    extrasSql,
  );
  if (!filas.length) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);
  const v = filas[0];
  if (!v.activo) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);

  const historial = await mensualidadRepository.historialPorVehiculo(
    v.id_vehiculo,
  );
  const activa =
    historial.find(
      (m) =>
        compararFechas(toFecha(m.fecha_inicio), hoy) <= 0 &&
        compararFechas(toFecha(m.fecha_fin), hoy) >= 0,
    ) ?? null;
  const ultima = historial[0] ?? null;
  const prox = calcularPeriodo({
    hoy,
    ultimaMensualidad: ultima
      ? {
          fecha_inicio: toFecha(ultima.fecha_inicio),
          fecha_fin: toFecha(ultima.fecha_fin),
        }
      : null,
    tarifa: Number(v.tarifa_mensual),
  });

  return {
    placa: v.placa,
    propietario: nombrePropietario(v),
    documento: v.documento ?? "",
    tipo_documento: v.tipo_documento ?? "",
    telefono: v.telefono ?? "",
    email: v.email ?? "",
    color: v.color ?? "",
    modelo: v.modelo ?? "",
    anio: v.anio ?? "",
    nombre_modelo: v.nombre_modelo ?? "",
    tipo: v.tipo,
    tipoCodigo: v.tipo_codigo,
    estadoMensualidad: derivarEstado({ hoy, activa, ultima }),
    mensualidadActual: activa
      ? {
          ...activa,
          fecha_inicio: toFecha(activa.fecha_inicio),
          fecha_fin: toFecha(activa.fecha_fin),
          valor: Number(activa.valor),
        }
      : null,
    proximoPeriodo: prox,
    historial: historial.map((m) => ({
      ...m,
      fecha_inicio: toFecha(m.fecha_inicio),
      fecha_fin: toFecha(m.fecha_fin),
      valor: Number(m.valor),
    })),
  };
}

export async function registrarPago(datos, user) {
  // === INICIO fix chk_pago_montos ===
  const montoNum = Number(datos?.monto ?? 0);
  if (!Number.isFinite(montoNum) || montoNum <= 0) {
    throw new ErrorNegocio(422, "El monto de la mensualidad es obligatorio y debe ser mayor a 0.");
  }
  const montoRecibidoNum =
    Number(datos?.monto_recibido) > 0
      ? Number(datos.monto_recibido)
      : montoNum;

  if (datos?.metodo_pago === "efectivo" && montoRecibidoNum < montoNum) {
    throw new ErrorNegocio(
      422,
      "El monto recibido no puede ser menor al valor de la mensualidad."
    );
  }
  // === FIN fix chk_pago_montos ===

  const placa = normalizarPlaca(datos?.placa);
  if (!placa) throw new ErrorNegocio(422, MSG.CAMPOS_OBLIGATORIOS);
  const tipo = tipoDePlaca(placa);
  if (!tipo) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  return conTransaccion(async (conn) => {
    const v = await mensualidadRepository.bloquearVehiculoPorPlaca(conn, placa);
    if (!v || !v.activo)
      throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);
    if (v.tipo_codigo !== tipo)
      throw new ErrorNegocio(422, MSG.PLACA_TIPO_INCOHERENTE);

    // === INICIO validación de cupo ===
    const [activa] = await conn.query(
      `SELECT 1 FROM mensualidades WHERE id_vehiculo = ? AND estado = 'activa' LIMIT 1`,
      [v.id_vehiculo]
    );

    if (activa.length === 0) {
      const [cupo] = await conn.query(
        `SELECT plazas_disponibles FROM v_resumen_cupos WHERE tipo_vehiculo = ?`,
        [v.tipo_codigo]
      );
      if (!cupo || Number(cupo.plazas_disponibles) <= 0) {
        throw new ErrorNegocio(409, "No hay cupo disponible. Libera un cupo antes de registrar una nueva mensualidad.");
      }
    }
    // === FIN validación de cupo ===

    const ultima = await mensualidadRepository.bloquearUltimaMensualidad(
      conn,
      v.id_vehiculo,
    );
    const hoy = hoyBogota();
    const periodo = calcularPeriodo({
      hoy,
      ultimaMensualidad: ultima,
      tarifa: Number(v.tarifa_mensual),
    });
    if (periodo.bloqueado) throw new ErrorNegocio(409, periodo.motivo);

    const id_usuario = user.id_usuario;
    const id_turno = await mensualidadRepository.resolverTurno(
      conn,
      id_usuario,
    );

    const id_mensualidad = await insertarDinamico(
      conn,
      "mensualidades",
      {
        id_vehiculo: v.id_vehiculo,
        fecha_inicio: periodo.inicio,
        fecha_fin: periodo.fin,
        valor: periodo.valor,
        estado: "activa",
      },
      {
        id_usuario,
        id_vehiculo: v.id_vehiculo,
        valor: periodo.valor,
        estadoDefault: "activa",
      },
    );

    const baseP = {
      id_mensualidad,
      id_turno,
      fecha_pago: "__NOW__",
    };
    const setP = await columnasTabla(conn, "pagos");
    for (const nombreMonto of [
      "valor",
      "monto",
      "valor_pago",
      "importe",
      "total",
      "cantidad",
      "precio",
    ]) {
      if (setP.has(nombreMonto)) {
        baseP[nombreMonto] = periodo.valor;
        break;
      }
    }
    // FIX chk_pago_montos: monto_recibido debe ser >= monto.
    if (setP.has("monto_recibido")) {
      baseP.monto_recibido = periodo.valor;
    }
    // FIX: si la tabla exige metodo_pago, usar 'efectivo' por defecto.
    if (setP.has("metodo_pago") && baseP.metodo_pago == null) {
      baseP.metodo_pago = "efectivo";
    }
    if (!setP.has("fecha_pago")) {
      if (setP.has("fecha")) baseP.fecha = "__NOW__";
      else if (setP.has("created_at")) baseP.created_at = "__NOW__";
    }

    const id_pago = await insertarDinamico(conn, "pagos", baseP, {
      id_usuario,
      id_vehiculo: v.id_vehiculo,
      id_mensualidad,
      id_turno,
      valor: periodo.valor,
      monto_recibido: montoRecibidoNum,
      metodo_pago: "efectivo",
      estadoDefault: "pagado",
    });

    await auditRepository.registrar(conn, {
      id_usuario,
      accion: "PAGO_MENSUALIDAD",
      detalle: `Pago ${placa} ${periodo.inicio}→${periodo.fin} $${periodo.valor}`,
    });

    return {
      id_mensualidad,
      id_pago,
      placa,
      fecha_inicio: periodo.inicio,
      fecha_fin: periodo.fin,
      valor: periodo.valor,
      anticipado: periodo.anticipado,
    };
  });
}

// -------------------- Eliminar --------------------

export async function eliminar(placaRaw, user) {
  const placa = normalizarPlaca(placaRaw);
  if (!tipoDePlaca(placa)) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  await conTransaccion(async (conn) => {
    const v = await mensualidadRepository.bloquearVehiculoSimple(conn, placa);
    if (!v) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);

    if (await mensualidadRepository.tieneAccesoAbierto(conn, v.id_vehiculo))
      throw new ErrorNegocio(409, "El vehículo está dentro del parqueadero");

    if (await mensualidadRepository.tieneHistorialAccesos(conn, v.id_vehiculo))
      throw new ErrorNegocio(
        409,
        "El vehículo tiene historial de accesos; no se puede eliminar",
      );

    if (await mensualidadRepository.tienePagos(conn, v.id_vehiculo))
      throw new ErrorNegocio(
        409,
        "El vehículo tiene pagos de mensualidad registrados",
      );

    await mensualidadRepository.verificarNovedades(conn, v.id_vehiculo);

    try {
      await mensualidadRepository.borrarMensualidadesDeVehiculo(
        conn,
        v.id_vehiculo,
      );
      await mensualidadRepository.borrarVehiculo(conn, v.id_vehiculo);
    } catch (e) {
      if (e.code === "ER_ROW_IS_REFERENCED_2")
        throw new ErrorNegocio(
          409,
          "El vehículo tiene registros relacionados; no se puede eliminar",
        );
      throw e;
    }

    try {
      await auditRepository.registrar(conn, {
        id_usuario: user.id_usuario,
        accion: "DELETE_VEHICULO",
        detalle: `Eliminado ${placa}`,
      });
    } catch (e) {
      console.warn("Auditoría no registrada:", e.message);
    }
  });
}

/**
 * PATCH /api/mensualidades/:placa/cancelar
 * Marca las mensualidades 'activa' del vehículo como 'cancelada'.
 * Efecto: el vehículo pasa a "Sin mensualidad" y libera cupo.
 */
export async function cancelar(placaRaw, user) {
  const placa = normalizarPlaca(placaRaw);
  if (!placa) throw new ErrorNegocio(422, "La placa es obligatoria.");

  return conTransaccion(async (conn) => {
    const veh = await mensualidadRepository.bloquearVehiculoPorPlaca(conn, placa);
    if (!veh) throw new ErrorNegocio(404, "Vehículo no encontrado.");
    if (veh.activo !== 1 && veh.activo !== true) {
      throw new ErrorNegocio(409, "El vehículo está inactivo.");
    }

    const dentro = await mensualidadRepository.tieneAccesoAbierto(conn, veh.id_vehiculo);
    if (dentro) {
      throw new ErrorNegocio(
        409,
        "El vehículo está dentro del parqueadero. Registre la salida antes de cancelar la mensualidad."
      );
    }

    const [activa] = await conn.query(
      `SELECT 1 FROM mensualidades WHERE id_vehiculo = ? AND estado = 'activa' LIMIT 1`,
      [veh.id_vehiculo]
    );
    if (!activa.length) {
      throw new ErrorNegocio(400, "El vehículo no tiene una mensualidad activa para cancelar.");
    }

    const afectadas = await mensualidadRepository.cancelarMensualidadesActivas(
      conn,
      veh.id_vehiculo
    );

    await auditRepository.registrar(conn, {
      id_usuario: user.id_usuario,
      accion: 'CANCEL_MENSUALIDAD',
      detalle: `Cancelación de mensualidad placa ${veh.placa} (${afectadas} filas)`
    });

    return {
      placa: veh.placa,
      id_vehiculo: veh.id_vehiculo,
      canceladas: afectadas,
    };
  });
}

// -------------------- Helpers inline --------------------

const PLACA_CARRO = /^[A-Z]{3}\d{3}$/;
const PLACA_MOTO = /^[A-Z]{3}\d{2}[A-Z]$/;

function normalizarPlaca(p) {
  return String(p ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");
}

function tipoDePlaca(p) {
  const n = normalizarPlaca(p);
  if (PLACA_CARRO.test(n)) return "carro";
  if (PLACA_MOTO.test(n)) return "moto";
  return null;
}

const hoyBogota = () =>
  new Intl.DateTimeFormat("en-CA", {
    timeZone: "America/Bogota",
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).format(new Date());

const toFecha = (v) => {
  if (!v) return null;
  if (typeof v === "string") return v.slice(0, 10);
  if (v instanceof Date) return v.toISOString().slice(0, 10);
  return String(v).slice(0, 10);
};

async function estadoMensualidadDe(conn, idVehiculo, hoy) {
  const [filas] = await conn.query(
    `SELECT fecha_inicio, fecha_fin
     FROM mensualidades WHERE id_vehiculo = ?
     ORDER BY fecha_fin DESC, id_mensualidad DESC`,
    [idVehiculo],
  );
  if (!filas.length) return "Sin mensualidad";

  const activa =
    filas.find(
      (m) =>
        compararFechas(toFecha(m.fecha_inicio), hoy) <= 0 &&
        compararFechas(toFecha(m.fecha_fin), hoy) >= 0,
    ) ?? null;
  const ultima = filas[0]
    ? {
        fecha_inicio: toFecha(filas[0].fecha_inicio),
        fecha_fin: toFecha(filas[0].fecha_fin),
      }
    : null;

  return derivarEstado({
    hoy,
    activa: activa
      ? {
          fecha_inicio: toFecha(activa.fecha_inicio),
          fecha_fin: toFecha(activa.fecha_fin),
        }
      : null,
    ultima,
  });
}

export async function dentro(qRaw) {

  const placa = esDocumento ? null : normalizarPlaca(q);

    tipo: f.tipo,
    tipoCodigo: f.tipo_codigo,
    celda: f.celda,
    entrada: formatearFechaHora(f.fecha_ingreso),
    salida: formatearFechaHora(ahora),

// -------------------- Entrada --------------------

export async function entrada(body, user) {
  const error = validarEntrada(body);
  if (error) throw new ErrorNegocio(422, error);

  const placa = normalizarPlaca(body.placa);
  const idCelda = Number(body.id_celda);
  const tipo = tipoDePlaca(placa);
  if (!tipo) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  return conTransaccion(async (conn) => {
    const v = await movimientoRepository.bloquearVehiculoPorPlaca(conn, placa);
    if (!v || !v.activo)
      throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);
    if (v.tipo_codigo !== tipo)
      throw new ErrorNegocio(422, MSG.PLACA_TIPO_INCOHERENTE);

    if (await movimientoRepository.estaDentro(conn, v.id_vehiculo))
      throw new ErrorNegocio(400, "El vehículo ya está dentro del parqueadero");

    const estado = await estadoMensualidadDe(conn, v.id_vehiculo, hoyBogota());
    if (estado !== "Al día")
      throw new ErrorNegocio(403, mensajeMensualidad(estado));

    const celda = await movimientoRepository.bloquearCelda(conn, idCelda);
    if (!celda)
      throw new ErrorNegocio(409, "La celda no existe o no está habilitada");
    if (celda.id_tipo_vehiculo !== v.id_tipo_vehiculo)
      throw new ErrorNegocio(422, "La celda es de otro tipo de vehículo");
    if (!celda.activa || celda.en_mantenimiento)
      throw new ErrorNegocio(409, "La celda no está disponible");
    if (await movimientoRepository.celdaOcupada(conn, idCelda))
      throw new ErrorNegocio(409, "La celda ya está ocupada");

    const idUsuario = user.id_usuario;
    const idTurno = await movimientoRepository.resolverTurno(conn, idUsuario);
    const idPuerta = await movimientoRepository.primeraPuertaActiva(conn);

    const idAcceso = await movimientoRepository.insertarAcceso(conn, {
      id_vehiculo: v.id_vehiculo,
      id_celda: idCelda,
      id_operador_ingreso: idUsuario,
      id_turno_ingreso: idTurno,
      id_puerta_ingreso: idPuerta,
    });

    await auditRepository.registrarAudit({
      id_usuario: idUsuario,
      accion: "entrada",
      recurso: "movimientos",
      detalle: `Ingreso ${placa} celda ${celda.codigo}`,
    });

    return {
      id: idAcceso,
      placa,
      tipo: v.tipo,
      celda: celda.codigo,
      accion: "entrada",
      ...formatearFechaHora(new Date()),
    };
  });
}

// -------------------- Salida --------------------

export async function salida(body, user) {
  const error = validarSalida(body);
  if (error) throw new ErrorNegocio(422, error);

  const placa = normalizarPlaca(body.placa);
  if (!tipoDePlaca(placa)) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  return conTransaccion(async (conn) => {
    const v = await movimientoRepository.bloquearVehiculoPorPlaca(conn, placa);
    if (!v) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);

    const abierto = await movimientoRepository.accesoAbierto(
      conn,
      v.id_vehiculo,
    );
    if (!abierto)
      throw new ErrorNegocio(
        400,
        "El vehículo no tiene un acceso abierto (no está dentro)",
      );

    const idUsuario = user.id_usuario;
    const idTurno = await movimientoRepository.resolverTurno(conn, idUsuario);
    const idPuerta = await movimientoRepository.primeraPuertaActiva(conn);

    await movimientoRepository.cerrarAcceso(conn, abierto.id_acceso, {
      id_operador_salida: idUsuario,
      id_turno_salida: idTurno,
      id_puerta_salida: idPuerta,
    });

    await auditRepository.registrarAudit({
      id_usuario: idUsuario,
      accion: "salida",
      recurso: "movimientos",
      detalle: `Salida ${placa} celda ${abierto.celda}`,
    });

    return {
      id: abierto.id_acceso,
      placa,
      tipo: v.tipo,
      celda: abierto.celda,
      accion: "salida",
      fecha_ingreso: formatearFechaHora(abierto.fecha_ingreso),
      permanencia: calcularPermanencia(abierto.fecha_ingreso, new Date()),
      ...formatearFechaHora(new Date()),
    };
  });
}

// -------------------- Reubicación --------------------

export async function reubicar(idAccesoRaw, body, user) {
  const error = validarReubicacion(body);
  if (error) throw new ErrorNegocio(422, error);

  const idAcceso = Number(idAccesoRaw);
  if (!Number.isInteger(idAcceso) || idAcceso <= 0)
    throw new ErrorNegocio(422, "Acceso inválido");
  const idCeldaDestino = Number(body.id_celda);

  return conTransaccion(async (conn) => {
    const acceso = await movimientoRepository.bloquearAcceso(conn, idAcceso);
    if (!acceso || acceso.fecha_salida)
      throw new ErrorNegocio(
        404,
        "Acceso no encontrado o el vehículo ya salió",
      );

    const celdaDestino = await movimientoRepository.bloquearCelda(
      conn,
      idCeldaDestino,
    );
    if (!celdaDestino) throw new ErrorNegocio(422, "Celda destino inválida");
    if (!celdaDestino.activa || celdaDestino.en_mantenimiento)
      throw new ErrorNegocio(
        422,
        "Celda destino deshabilitada o en mantenimiento",
      );
    if (celdaDestino.id_tipo_vehiculo !== acceso.id_tipo_vehiculo)
      throw new ErrorNegocio(422, "Celda destino de otro tipo de vehículo");
    if (await movimientoRepository.celdaOcupada(conn, idCeldaDestino))
      throw new ErrorNegocio(409, "La celda destino ya está ocupada");

    await movimientoRepository.actualizarCeldaAcceso(
      conn,
      idAcceso,
      idCeldaDestino,
    );

    await auditRepository.registrarAudit({
      id_usuario: user.id_usuario,
      accion: "reubicacion",
      recurso: "movimientos",
      detalle: `Reubicación ${acceso.placa} ${acceso.celda} → ${celdaDestino.codigo}`,
    });

    return {
      id: idAcceso,
      placa: acceso.placa,
      celda_origen: acceso.celda,
      celda: celdaDestino.codigo,
      accion: "reubicacion",
    };
  });
}

// -------------------- Helpers --------------------

function mensajeMensualidad(estado) {
  if (estado === "Pendiente")
    return "La mensualidad aún no inicia; no se permite el ingreso";
  if (estado === "En mora")
    return "La mensualidad está en mora; no se permite el ingreso";
  return "El vehículo no tiene mensualidad activa; no se permite el ingreso";
}

import * as userRepository from "../repositories/userRepository.js";
import { validarDatosUsuario } from "../middleware/validation.js";
import { MSG } from "../utils/messages.js";

const limpiar = ({ clave_hash, ...u }) => ({
  ...u,
  sesion_activa: !!u.sesion_activa,
});

export const listarUsuarios = async (opts) => {
  const r = await userRepository.listar(opts);
  return { ...r, rows: r.rows.map(limpiar) };
};

export const obtenerUsuario = async (id) => {
  const u = await userRepository.findById(id);
  return u
    ? { status: 200, body: limpiar(u) }
    : { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };
};

export const editarUsuario = async (id, datos) => {
  const invalido = validarDatosUsuario(datos, { requiereClave: false });
  if (invalido) return { status: 422, error: invalido };
  if (!(await userRepository.findById(id)))
    return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };

  const dup = await userRepository.findDuplicate(
    {
      tipo_documento: datos.tipo_documento,
      documento: datos.documento,
      usuario_login: datos.usuario_login,
      email: datos.email || undefined,
    },
    id,
  );
  if (dup)
    return {
      status: 409,
      error: MSG.DUPLICADO("Usuario (Documento/Login/Email)"),
    };

  if (!(await userRepository.actualizar(id, datos)))
    return {
      status: 200,
      body: { mensaje: "No se realizaron cambios en el perfil del usuario." },
    };
  return {
    status: 200,
    body: {
      mensaje: MSG.ACTUALIZADO("Usuario"),
      usuario: limpiar(await userRepository.findById(id)),
    },
  };
};

export const cambiarEstadoUsuario = async (id, estado) => {
  if (!["activo", "inactivo"].includes(estado))
    return {
      status: 422,
      error: MSG.FORMATO_INVALIDO("Estado (activo/inactivo)"),
    };
  if (!(await userRepository.findById(id)))
    return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };
  await userRepository.cambiarEstado(id, estado);
  return {
    status: 200,
    body: {
      mensaje: `Estado del usuario modificado a '${estado}' exitosamente.`,
    },
  };
};

export default {
  listarUsuarios,
  obtenerUsuario,
  editarUsuario,
  cambiarEstadoUsuario,
};

// -------------------- Crear --------------------

export async function crear(body, user) {
  const error = validarCrearVehiculo(body);
  if (error) throw new ErrorNegocio(422, error);

  const placa = normalizarPlaca(body.placa);
  const tipo = tipoDePlaca(placa);
  const incoherencia = coherenciaPlacaTipo(placa, body.tipo);
  if (incoherencia) throw new ErrorNegocio(422, incoherencia);

  return conTransaccion(async (conn) => {
    const existente = await vehiculoRepository.bloquearPorPlaca(conn, placa);
    if (existente)
      throw new ErrorNegocio(409, "Ya existe un vehículo con esa placa");

    const tipoVehiculo = await vehiculoRepository.buscarTipoPorCodigo(
      conn,
      body.tipo ?? tipo,
    );
    if (!tipoVehiculo)
      throw new ErrorNegocio(422, "Tipo de vehículo inválido");

    const id = await vehiculoRepository.insertar(conn, {
      placa,
      id_tipo_vehiculo: tipoVehiculo.id_tipo_vehiculo,
      color: body.color ?? null,
      modelo: body.modelo ?? null,
      anio: body.anio ?? null,
      nombre_modelo: body.nombre_modelo ?? null,
      ...mapPropietario(body),
    });

    await auditRepository.registrarAudit({
      id_usuario: user.id_usuario,
      accion: "CREATE_VEHICLE",
      recurso: "vehiculos",
      detalle: `Alta vehículo ${placa}`,
    }, conn);

    return vehiculoRepository.buscarPorIdTx(conn, id);
  });
}

// -------------------- Editar --------------------

export async function editar(placaRaw, body, user) {
  const placa = normalizarPlaca(placaRaw);
  if (!tipoDePlaca(placa)) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  const error = validarEditarVehiculo(body);
  if (error) throw new ErrorNegocio(422, error);

  return conTransaccion(async (conn) => {
    const v = await vehiculoRepository.bloquearPorPlaca(conn, placa);
    if (!v) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);

    if (body.placa && normalizarPlaca(body.placa) !== v.placa)
      throw new ErrorNegocio(422, "La placa no se puede modificar; registre un vehículo nuevo");

    const cambios = {
      color: body.color,
      modelo: body.modelo,
      anio: body.anio,
      nombre_modelo: body.nombre_modelo,
    };

    if (body.tipo) {
      const incoherencia = coherenciaPlacaTipo(placa, body.tipo);
      if (incoherencia) throw new ErrorNegocio(422, incoherencia);
      const tipo = await vehiculoRepository.buscarTipoPorCodigo(conn, body.tipo);
      if (!tipo) throw new ErrorNegocio(422, "Tipo de vehículo inválido");
      cambios.id_tipo_vehiculo = tipo.id_tipo_vehiculo;
    }

    const tieneDatosPropietario =
      body.documento || body.tipo_documento || body.nombres ||
      body.apellidos || body.nombre_completo || body.telefono || body.email;

    if (tieneDatosPropietario) Object.assign(cambios, mapPropietario(body));

    await vehiculoRepository.actualizar(conn, v.id_vehiculo, cambios);

    await auditRepository.registrarAudit({
      id_usuario: user.id_usuario,
      accion: "EDIT_VEHICLE",
      recurso: "vehiculos",
      detalle: `Edición vehículo ${placa}`,
    }, conn);

    return vehiculoRepository.buscarPorIdTx(conn, v.id_vehiculo);
  });
}

// -------------------- Cambiar estado --------------------

export async function cambiarEstado(placaRaw, body, user) {
  const placa = normalizarPlaca(placaRaw);
  if (!tipoDePlaca(placa)) throw new ErrorNegocio(422, MSG.PLACA_INVALIDA);

  const error = validarEstadoVehiculo(body);
  if (error) throw new ErrorNegocio(422, error);

  const activo = body.activo === true || body.activo === "true";

  return conTransaccion(async (conn) => {
    const v = await vehiculoRepository.bloquearPorPlaca(conn, placa);
    if (!v) throw new ErrorNegocio(404, MSG.VEHICULO_NO_ENCONTRADO);

    if (!activo && (await vehiculoRepository.estaDentroTx(conn, v.id_vehiculo)))
      throw new ErrorNegocio(
        409,
        "No se puede desactivar un vehículo que está dentro del parqueadero",
      );

    await vehiculoRepository.cambiarActivo(conn, v.id_vehiculo, activo);
    await auditRepository.registrarAudit({
      id_usuario: user.id_usuario,
      accion: activo ? "ACTIVATE_VEHICLE" : "DEACTIVATE_VEHICLE",
      recurso: "vehiculos",
      detalle: `${activo ? "Activación" : "Desactivación"} vehículo ${placa}`,
    }, conn);

    return vehiculoRepository.buscarPorIdTx(conn, v.id_vehiculo);
  });
}

export const SQL_OCUPADA = `EXISTS (SELECT 1 FROM accesos_vehiculos a WHERE a.id_celda = c.id_celda AND a.fecha_salida IS NULL)`;

/** Prioridad: inactiva > en mantenimiento > ocupada > libre. */
export const ESTADO_SQL = `CASE
  WHEN c.activa = FALSE THEN 'inactiva'
  WHEN c.en_mantenimiento = TRUE AND (c.mantenimiento_hasta IS NULL OR c.mantenimiento_hasta > UTC_TIMESTAMP()) THEN 'en mantenimiento'
  WHEN ${SQL_OCUPADA} THEN 'ocupada'
  ELSE 'libre' END`;

const SQL_LIBERAR = `UPDATE celdas SET en_mantenimiento = FALSE, mantenimiento_hasta = NULL
  WHERE en_mantenimiento = TRUE AND mantenimiento_hasta IS NOT NULL AND mantenimiento_hasta <= UTC_TIMESTAMP()`;

/** Libera mantenimientos vencidos. `db` puede ser el pool o una conexión de transacción. */
export const liberarMantenimientosExpirados = (db = pool) =>

/** Normaliza page/limit. Nunca devuelve offsets negativos. */
export function paginar(
  { page, limit } = {},
  { porDefecto = 20, maximo = 100 } = {},
) {
  const p = Math.max(Number.parseInt(page, 10) || 1, 1);
  const l = Math.min(
    Math.max(Number.parseInt(limit, 10) || porDefecto, 1),
    maximo,
  );
  return { page: p, limit: l, offset: (p - 1) * l };
}

// -------------------- Columnas de una tabla (cacheadas) --------------------
const _colsCacheTabla = new Map();
const _colsCacheTime = new Map();
const CACHE_TTL = 3600000; // 1 hora

export async function columnasTabla(conn, tabla) {
  const ahora = Date.now();
  if (_colsCacheTabla.has(tabla) && (ahora - (_colsCacheTime.get(tabla) || 0) < CACHE_TTL)) {
    return _colsCacheTabla.get(tabla);
  }
  const [filas] = await conn.query(
    `SELECT COLUMN_NAME FROM INFORMATION_SCHEMA.COLUMNS
     WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = ?`,
    [tabla],
  );
  const set = new Set(filas.map((f) => f.COLUMN_NAME));
  _colsCacheTabla.set(tabla, set);
  _colsCacheTime.set(tabla, ahora);
  return set;
}

// -------------------- Columnas requeridas (NOT NULL sin default, sin auto_increment) --------------------
const _reqCacheTabla = new Map();
const _reqCacheTime = new Map();

export async function columnasRequeridas(conn, tabla) {
  const ahora = Date.now();
  if (_reqCacheTabla.has(tabla) && (ahora - (_reqCacheTime.get(tabla) || 0) < CACHE_TTL)) {
    return _reqCacheTabla.get(tabla);
  }
  const [filas] = await conn.query(
    `SELECT COLUMN_NAME, DATA_TYPE FROM INFORMATION_SCHEMA.COLUMNS
     WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = ?
       AND IS_NULLABLE = 'NO'
       AND COLUMN_DEFAULT IS NULL
       AND EXTRA NOT LIKE '%auto_increment%'`,
    [tabla],
  );
  _reqCacheTabla.set(tabla, filas);
  _reqCacheTime.set(tabla, ahora);
  return filas;
}

// Valor por defecto para una columna requerida desconocida.
export function valorDefectoPara(nombre, tipo, ctx) {
  const n = String(nombre || "").toLowerCase();
  if (
    ["id_usuario", "id_usuario_registro", "usuario_id", "id_operador"].includes(
      n,
    )
  )
    return ctx.id_usuario;
  if (n === "id_vehiculo") return ctx.id_vehiculo ?? 0;
  if (n === "id_mensualidad") return ctx.id_mensualidad ?? 0;
  if (n === "id_turno") return ctx.id_turno ?? 0;
  if (["metodo_pago", "medio_pago", "forma_pago"].includes(n))
    return "efectivo";
  if (n === "estado") return ctx.estadoDefault ?? "activa";
  if (n === "created_at" || n === "updated_at" || n.startsWith("fecha"))
    return new Date();
  if (
    [
      "valor",
      "monto",
      "valor_pago",
      "importe",
      "total",
      "cantidad",
      "precio",
    ].includes(n)
  )
    return ctx.valor ?? 0;
  if (["int", "bigint", "tinyint", "smallint", "mediumint"].includes(tipo))
    return 0;
  if (["decimal", "float", "double", "numeric"].includes(tipo)) return 0;
  if (["date", "datetime", "timestamp"].includes(tipo)) return new Date();
  return "";
}

// Construye el INSERT dinámico rellenando cualquier columna requerida faltante.
export async function insertarDinamico(conn, tabla, base, ctx) {
  const columnas = await columnasTabla(conn, tabla);
  const requeridas = await columnasRequeridas(conn, tabla);

  const campos = [];
  const valores = [];
  const placeholders = [];

  const addVal = (nombre, valor) => {
    campos.push(nombre);
    valores.push(valor);
    placeholders.push("?");
  };
  const addRaw = (nombre, sql) => {
    campos.push(nombre);
    placeholders.push(sql);
  };

  // 1) Campos explícitos del controlador, solo si la columna existe.
  for (const [nombre, valor] of Object.entries(base)) {
    if (!columnas.has(nombre)) continue;
    if (valor === "__NOW__") addRaw(nombre, "NOW()");
    else addVal(nombre, valor);
  }

  // 2) Columna de usuario: cualquiera de los alias conocidos.
  for (const alias of [
    "id_usuario_registro",
    "id_usuario",
    "usuario_id",
    "id_operador",
  ]) {
    if (columnas.has(alias) && !campos.includes(alias)) {
      addVal(alias, ctx.id_usuario);
    }
  }

  // 3) Rellenar el resto de requeridas que aún no estén.
  for (const col of requeridas) {
    if (campos.includes(col.COLUMN_NAME)) continue;
    addVal(
      col.COLUMN_NAME,
      valorDefectoPara(col.COLUMN_NAME, col.DATA_TYPE, ctx),
    );
  }

  if (!campos.length) {
    throw new ErrorNegocio(
      500,
      `La tabla '${tabla}' no tiene columnas para insertar`,
    );
  }

  const sql = `INSERT INTO ${tabla} (${campos.join(", ")})
               VALUES (${placeholders.join(", ")})`;
  const [ins] = await conn.query(sql, valores);
  return ins.insertId;
}

/**
 * Cálculo puro del próximo periodo de mensualidad.
 * Sin BD: recibe fechas ya resueltas en zona Bogotá (YYYY-MM-DD).
 *
 * Reglas:
 *  - Sin historial o última vencida: inicio = hoy, fin = inicio + 1 mes - 1 día.
 *  - Con mensualidad vigente:       inicio = fecha_fin + 1 día, fin = inicio + 1 mes - 1 día (anticipado).
 *  - Con siguiente periodo ya pagado (inicio > hoy): { bloqueado: true }.
 */

// Cálculo puro del periodo y del estado de mensualidad. Sin BD.

// Cálculo puro del periodo y del estado de mensualidad. Sin BD.

export const GRACIA_DIAS = 1; // días que un "pendiente"/"en mora" retiene cupo
export const DIAS_ANTICIPACION = 5; // días antes del vencimiento para renovar

export function compararFechas(a, b) {
  if (!a && !b) return 0;
  if (!a) return -1;
  if (!b) return 1;
  return a < b ? -1 : a > b ? 1 : 0;
}

export function diferenciaDias(a, b) {
  // (b - a) en días
  const da = new Date(a + "T00:00:00Z");
  const db = new Date(b + "T00:00:00Z");
  return Math.round((db - da) / (1000 * 60 * 60 * 24));
}

export function sumarUnDia(fecha) {
  const d = new Date(fecha + "T00:00:00Z");
  d.setUTCDate(d.getUTCDate() + 1);
  return d.toISOString().slice(0, 10);
}

export function restarUnDia(fecha) {
  const d = new Date(fecha + "T00:00:00Z");
  d.setUTCDate(d.getUTCDate() - 1);
  return d.toISOString().slice(0, 10);
}

export function sumarUnMes(fecha) {
  const [y, m, d] = fecha.split("-").map(Number);
  const obj = new Date(Date.UTC(y, m - 1, d));
  obj.setUTCMonth(obj.getUTCMonth() + 1);
  return obj.toISOString().slice(0, 10);
}

export function calcularPeriodo({ hoy, ultimaMensualidad, tarifa }) {
  // Ya hay un periodo futuro pagado → bloquear.
  if (
    ultimaMensualidad &&
    compararFechas(ultimaMensualidad.fecha_inicio, hoy) > 0
  ) {
    return {
      bloqueado: true,
      motivo: "El vehículo ya tiene pagado el próximo periodo",
    };
  }

  const vigente =
    ultimaMensualidad && compararFechas(ultimaMensualidad.fecha_fin, hoy) >= 0;

  // Con periodo vigente, solo se puede renovar cuando falten <= DIAS_ANTICIPACION días.
  if (vigente) {
    const diasRestantes = diferenciaDias(hoy, ultimaMensualidad.fecha_fin);
    if (diasRestantes > DIAS_ANTICIPACION) {
      return {
        bloqueado: true,
        motivo: `El periodo actual vence el ${ultimaMensualidad.fecha_fin}. Podrás renovar ${DIAS_ANTICIPACION} días antes.`,
        fecha_fin_actual: ultimaMensualidad.fecha_fin,
        dias_restantes: diasRestantes,
      };
    }
  }

  const inicio = vigente ? sumarUnDia(ultimaMensualidad.fecha_fin) : hoy;
  const fin = restarUnDia(sumarUnMes(inicio));
  return {
    bloqueado: false,
    inicio,
    fin,
    valor: tarifa,
    anticipado: Boolean(vigente),
  };
}

/**
 * Regla de negocio (con gracia 1 día):
 *  - Al día         : suscripción activa hoy.
 *  - Pendiente      : suscripción futura que empieza en ≤ GRACIA_DIAS días.
 *  - En mora        : suscripción vencida hace ≤ GRACIA_DIAS días.
 *  - Sin mensualidad: sin suscripción, o vencida/por-iniciar hace más de GRACIA_DIAS.
 *    En este estado el vehículo NO ocupa cupo.
 */
export function derivarEstado({ hoy, activa, ultima }) {
  if (activa) return "Al día";
  if (!ultima) return "Sin mensualidad";

  if (compararFechas(ultima.fecha_inicio, hoy) > 0) {
    const dias = diferenciaDias(hoy, ultima.fecha_inicio);
    return dias <= GRACIA_DIAS ? "Pendiente" : "Sin mensualidad";
  }

  if (compararFechas(ultima.fecha_fin, hoy) < 0) {
    const dias = diferenciaDias(ultima.fecha_fin, hoy);
    return dias <= GRACIA_DIAS ? "En mora" : "Sin mensualidad";
  }

  return "Sin mensualidad";
}

export const responder = (res, status, texto, extra = null) => {
  const esExito = status >= 200 && status < 300;
  let payload;
  if (!esExito) {
    payload = { error: texto };
  } else {
    payload = { mensaje: texto };
    if (Array.isArray(extra)) {
      payload.data = extra;
    } else if (extra) {
      Object.assign(payload, extra);
    }
  }
  return res.status(status).json(payload);
};

const PLACA_CARRO = /^[A-Z]{3}\d{3}$/;
const PLACA_MOTO = /^[A-Z]{3}\d{2}[A-Z]$/;

export function normalizarPlaca(p) {
  return String(p ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");
}

export function tipoDePlaca(p) {
  const n = normalizarPlaca(p);
  if (PLACA_CARRO.test(n)) return "carro";
  if (PLACA_MOTO.test(n)) return "moto";
  return null;
}

/**
 * Devuelve string de error si la placa no corresponde al tipo indicado, o null.
 */
export function coherenciaPlacaTipo(placa, tipo) {
  if (!tipo) return null;
  const esperado = tipoDePlaca(placa);
  if (!esperado) return "Formato de placa inválido";
  if (esperado !== String(tipo).toLowerCase())
    return `La placa ${placa} no corresponde a un ${tipo}`;
  return null;
}

/**
 * Extrae los campos del propietario que el schema guarda en `vehiculos`
 * (datos integrados: nombre, tipo y número de documento, teléfono, correo).
 */
export function mapPropietario(body) {
  return {
    tipo_documento: body.tipo_documento ?? null,
    documento: body.documento ?? null,
    nombres: body.nombres ?? null,
    apellidos: body.apellidos ?? null,
    nombre_completo:
      body.nombre_completo ??
      ([body.nombres, body.apellidos].filter(Boolean).join(" ").trim() || null),
    telefono: body.telefono ?? null,
    email: body.email ?? null,
  };
}

// Validacion de placas colombianas.
//   - Carro: 3 letras + 3 numeros          -> ABC123  (ABC-123)
//   - Moto:  3 letras + 2 numeros + letra  -> ABC12C  (ABC-12C)

/** @type {Object.<string, RegExp>} */
export const FORMATOS_POR_TIPO = {
  carro: /^([A-Z]{3})-?([0-9]{3})$/,
  moto: /^([A-Z]{3})-?([0-9]{2})([A-Z])$/,
};

export const FORMATOS = [FORMATOS_POR_TIPO.carro, FORMATOS_POR_TIPO.moto];

/**
 * Normaliza una placa: mayúsculas, sin espacios ni guiones.
 * @param {string} placa 
 * @returns {string}
 */
export const normalizarPlaca = (placa) =>
  String(placa ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");

/**
 * Verifica si una placa es válida según el tipo.
 * @param {string} placa 
 * @param {string|null} tipo - 'carro' | 'moto' | null
 * @returns {boolean}
 */
export const esPlacaValida = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) return false;
  if (tipo && FORMATOS_POR_TIPO[tipo]) return FORMATOS_POR_TIPO[tipo].test(p);
  return FORMATOS.some((re) => re.test(p));
};

/**
 * Valida una placa y devuelve objeto con detalles.
 * @param {string} placa 
 * @param {string|null} tipo 
 * @returns {{ valida: boolean, placa: string, tipo: string|null, error: string|null }}
 */
export const validarPlaca = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) {
    return { valida: false, placa: p, tipo, error: "La placa es obligatoria" };
  }

  if (tipo && FORMATOS_POR_TIPO[tipo]) {
    if (!FORMATOS_POR_TIPO[tipo].test(p)) {
      return {
        valida: false,
        placa: p,
        tipo,
        error:
          tipo === "moto"
            ? "Formato de placa inválido para moto. Ejemplo: ABC12C"
            : "Formato de placa inválido para carro. Ejemplo: ABC123",
      };
    }
    return { valida: true, placa: p, tipo, error: null };
  }

  if (!FORMATOS.some((re) => re.test(p))) {
    return {
      valida: false,
      placa: p,
      tipo,
      error:
        "Formato de placa inválido. Ejemplo: ABC123 (carro) o ABC12C (moto)",
    };
  }

  const tipoDetectado = FORMATOS_POR_TIPO.moto.test(p) ? "moto" : "carro";
  return { valida: true, placa: p, tipo: tipoDetectado, error: null };
};

/**
 * @fileoverview Validaciones puras de entrada para vehículos.
 * Devuelven string de error o null.
 */

const PLACA_CARRO = /^[A-Z]{3}\d{3}$/;
const PLACA_MOTO = /^[A-Z]{3}\d{2}[A-Z]$/;
const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const TIPOS_DOC = ["cc", "ce", "nit", "pasaporte"];

export function validarDocumento(doc) {
  const d = String(doc ?? "").trim();
  if (d.length < 5 || d.length > 20)
    return "El documento debe tener entre 5 y 20 caracteres";
  if (!/^[A-Za-z0-9]+$/.test(d))
    return "El documento solo admite caracteres alfanuméricos";
  return null;
}

export function validarCrearVehiculo(body) {
  const placa = String(body?.placa ?? "")
    .toUpperCase()
    .replace(/[\s-]/g, "");
  if (!PLACA_CARRO.test(placa) && !PLACA_MOTO.test(placa))
    return "Formato de placa inválido (AAA### o AAA##X)";

  if (body?.tipo && !["carro", "moto"].includes(body.tipo))
    return "tipo inválido (carro | moto)";

  const docErr = validarDocumento(body?.documento);
  if (docErr) return docErr;

  if (!body?.nombres && !body?.nombre_completo)
    return "Debe indicar nombres o nombre_completo del propietario";

  if (body?.tipo_documento && !TIPOS_DOC.includes(body.tipo_documento))
    return "tipo_documento inválido (cc | ce | nit | pasaporte)";

  if (body?.email && !EMAIL.test(body.email))
    return "Correo electrónico inválido";

  return null;
}

export function validarEditarVehiculo(body) {
  if (body?.documento) {
    const docErr = validarDocumento(body.documento);
    if (docErr) return docErr;
  }
  if (body?.email && !EMAIL.test(body.email))
    return "Correo electrónico inválido";
  if (body?.tipo_documento && !TIPOS_DOC.includes(body.tipo_documento))
    return "tipo_documento inválido (cc | ce | nit | pasaporte)";
  return null;
}

export function validarEstadoVehiculo(body) {
  if (body?.activo === undefined)
    return "Debe indicar el campo activo (true | false)";
  if (typeof body.activo !== "boolean" && !["true", "false"].includes(body.activo))
    return "activo debe ser booleano";
  return null;
}
