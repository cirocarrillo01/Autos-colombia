# Parches SQL — Auto Colombia

Este documento registra los cambios aplicados a `backend/Script/parqueadero.sql` y las migraciones incrementales no incluidas en el esquema base.

---

## 1. Parches aplicados a `backend/Script/parqueadero.sql`

### 1.1. Eliminación de depuración final (antes líneas 318-321)

Se eliminaron las líneas de depuración que se ejecutaban al importar el script:

```sql
USE autos_colombia;

SELECT *
FROM vehiculos;
```

**Impacto:** Ninguno en el esquema ni en los datos. Solo se evita salida innecesaria en la consola del cliente MySQL al crear la base.

---

### 1.2. Actualización de comentarios obsoletos ("celda fija")

El modelo de negocio es de **celdas rotativas** (cada ingreso elige una celda libre del mismo tipo), no celdas fijas asignadas por vehículo. Se corrigieron los comentarios:

| Línea antes | Contenido anterior | Contenido nuevo |
|-------------|-------------------|-----------------|
| 8 | `Cada vehículo mensual tiene una celda fija asignada.` | `Cada ingreso elige una celda libre rotativa del mismo tipo del vehículo.` |
| 21 | `vehiculos: placa + propietario + celda_fija + tipo` | `vehiculos: placa + propietario + tipo` |
| 214 | `id_celda ... -- toma de vehiculos.id_celda_fija al ingresar` | `id_celda ... -- celda asignada en el ingreso (rotativa)` |

**Nota:** La tabla `vehiculos` nunca tuvo columna `celda_fija`; el comentario anterior era factualmente incorrecto.

---

### 1.3. Índices adicionales

Se agregaron dos índices con `IF NOT EXISTS` (idempotentes):

```sql
CREATE INDEX IF NOT EXISTS ix_acceso_fecha_ingreso ON accesos_vehiculos (fecha_ingreso);
CREATE INDEX IF NOT EXISTS ix_la_fecha ON login_attempts (fecha_intento);
```

- `ix_acceso_fecha_ingreso`: mejora consultas de historial filtradas solo por rango de fechas.
- `ix_la_fecha`: mejora purgas masivas de `login_attempts` por antigüedad.

---

### 1.4. Evento programado de purga (comentado por seguridad)

Se agregó como SQL **comentado** un evento programado para purgar `login_attempts` y `audit_log` antiguos (más de 90 días):

```sql
-- CREATE EVENT IF NOT EXISTS ev_purga_login_attempts
-- ON SCHEDULE EVERY 24 HOUR
-- DO
--   DELETE FROM login_attempts WHERE fecha_intento < DATE_SUB(UTC_TIMESTAMP(), INTERVAL 90 DAY);
```

**No está activado por defecto** porque:
- Borra datos irreversiblemente.
- Requiere `event_scheduler = ON` en el servidor MySQL.
- La política de retención debe definirse con el negocio y validarse en staging antes de activarse.

---

### 1.5. `refresh_tokens.token` guarda SHA-256

La columna `refresh_tokens.token` ya es `VARCHAR(128)`, suficiente para almacenar un hash SHA-256 hex (64 caracteres). El código backend (`refreshTokenRepository.js`) ya guarda `hashToken(token)` en lugar del token en claro.

**Impacto operativo:** Los refresh tokens existentes en la base de datos (guardados en claro antes de este cambio) dejarán de validar. Los usuarios deberán volver a iniciar sesión una vez tras el despliegue.

---

## 2. Migraciones incrementales (`backend/migrations/`)

| Archivo | Descripción |
|---------|-------------|
| `001_initial_schema.sql` | Esquema inicial (tablas base). |
| `002_add_sesion_activa.sql` | Agrega `sesion_activa` y `fecha_sesion_activa` a `usuarios`, más índice `ix_usuario_sesion_activa`. |
| `003_add_mantenimiento_hasta.sql` | Agrega `mantenimiento_hasta` a `celdas`. |

---

## 3. Archivo suelto: `backend/Script/migracion_sesion_activa.sql`

Existe un archivo duplicado de la migración 002 en `backend/Script/migracion_sesion_activa.sql`. Contiene el mismo `ALTER TABLE` que `backend/migrations/002_add_sesion_activa.sql` más un `SELECT` de confirmación. No está versionado como migración incremental; se mantiene como referencia para bases creadas con `parqueadero.sql` antes de que las columnas existieran.

**Recomendación:** Usar `backend/migrations/002_add_sesion_activa.sql` como fuente de verdad. El archivo en `backend/Script/` puede eliminarse una vez confirmado que no se referencia en ningún proceso de despliegue.

---

## 4. Cómo aplicar las migraciones

Desde `backend/`:

```bash
# Verificar migraciones pendientes (según el entorno)
mysql -u root -p autos_colombia < backend/migrations/007_audit_log_accion.sql
```

Siempre tomar un backup (`mysqldump`) antes de aplicar cualquier migración en producción.

});

/** Consulta parametrizada; devuelve solo las filas. */
export async function query(sql, params = []) {
  try {
    const [filas] = await pool.query(sql, params);
    return filas;
  } catch (err) {
    console.error("Error en consulta SQL:", err.message, "\nSQL:", sql);
    throw err;
  }
}

/**
 * Ejecuta `trabajo(conn)` dentro de UNA transacción real (misma conexión).
 * Commit si termina bien, rollback si lanza.
 */
export async function conTransaccion(trabajo) {
  const conn = await pool.getConnection();
  try {
    await conn.beginTransaction();
    const r = await trabajo(conn);
    await conn.commit();
    return r;
  } catch (err) {
    try {
      await conn.rollback();
    } catch {
      /* conexión ya cerrada */
    }
    throw err;
  } finally {
    conn.release();
  }
}

// Funciones puras para leer y validar variables de entorno (testeables sin tocar disco).

/** Parsea el contenido de un .env. Soporta comillas y comentarios `# ...` en línea. */
export function parseEnv(contenido) {
  const out = {};
  for (const linea of String(contenido).split(/\r?\n/)) {
    const texto = linea.trim();
    if (!texto || texto.startsWith("#")) continue;
    const igual = texto.indexOf("=");
    if (igual === -1) continue;
    const clave = texto.slice(0, igual).trim();
    let valor = texto.slice(igual + 1).trim();
    if (valor.length >= 2) {
      const primera = valor[0];
      const ultima = valor[valor.length - 1];
      if ((primera === '"' || primera === "'") && primera === ultima) {
        valor = valor.slice(1, -1);
      } else {
        valor = recortarComentarioEnLinea(valor);
      }
    } else {
      valor = recortarComentarioEnLinea(valor);
    }
    out[clave] = valor;
  }
  return out;
}

/** Elimina un comentario en línea "# ..." precedido de espacio en blanco. */
function recortarComentarioEnLinea(valor) {
  const inicio = valor.indexOf("#");
  if (inicio > 0 && /\s/.test(valor[inicio - 1])) {
    return valor.slice(0, inicio).trimEnd();
  }
  return valor;
}

/** Convierte a entero o devuelve el valor por defecto. */
export const entero = (valor, porDefecto) => {
  const n = Number.parseInt(valor ?? "", 10);
  return Number.isFinite(n) ? n : porDefecto;
};

/** Construye la configuración tipada. Lanza Error si falta algo obligatorio. */
export function construirEnv(src = process.env) {
  const obligatorias = ["DB_USER", "DB_NAME", "JWT_SECRET"];
  const faltantes = obligatorias.filter((k) => !src[k]);
  if (faltantes.length) {
    throw new Error(
      `Faltan variables de entorno obligatorias: ${faltantes.join(", ")} (modelo en backend/.env.example)`
    );
  }
  const NODE_ENV = src.NODE_ENV || "development";
  if (NODE_ENV === "production" && src.JWT_SECRET.length < 32) {
    throw new Error(
      "JWT_SECRET debe tener al menos 32 caracteres en producción"
    );
  }
  const origenes = (
    src.CORS_ORIGIN || "http://localhost:5173,http://localhost:5174"
  )
    .split(",")
    .map((s) => s.trim())
    .filter(Boolean);
  return {
    NODE_ENV,
    PORT: entero(src.PORT, 3000),
    DB_HOST: src.DB_HOST || "localhost",
    DB_PORT: entero(src.DB_PORT, 3306),
    DB_USER: src.DB_USER,
    DB_PASSWORD: src.DB_PASSWORD ?? "",
    DB_NAME: src.DB_NAME,
    CORS_ORIGINS: origenes,
    TRUST_PROXY: src.TRUST_PROXY ?? "0",
    JWT_SECRET: src.JWT_SECRET,
    JWT_EXPIRES_IN: src.JWT_EXPIRES_IN || "8h",
  };
}

// Controladores de autenticación y registro de usuarios.
import * as authService from "../services/authService.js";
import { validarDatosUsuario } from "../middleware/validation.js";
import { responder } from "../utils/responseHelper.js";
import { MSG } from "../utils/messages.js";

export const register = async (req, res) => {
  try {
    // Antes: `req.body` sin `?? {}` -> TypeError (500) si el cliente no enviaba JSON.
    const { claveAdmin, ...datos } = req.body ?? {};
    if (!claveAdmin)
      return responder(res, 422, MSG.CAMPOS_OBLIGATORIOS);

    if (!req.user)
      return responder(res, 401, MSG.TOKEN_REQUERIDO);

    const auth = await authService.verificarClaveUsuario({
      usuario_login: req.user.usuario_login,
      clave: claveAdmin,
    });
    // 403 y no 401: el front interpreta 401 como "sesión vencida" y cerraba la sesión del admin
    // cada vez que se equivocaba al escribir su clave.
    if (auth.status !== 200)
      return responder(res, 403, "Clave de administrador incorrecta");

    const invalido = validarDatosUsuario(datos);
    if (invalido) return responder(res, 422, invalido);
    
    const r = await authService.registrar(datos, req.user);
    responder(res, r.status, r.mensaje || r.error, r.body || (r.usuario ? {usuario: r.usuario} : {}));
  } catch (err) {
    console.error(err);
    responder(res, 500, MSG.ERROR_INTERNO);
  }
};

  try {
    await liberarMantenimientosExpirados();
    const { tipo, bloque, estado } = req.query;
    const { page, limit, offset } = paginar(req.query);
    const conds = [],
      params = [];
    if (tipo === "carro" || tipo === "moto") {
      conds.push(`tv.codigo = ?`);
      params.push(tipo);
    }
    if (bloque) {
      conds.push(`c.letra = ?`);
      params.push(String(bloque).toUpperCase());

    if (estado) {

      if (!filtro) return responder(res, 400, MSG.FORMATO_INVALIDO("Estado"));
      conds.push(filtro);

    const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";
    const rows = await query(
      `${SELECT_CELDA} ${where} ORDER BY c.letra, c.numero LIMIT ? OFFSET ?`,
      [...params, limit, offset],
    );
    const [{ total }] = await query(
      `SELECT COUNT(*) AS total FROM celdas c INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = c.id_tipo_vehiculo ${where}`,
      params,
    );
    return responder(res, 200, MSG.LISTADO("Celdas"), { rows, total: Number(total), page, limit });

    manejar(res, err, "Error al listar las celdas");
  }
};

export const crearCelda = async (req, res) => {
  try {
    const { letra, numero, id_tipo_vehiculo } = req.body ?? {};
    if (!letra || !numero || !id_tipo_vehiculo) {
      return responder(res, 422, MSG.CAMPOS_OBLIGATORIOS);
    }
    const letraNorm = String(letra).trim().toUpperCase();
    if (!/^[A-Z]$/.test(letraNorm))
      return responder(res, 422, MSG.FORMATO_INVALIDO("Bloque (A-Z)"));
    const n = Number(numero);
    if (!Number.isInteger(n) || n < 1)
      return responder(res, 422, "El numero de celda debe ser un entero mayor o igual a 1");

    const [tipo] = await query(
      `SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ?`,
      [id_tipo_vehiculo],
    );
    if (!tipo)
      return responder(res, 422, MSG.FORMATO_INVALIDO("Tipo de vehículo"));

    const max = limiteCeldas(tipo.codigo);
    if (max !== null) {
      const [{ total }] = await query(
        `SELECT COUNT(*) AS total FROM celdas WHERE id_tipo_vehiculo = ?`,
        [tipo.id_tipo_vehiculo],
      );
      if (Number(total) >= max)
        return responder(res, 400, MSG.LIMITE_ALCANZADO(max, tipo.codigo));
    }
    const r = await query(
      `INSERT INTO celdas (id_tipo_vehiculo, letra, numero) VALUES (?, ?, ?)`,
      [tipo.id_tipo_vehiculo, letraNorm, n],
    );
    const [celda] = await query(
      `SELECT id_celda, codigo, letra, numero, id_tipo_vehiculo, activa, en_mantenimiento FROM celdas WHERE id_celda = ?`,
      [r.insertId],
    );
    return responder(res, 201, MSG.CREADO("Celda"), { celda });
  } catch (err) {
    if (err.code === "ER_DUP_ENTRY")
      return responder(res, 409, MSG.DUPLICADO("Celda (Letra + Número)"));
    manejar(res, err, "Error al crear la celda");
  }
};

export const actualizarCelda = async (req, res) => {
  try {
    const idTipo = Number(req.body?.id_tipo_vehiculo);
    if (!Number.isInteger(idTipo) || idTipo < 1)
      return responder(res, 422, "El tipo de vehiculo es obligatorio");

    const [celda] = await query(
      `SELECT c.id_celda, c.id_tipo_vehiculo, ${SQL_OCUPADA} AS ocupada FROM celdas c WHERE c.id_celda = ?`,
      [req.params.id],
    );
    if (!celda) return responder(res, 404, MSG.NO_ENCONTRADO("Celda"));
    if (Number(celda.ocupada))
      return responder(res, 400, "No se puede cambiar el tipo de una celda ocupada");

    const [tipo] = await query(
      `SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ?`,
      [idTipo],
    );
    if (!tipo)
      return responder(res, 422, MSG.FORMATO_INVALIDO("Tipo de vehículo"));

    if (celda.id_tipo_vehiculo !== idTipo) {
      const max = limiteCeldas(tipo.codigo);
      const [{ total }] = await query(
        `SELECT COUNT(*) AS total FROM celdas WHERE id_tipo_vehiculo = ?`,
        [idTipo],
      );
      if (max !== null && Number(total) >= max) {
        return responder(res, 400, MSG.LIMITE_ALCANZADO(max, tipo.codigo));
      }
    }
    await query(`UPDATE celdas SET id_tipo_vehiculo = ? WHERE id_celda = ?`, [
      idTipo,
      req.params.id,
    ]);
    return responder(res, 200, MSG.ACTUALIZADO("Tipo de celda"));
  } catch (err) {
    manejar(res, err, "Error al actualizar la celda");
  }
};

/**
 * Intercambia el tipo de dos celdas libres.
 * BUG CRÍTICO corregido: antes se usaba query("START TRANSACTION") sobre el pool; cada query
 * puede salir por una conexión distinta, así que no había transacción y un fallo a mitad dejaba
 * dos celdas del mismo tipo. Ahora es una transacción real con FOR UPDATE (también evita carreras con un ingreso).
 */
export const intercambiarTipoCelda = async (req, res) => {
  const a = Number(req.body?.id_celda_1),
    b = Number(req.body?.id_celda_2);
  if (!Number.isInteger(a) || !Number.isInteger(b) || a < 1 || b < 1) {
    return responder(res, 422, "Ambos IDs de celda son obligatorios");
  }
  if (a === b)
    return responder(res, 422, "Debe elegir dos celdas distintas");
  try {
    await conTransaccion(async (conn) => {
      const [filas] = await conn.query(
        `SELECT c.id_celda, c.id_tipo_vehiculo, ${SQL_OCUPADA} AS ocupada FROM celdas c WHERE c.id_celda IN (?, ?) FOR UPDATE`,
        [a, b],
      );
      if (filas.length !== 2)
        throw new ErrorNegocio(404, "Una o ambas celdas no existen");
      const [c1, c2] = [
        filas.find((f) => f.id_celda === a),
        filas.find((f) => f.id_celda === b),
      ];
      if (Number(c1.ocupada) || Number(c2.ocupada))
        throw new ErrorNegocio(
          400,
          "No se pueden intercambiar tipos de celdas ocupadas",
        );
      if (c1.id_tipo_vehiculo === c2.id_tipo_vehiculo)
        throw new ErrorNegocio(400, "Las celdas ya son del mismo tipo");
      await conn.query(
        `UPDATE celdas SET id_tipo_vehiculo = ? WHERE id_celda = ?`,
        [c2.id_tipo_vehiculo, c1.id_celda],
      );
      await conn.query(
        `UPDATE celdas SET id_tipo_vehiculo = ? WHERE id_celda = ?`,
        [c1.id_tipo_vehiculo, c2.id_celda],
      );
    });
    return responder(res, 200, "Intercambio de tipos realizado correctamente");
  } catch (err) {
    manejar(res, err, "Error al realizar el intercambio");
  }
};

export const cambiarEstadoCelda = async (req, res) => {
  try {
    await liberarMantenimientosExpirados();
    const { activa, en_mantenimiento } = req.body ?? {};
    const [celda] = await query(
      `SELECT c.id_celda, c.activa, c.en_mantenimiento, ${SQL_OCUPADA} AS ocupada FROM celdas c WHERE c.id_celda = ?`,
      [req.params.id],
    );
    if (!celda) return responder(res, 404, MSG.NO_ENCONTRADO("Celda"));

    const cambios = [],
      params = [];
    if (typeof activa === "boolean") {
      // Nueva validación de aforo al activar una celda desactivada
      if (activa === true && celda.activa === 0) {
        const [tipo] = await query(
          `SELECT tv.codigo, tv.id_tipo_vehiculo FROM tipos_vehiculos tv
           INNER JOIN celdas c ON c.id_tipo_vehiculo = tv.id_tipo_vehiculo
           WHERE c.id_celda = ?`,
          [req.params.id]
        );
        const max = limiteCeldas(tipo.codigo);
        if (max !== null) {
          const [{ total }] = await query(
            `SELECT COUNT(*) AS total FROM celdas WHERE id_tipo_vehiculo = ? AND activa = TRUE`,
            [tipo.id_tipo_vehiculo]
          );
          if (Number(total) >= max) {
            return responder(res, 400, `No es posible habilitar esta celda: se ha alcanzado la capacidad máxima de ${max} celdas activas para ${tipo.codigo}s.`);
          }
        }
      }
      cambios.push(`activa = ?`);
      params.push(activa);
    }
    if (typeof en_mantenimiento === "boolean") {
      cambios.push(`en_mantenimiento = ?`);
      params.push(en_mantenimiento);
      if (en_mantenimiento) {
        const minutos = Number(
          req.body.minutos_mantenimiento ?? req.body.duracion_minutos ?? 60,
        );
        if (!Number.isFinite(minutos) || minutos < 1) {
          return responder(res, 422, "La duracion del mantenimiento debe ser mayor a 0 minutos");
        }
        cambios.push(
          `mantenimiento_hasta = DATE_ADD(UTC_TIMESTAMP(), INTERVAL ? MINUTE)`,
        );
        params.push(minutos);
      } else {
        cambios.push(`mantenimiento_hasta = NULL`);
      }
    }
    if (!cambios.length)
      return responder(res, 422, "Debe indicar activa y/o en_mantenimiento");

    const vaInactiva = typeof activa === "boolean" ? !activa : !celda.activa;
    const vaMant =
      typeof en_mantenimiento === "boolean"
        ? en_mantenimiento
        : !!celda.en_mantenimiento;
    if ((vaInactiva || vaMant) && Number(celda.ocupada)) {
      return responder(res, 400, "No se puede deshabilitar una celda ocupada. Registre la salida primero.");
    }
    await query(`UPDATE celdas SET ${cambios.join(", ")} WHERE id_celda = ?`, [
      ...params,
      req.params.id,
    ]);
    return responder(res, 200, MSG.ACTUALIZADO("Estado de la celda"));
  } catch (err) {
    manejar(res, err, "Error al actualizar el estado de la celda");
  }
};

export const eliminarCelda = async (req, res) => {
  try {
    const id = req.params.id;
    const [celda] = await query(
      `SELECT c.id_celda, ${SQL_OCUPADA} AS ocupada,
              EXISTS (SELECT 1 FROM accesos_vehiculos a WHERE a.id_celda = c.id_celda) AS historial
       FROM celdas c WHERE c.id_celda = ?`,
      [id],
    );
    if (!celda) return responder(res, 404, MSG.NO_ENCONTRADO("Celda"));
    if (Number(celda.ocupada))
      return responder(res, 409, "Acción bloqueada: la celda está actualmente ocupada por un vehículo.");
    if (Number(celda.historial))
      return responder(res, 409, "Acción bloqueada: existen registros históricos de ingresos y salidas vinculados a esta celda.");
    await query(`DELETE FROM celdas WHERE id_celda = ?`, [id]);
    return responder(res, 200, MSG.ELIMINADO("Celda"));
  } catch (err) {
    if (err.code === "ER_ROW_IS_REFERENCED_2")
      return responder(res, 400, "No se puede eliminar la celda porque tiene registros asociados");
    manejar(res, err, "Error al eliminar la celda");
  }
};

/** Resumen por tipo. Una sola consulta (antes dos con el CASE repetido 10 veces) y totales sumados en JS. */
export const resumenCeldas = async (_req, res) => {
  try {
    await liberarMantenimientosExpirados();
    const filas = await query(
      `SELECT tipo, COUNT(*) AS total,
              SUM(estado = 'libre') AS libres, SUM(estado = 'ocupada') AS ocupadas,
              SUM(estado IN ('inactiva','en mantenimiento')) AS no_disponibles
       FROM (SELECT tv.codigo AS tipo, ${ESTADO_SQL} AS estado
             FROM celdas c INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = c.id_tipo_vehiculo) t
       GROUP BY tipo ORDER BY tipo`,
    );
    const porTipo = filas.map((f) => ({
      tipo: f.tipo,
      total: Number(f.total),
      libres: Number(f.libres),
      asignadas: 0,
      ocupadas: Number(f.ocupadas),
      no_disponibles: Number(f.no_disponibles),
    }));
    const suma = (k) => porTipo.reduce((s, f) => s + f[k], 0);
    return responder(res, 200, MSG.RESUMEN("Celdas"), {
      porTipo,
      totales: {
        total: suma("total"),
        libres: suma("libres"),
        asignadas: 0,
        ocupadas: suma("ocupadas"),
        no_disponibles: suma("no_disponibles"),
      },
    });
  } catch (err) {
    manejar(res, err, "Error al generar el resumen de celdas");
  }
};

    if (!v) return responder(res, 404, MSG.NO_ENCONTRADO("Vehículo"));

    const [vigente = null] = await query(SQL_ULTIMA_MENSUALIDAD, [
      v.id_vehiculo,
    ]);
    const estado = derivarEstado(vigente);
    const plan = planificarPeriodo(vigente, hoyBogota());

    // Verificar si ya existe el siguiente periodo pagado
    let siguientePagado = false;
    if (vigente) {
      const [s] = await query(
        `SELECT 1 FROM mensualidades
         WHERE id_vehiculo = ? AND estado <> 'cancelada' AND fecha_inicio > ? LIMIT 1`,
        [v.id_vehiculo, aYMD(vigente.fecha_fin)],
      );
      siguientePagado = !!s;
    }

    const ocupados = await svc.contarOcupados(pool, v.id_tipo_vehiculo);
    const max = CUPOS_POR_TIPO[v.tipo_codigo] ?? null;
    const hayCupo = max === null || plan.esRenovacion || ocupados < max;

    let motivo = null;
    if (siguientePagado) motivo = "El vehículo ya tiene confirmado el siguiente periodo.";
    else if (!plan.puedePagar)
      motivo = `Mensualidad vigente: podrá renovar cuando falten ${DIAS_ANTICIPACION_MAX} días o menos (faltan ${plan.diasRestantes}).`;
    else if (!hayCupo) motivo = `No hay cupo disponible para ${v.tipo}.`;

    return responder(res, 200, "Previsualización del pago", {
      placa: v.placa,
      propietario: v.propietario,
      tipo: v.tipo,
      valor: Number(v.tarifa_mensual),
      periodo: { inicio: plan.inicio, fin: plan.fin },
      es_renovacion: plan.esRenovacion,
      puede_pagar: !siguientePagado && plan.puedePagar && hayCupo,
      motivo_bloqueo: motivo,
      dias_restantes: plan.diasRestantes,
      estado_actual: estado,
      hay_cupo: hayCupo,
      cupo: { ocupados, max },
    });
  } catch (err) {
    manejar(res, err, "Error al previsualizar el pago");
  }
};

export const listarMensualidades = async (req, res) => {
  try {
    const { page, limit, offset } = paginar(req.query, { porDefecto: 10 });
    const { q, estado, tipo } = req.query;

    if (estado && !Object.values(ESTADO_MENSUALIDAD).includes(estado))
      return responder(res, 422, MSG.FORMATO_INVALIDO("Estado"));
    if (tipo && !["carro", "moto"].includes(tipo))
      return responder(res, 422, MSG.FORMATO_INVALIDO("Tipo"));

    const conds = [`v.activo = TRUE`];
    const params = [];
    if (q) {
      conds.push(`(v.placa LIKE ? OR v.propietario_documento LIKE ?)`);
      const s = likeSeguro(q);
      params.push(s, s);
    }
    if (tipo === "carro" || tipo === "moto") {
      conds.push(`tv.codigo = ?`);
      params.push(tipo);
    }
    const where = `WHERE ${conds.join(" AND ")}`;

    // Obtener TODAS las mensualidades por vehículo (no solo la "vigente" SQL)
    // para poder elegir la correcta en JS (elegirVigente considera renovación anticipada).
    const sql = `
      SELECT v.id_vehiculo, v.placa, v.propietario_nombre AS propietario,
             v.propietario_documento AS documento,
             tv.codigo AS tipo_codigo, tv.nombre AS tipo,
             tv.tarifa_mensual AS valor,
             m.id_mensualidad, m.fecha_inicio, m.fecha_fin, m.estado AS estado_bd,
             (SELECT COUNT(*) FROM accesos_vehiculos a WHERE a.id_vehiculo = v.id_vehiculo AND a.fecha_salida IS NULL) AS dentro
      FROM vehiculos v
      INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
      LEFT JOIN mensualidades m ON m.id_vehiculo = v.id_vehiculo AND m.estado <> 'cancelada'
      ${where}
      ORDER BY v.placa, m.fecha_inicio DESC`;

    const rows = await query(sql, params);

    const hoy = hoyBogota();
    // Agrupar por vehículo y elegir la vigente con elegirVigente (considera renovación anticipada)
    const byVehicle = new Map();
    for (const r of rows) {
      const key = r.id_vehiculo;
      if (!byVehicle.has(key)) {
        byVehicle.set(key, {
          vehiculo: {
            id_vehiculo: r.id_vehiculo,
            placa: r.placa,
            propietario: r.propietario,
            documento: r.documento,
            tipo: r.tipo,
            tipo_codigo: r.tipo_codigo,
            valor: r.valor,
            dentro: !!r.dentro,
          },
          mensualidades: [],
        });
      }
      if (r.id_mensualidad) {
        byVehicle.get(key).mensualidades.push({
          id_mensualidad: r.id_mensualidad,
          fecha_inicio: aYMD(r.fecha_inicio),
          fecha_fin: aYMD(r.fecha_fin),
          estado: r.estado_bd,
          valor: r.valor,
        });
      }
    }

    // Calcular ocupados por tipo para cupo (RF06.6)
    const ocupados = await ocupadosPorTipo(pool);
    const { AL_DIA, PENDIENTE, SIN_MENSUALIDAD } = ESTADO_MENSUALIDAD;

    let data = [];
    for (const [, group] of byVehicle) {
      const { vigente, estado, fechaFin, siguientePagado } = estadoEfectivo(group.mensualidades, hoy);
      const dias = fechaFin ? diasParaVencer(fechaFin, hoy) : null;
      const tipoCodigo = group.vehiculo.tipo_codigo;

      const esNuevo = estado === SIN_MENSUALIDAD;
      const puedeRenovar =
        !siguientePagado &&
        (estado === PENDIENTE || (estado === AL_DIA && dias !== null && dias <= DIAS_ANTICIPACION_MAX));
      const sinCupo = esNuevo && (ocupados[tipoCodigo] ?? 0) >= (CUPOS_POR_TIPO[tipoCodigo] ?? Infinity);

      data.push({
        id_vehiculo: group.vehiculo.id_vehiculo,
        placa: group.vehiculo.placa,
        propietario: group.vehiculo.propietario,
        documento: group.vehiculo.documento,
        tipo: group.vehiculo.tipo,
        tipo_codigo: group.vehiculo.tipo_codigo,
        estado,
        valor: group.vehiculo.valor,
        fecha_vencimiento: fechaFin,
        dias_para_vencer: dias,
        siguiente_pagado: siguientePagado,
        puede_renovar: puedeRenovar,
        sin_cupo: sinCupo,
        puede_pagar: (esNuevo || puedeRenovar) && !sinCupo,
        id_mensualidad: vigente ? vigente.id_mensualidad : null,
        dentro: group.vehiculo.dentro,
      });
    }

    const prioridad = (d) => (d.puede_renovar ? 1 : d.estado === AL_DIA ? 2 : 3);
    data.sort((a, b) => prioridad(a) - prioridad(b) || a.placa.localeCompare(b.placa));

    let total;
    if (estado) {
      data = data.filter((d) => d.estado === estado);
      total = data.length;
    } else {
      total = data.length;
    }

    // Paginar siempre en memoria para respetar el orden de prioridad global
    data = data.slice(offset, offset + limit);

    return responder(res, 200, MSG.LISTADO("Mensualidades"), {
      rows: data,
      total,
      page,
      limit,
    });
  } catch (err) {
    manejar(res, err, "Error al listar las mensualidades");
  }
};

/** Resumen por tipo (RF06.4). */
export const resumenMensualidades = async (_req, res) => {
  try {
    // Obtener TODAS las mensualidades por vehículo para resumen correcto
    const rows = await query(
      `SELECT tv.codigo AS tipo, v.id_vehiculo,
              m.fecha_inicio, m.fecha_fin, m.estado AS estado_bd, m.id_mensualidad, m.valor
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       LEFT JOIN mensualidades m ON m.id_vehiculo = v.id_vehiculo AND m.estado <> 'cancelada'
       WHERE v.activo = TRUE`,
    );

    const hoy = hoyBogota();
    const byVehicle = new Map();
    for (const r of rows) {
      const key = r.id_vehiculo;
      if (!byVehicle.has(key)) {
        byVehicle.set(key, {
          tipo: r.tipo,
          mensualidades: [],
        });
      }
      if (r.id_mensualidad) {
        byVehicle.get(key).mensualidades.push({
          id_mensualidad: r.id_mensualidad,
          fecha_inicio: aYMD(r.fecha_inicio),
          fecha_fin: aYMD(r.fecha_fin),
          estado: r.estado_bd,
          valor: r.valor,
        });
      }
    }

    const acc = {};
    // Inicializar siempre ambos tipos (RF06.4)
    for (const [tipo, cap] of Object.entries(CUPOS_POR_TIPO)) {
      acc[tipo] = { tipo, al_dia: 0, pendiente: 0, sin_mensualidad: 0, ocupados: 0, capacidad: cap };
    }
    for (const [, group] of byVehicle) {
      const { estado } = estadoEfectivo(group.mensualidades, hoy);
      if (estado === ESTADO_MENSUALIDAD.AL_DIA) acc[group.tipo].al_dia++;
      else if (estado === ESTADO_MENSUALIDAD.PENDIENTE) acc[group.tipo].pendiente++;
      else acc[group.tipo].sin_mensualidad++;
      if (estado !== ESTADO_MENSUALIDAD.SIN_MENSUALIDAD) acc[group.tipo].ocupados++;
    }
    return responder(res, 200, MSG.RESUMEN("Mensualidades"), {
      porTipo: Object.values(acc),
    });
  } catch (err) {
    manejar(res, err, "Error al generar el resumen");
  }
};

       WHERE v.placa = ? LIMIT 1`,
      [f.placa],
    );
    if (!v) return responder(res, 404, MSG.NO_ENCONTRADO("Vehículo"));

    const mensualidadesBD = await query(
      `SELECT m.id_mensualidad, m.fecha_inicio, m.fecha_fin, m.estado, m.valor,
              m.fecha_creacion AS fecha_registro
       FROM mensualidades m WHERE m.id_vehiculo = ?
       ORDER BY m.fecha_inicio DESC`,
      [v.id_vehiculo],
    );

      ...m,
      fecha_inicio: aYMD(m.fecha_inicio),
      fecha_fin: aYMD(m.fecha_fin),
      estado: m.estado === "cancelada" ? "cancelada" : estadoFila(m, mensualidadesBD, hoy),
    }));

    const { vigente, estado } = estadoEfectivo(mensualidadesBD, hoy);

    const proximoBD = mensualidadesBD
      .filter((m) => m.estado !== "cancelada"
        && aYMD(m.fecha_inicio) > hoy
        && m.id_mensualidad !== vigente?.id_mensualidad)
      .sort((a, b) => aYMD(a.fecha_inicio).localeCompare(aYMD(b.fecha_inicio)))[0];
    const proximo_periodo = proximoBD
      ? { id_mensualidad: proximoBD.id_mensualidad, fecha_inicio: aYMD(proximoBD.fecha_inicio),
          fecha_fin: aYMD(proximoBD.fecha_fin), valor: proximoBD.valor }
      : null;

      `SELECT p.id_pago, p.fecha_pago, p.monto,
              m.fecha_inicio AS periodo_inicio, m.fecha_fin AS periodo_fin,
              u.nombres AS operador_nombres, u.apellidos AS operador_apellidos
       FROM pagos p
       INNER JOIN mensualidades m ON m.id_mensualidad = p.id_mensualidad
       LEFT JOIN usuarios u ON u.id_usuario = p.id_usuario
       WHERE m.id_vehiculo = ?
       ORDER BY p.fecha_pago DESC`,
      [v.id_vehiculo],
    );
    const pagos = pagosBD.map((p) => ({
      ...p,
      periodo_inicio: aYMD(p.periodo_inicio),
      periodo_fin: aYMD(p.periodo_fin),
    }));

    let actual = null;
    if (vigente && estado !== ESTADO_MENSUALIDAD.SIN_MENSUALIDAD) {
      const [p] = await query(
        `SELECT u.usuario_login FROM pagos p 
         INNER JOIN usuarios u ON u.id_usuario = p.id_usuario 
         WHERE p.id_mensualidad = ? LIMIT 1`,
        [vigente.id_mensualidad]
      );
      actual = {
        id_mensualidad: vigente.id_mensualidad,
        fecha_inicio: aYMD(vigente.fecha_inicio),
        fecha_fin: aYMD(vigente.fecha_fin),
        valor: vigente.valor,
        estado,
        confirmador: p?.usuario_login ?? "sistema",
      };
    }

    return responder(res, 200, MSG.ENCONTRADO("Mensualidad"), {
      vehiculo: { ...v, estado },
      mensualidad_actual: actual,
      proximo_periodo,
      historial_mensualidades: mensualidades,
      historial_pagos: pagos,
    });
  } catch (err) {
    manejar(res, err, "Error al obtener el detalle");
  }
};

const SQL_AUDIT = `INSERT INTO audit_log (id_usuario, usuario_login, accion, recurso, detalle, ip_address) VALUES (?, ?, ?, 'accesos_vehiculos', ?, ?)`;

/** Rechazos se auditan FUERA de la transacción para que el rollback no los borre. */

const auditar = async (conn, req, accion, detalle) => {

/** Ejecuta `trabajo(conn)` en transacción y traduce errores a HTTP. */
async function ejecutar(req, res, trabajo, ctx = {}) {
  const conn = await pool.getConnection();
  try {
    await conn.beginTransaction();
    const { status, body } = await trabajo(conn);
    await conn.commit();
    return responder(res, status, body.mensaje ?? "Operación exitosa", body);
  } catch (err) {
    try {
      await conn.rollback();
    } catch {
      /* conexión cerrada */
    }
    if (err instanceof ErrorNegocio) {
      await auditarRechazo(req, ctx, err.message);
      return responder(res, err.status, err.message);
    }
    if (err.code === "ER_DUP_ENTRY") {
      const msg = String(err.message).includes("uq_acceso_celda_ocupada")
        ? "La celda ya no está disponible"
        : MSG.VEHICULO_DENTRO;
      await auditarRechazo(req, ctx, msg);
      return responder(res, 409, msg);
    }
    console.error("Error en movimiento:", err);
    responder(res, 500, MSG.ERROR_INTERNO);
  } finally {
    conn.release();
  }
}

export const registrarEntrada = (req, res) => {
  const { placa, id_celda } = req.body ?? {};
  if (!placa || !id_celda)
    return responder(res, 422, "Placa y celda requeridos");

  return ejecutar(
    req,
    res,
    async (conn) => {
      const formato = validarPlaca(placa);
      if (!formato.valida) throw new ErrorNegocio(422, formato.error);

      const [vehiculos] = await conn.query(
        `SELECT v.id_vehiculo, v.placa, v.id_tipo_vehiculo, tv.nombre AS tipo, tv.codigo AS tipo_codigo
       FROM vehiculos v INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       WHERE v.placa = ? AND v.activo = TRUE LIMIT 1`,
        [formato.placa],
      );
      if (!vehiculos.length)
        throw new ErrorNegocio(404, MSG.NO_ENCONTRADO("Vehículo"));
      const v = vehiculos[0];
      if (!validarPlaca(v.placa, v.tipo_codigo).valida) {
        throw new ErrorNegocio(
          422,
          `La placa ${v.placa} no tiene el formato válido para ${v.tipo}`,
        );
      }

      const [dentro] = await conn.query(
        `SELECT id_acceso FROM accesos_vehiculos WHERE id_vehiculo = ? AND fecha_salida IS NULL LIMIT 1`,
        [v.id_vehiculo],
      );
      if (dentro.length) throw new ErrorNegocio(400, MSG.VEHICULO_DENTRO);

      await liberarMantenimientosExpirados(conn);

      // Consultar todas las mensualidades del vehículo para obtener el estado efectivo
      const [mensualidades] = await conn.query(
        `SELECT id_mensualidad, fecha_inicio, fecha_fin, estado
         FROM mensualidades
         WHERE id_vehiculo = ? AND estado <> 'cancelada'`,
        [v.id_vehiculo],
      );
      const { estado: estadoM } = estadoEfectivo(mensualidades, hoyBogota());
      if (!puedeIngresar(estadoM))
        throw new ErrorNegocio(403, MENSAJE_BLOQUEO[estadoM] ?? "Vehículo sin mensualidad válida");

      const [celdas] = await conn.query(
        `SELECT id_celda, codigo, id_tipo_vehiculo FROM celdas WHERE id_celda = ? AND activa = TRUE AND en_mantenimiento = FALSE LIMIT 1 FOR UPDATE`,
        [id_celda],
      );
      if (!celdas.length) throw new ErrorNegocio(409, "La celda ya no está disponible");
      const c = celdas[0];
      if (c.id_tipo_vehiculo !== v.id_tipo_vehiculo)
        throw new ErrorNegocio(
          422,
          "La celda no es compatible con el tipo de vehículo",
        );

      const [ocupada] = await conn.query(
        `SELECT id_acceso FROM accesos_vehiculos WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,
        [c.id_celda],
      );
      if (ocupada.length) throw new ErrorNegocio(409, "La celda ya no está disponible");

      const { idOperador, idTurno } = await operadorYTurno(
        conn,
        req.user?.id_usuario,
      );
      const idPuerta = await puertaActiva(conn);
      const [r] = await conn.query(
        `INSERT INTO accesos_vehiculos (id_vehiculo, id_celda, id_puerta_ingreso, id_operador_ingreso, id_turno_ingreso) VALUES (?, ?, ?, ?, ?)`,
        [v.id_vehiculo, c.id_celda, idPuerta, idOperador, idTurno],
      );

      await auditar(
        conn,
        req,
        "entrada",
        `Vehículo ${v.placa} ingresó a celda ${c.codigo}`,
      );
      return {
        status: 201,
        body: {
          id: r.insertId,
          placa: v.placa,
          tipo: v.tipo,
          celda: c.codigo,
          accion: "entrada",
          mensaje: "Entrada registrada correctamente",
          ...formatearFechaHora(),
        },
      };
    },
    { accion: "entrada", placa },
  );
};

  if (!Number.isInteger(idAcceso) || idAcceso < 1)

  if (!Number.isInteger(idCelda) || idCelda < 1)
    return responder(res, 422, "Celda requerida");

          422,
          "La celda no existe, no está habilitada o no es del tipo del vehículo",

      const [ocupada] = await conn.query(
        `SELECT id_acceso FROM accesos_vehiculos WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,

export const listarAccesos = async (req, res) => {
  try {
    const { page, limit, offset } = paginar(req.query);
    const placa = String(req.query.placa ?? "")
      .trim()
      .toUpperCase();
    const celda = String(req.query.celda ?? "")
      .trim()
      .toUpperCase();
    const operador = String(req.query.operador ?? "").trim();
    const estado = String(req.query.estado ?? "")
      .trim()
      .toLowerCase();
    const desde = String(req.query.fecha_desde ?? "").trim();
    const hasta = String(req.query.fecha_hasta ?? "").trim();
    for (const f of [desde, hasta]) {
      if (f && !FECHA_ISO.test(f))
        return responder(res, 422, "Las fechas deben tener formato AAAA-MM-DD");
    }

    const conds = [],
      params = [];
    if (placa) {
      conds.push(`v.placa LIKE ?`);
      params.push(likeSeguro(placa));
    }
    if (celda) {
      conds.push(`c.codigo LIKE ?`);
      params.push(likeSeguro(celda));
    }
    if (operador) {
      conds.push(
        `(ui.nombres LIKE ? OR ui.apellidos LIKE ? OR us.nombres LIKE ? OR us.apellidos LIKE ?)`,
      );
      const like = likeSeguro(operador);
      params.push(like, like, like, like);
    }
    if (estado === "adentro" || estado === "fuera") {
      conds.push(
        estado === "adentro"
          ? `a.fecha_salida IS NULL`
          : `a.fecha_salida IS NOT NULL`,
      );
      conds.push(
        `a.id_acceso = (SELECT MAX(a2.id_acceso) FROM accesos_vehiculos a2 WHERE a2.id_vehiculo = a.id_vehiculo)`,
      );
    }
    if (desde) {
      conds.push(`${sqlFechaBogota("a.fecha_ingreso")} >= ?`);
      params.push(desde);
    }
    if (hasta) {
      conds.push(`${sqlFechaBogota("a.fecha_ingreso")} <= ?`);
      params.push(hasta);
    }

    const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";
    const FROM = `FROM accesos_vehiculos a
      INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
      INNER JOIN celdas c ON c.id_celda = a.id_celda
      INNER JOIN usuarios ui ON ui.id_usuario = a.id_operador_ingreso
      LEFT JOIN usuarios us ON us.id_usuario = a.id_operador_salida ${where}`;

    const [rows] = await pool.query(
      `SELECT a.id_acceso, v.placa, v.propietario_nombre, c.codigo AS celda,
              ui.nombres AS operador_ingreso_nombres, ui.apellidos AS operador_ingreso_apellidos,
              us.nombres AS operador_salida_nombres, us.apellidos AS operador_salida_apellidos, a.fecha_ingreso, a.fecha_salida
       ${FROM} ORDER BY a.fecha_ingreso DESC LIMIT ? OFFSET ?`,
      [...params, limit, offset],
    );
    const [[{ total }]] = await pool.query(
      `SELECT COUNT(*) AS total ${FROM}`,
      params,
    );
    return responder(res, 200, MSG.LISTADO("Historial de accesos"), { rows, total: Number(total), page, limit });
  } catch (err) {
    console.error(err);
    responder(res, 500, MSG.ERROR_INTERNO);
  }
};

export default {
  registrarEntrada,
  registrarSalida,
  listarDentro,
  registrarReubicacion,
  listarAccesos,
};

/** Re-autenticación con la clave del admin. Devuelve {status,error} o null si es válida. */
const verificarClaveAdmin = async (req, claveAdmin) => {
  if (!claveAdmin)
    return {
      status: 422,
      error: MSG.CAMPOS_OBLIGATORIOS,
    };
  const r = await authService.verificarClaveUsuario({
    usuario_login: req.user.usuario_login,
    clave: claveAdmin,
  });
  return r.error ? r : null;
};

export const actualizar = async (req, res) => {
  try {
    const id = Number(req.params.id);
    const { estado: _ignorado, claveAdmin, ...datos } = req.body ?? {};
    const verif = await verificarClaveAdmin(req, claveAdmin);
    if (verif)
      return responder(res, verif.status === 400 ? 403 : verif.status, verif.error);
    if (id === req.user.id_usuario && datos.rol && datos.rol !== req.user.rol) {
      return responder(res, 400, "No puede cambiar su propio rol");
    }
    const r = await userService.editarUsuario(id, datos);
    if (r.status === 200)
      await auditar(req, "EDIT_USER", `Usuario ${id} actualizado`);
    if (r.error) return responder(res, r.status, r.error);
    return responder(res, 200, r.body.mensaje, r.body);
  } catch (err) {
    console.error(err);
    responder(res, 500, MSG.ERROR_INTERNO);
  }
};

    const r = await userService.cambiarEstadoUsuario(id, estado);

      await auditar(

        `Usuario ${id} -> ${estado}`,
      );
    if (r.error) return responder(res, r.status, r.error);
    return responder(res, 200, r.body.mensaje);
  } catch (err) {
    console.error(err);
    responder(res, 500, MSG.ERROR_INTERNO);
  }
};

    const formato = validarPlaca(b.placa);
    if (!formato.valida) return responder(res, 422, formato.error);

      "id_tipo_vehiculo",
      "color",
      "modelo",
      "nombre_modelo",
      "propietario_nombre",
      "propietario_documento",
    ].filter(
      (k) => b[k] === undefined || b[k] === null || String(b[k]).trim() === "",
    );
    if (faltan.length)
      return responder(res, 422, `Campos obligatorios faltantes: ${faltan.join(", ")}`);

    const tipoDoc = b.propietario_tipo_documento ?? "cc";
    if (!VALID_TIPOS_DOCUMENTO.includes(tipoDoc))

    const anioActual = new Date().getFullYear();
    if (!anio || anio < 1930 || anio > anioActual)
      return responder(res, 422, `El año debe estar entre 1930 y ${anioActual}.`);

    const [tipo] = await query(
      `SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ?`,
      [b.id_tipo_vehiculo],
    );
    if (!tipo)
      return responder(res, 422, "Tipo de vehículo inválido");
    const porTipo = validarPlaca(b.placa, tipo.codigo);
    if (!porTipo.valida) return responder(res, 422, porTipo.error);

    // BUG CRÍTICO corregido: el INSERT tenía `NULL` literal para el email y solo 9 placeholders,
    // pero se pasaban 10 parámetros -> "Incorrect arguments" en TODA creación de vehículos. Y el email nunca se guardaba.
    const r = await query(
      `INSERT INTO vehiculos (id_tipo_vehiculo, placa, color, modelo, nombre_modelo, propietario_nombre,

// Autenticación JWT (HS256) + estado del usuario.
import jwt from "jsonwebtoken";
import crypto from "node:crypto";
import { env } from "../config/envLoader.js";
import { query } from "../config/db.js";
import * as revokedTokenRepository from "../repositories/revokedTokenRepository.js";
import { responder } from "../utils/responseHelper.js";
import { MSG } from "../utils/messages.js";

const ALGORITMO = "HS256";

export const generarToken = (idUsuario) =>
  jwt.sign(
    { id_usuario: idUsuario, jti: crypto.randomUUID() },
    env.JWT_SECRET,
    {
      expiresIn: env.JWT_EXPIRES_IN,
      algorithm: ALGORITMO,
    },
  );

export const verificarToken = (token) =>
  jwt.verify(token, env.JWT_SECRET, { algorithms: [ALGORITMO] });

/** "Bearer xxx" -> "xxx" | null */
export function extraerBearer(header = "") {
  const partes = String(header).split(" ");
  if (partes.length !== 2 || partes[0].toLowerCase() !== "bearer" || !partes[1])
    return null;
  return partes[1];
}

export const autenticar = async (req, res, next) => {
  try {
    const token = extraerBearer(req.headers.authorization);
    if (!token)
      return responder(res, 401, MSG.TOKEN_REQUERIDO);

    const decoded = verificarToken(token);
    if (
      decoded.jti &&
      (await revokedTokenRepository.estaRevocado(decoded.jti))
    ) {
      return responder(res, 401, "Token revocado o sesión cerrada");
    }

    // Incluye email y telefono: /auth/me los devolvía siempre como undefined.
    const [u] = await query(
      `SELECT id_usuario, usuario_login, rol, nombres, apellidos, email, telefono, estado
       FROM usuarios WHERE id_usuario = ?`,
      [decoded.id_usuario],
    );
    if (!u) return responder(res, 401, "Usuario no encontrado");
    if (u.estado !== "activo") {
      return responder(res, 403, "Usuario inactivo. No puede iniciar sesión.");
    }

    req.user = { ...u, nombreCompleto: `${u.nombres} ${u.apellidos}` };
    next();
  } catch (err) {
    if (err.name === "TokenExpiredError") {
      return responder(res, 401, MSG.SESION_EXPIRADA);
    }
    if (err.name === "JsonWebTokenError" || err.name === "NotBeforeError") {
      return responder(res, 401, "Token inválido");
    }
    next(err);
  }
};

export default { autenticar, generarToken, verificarToken, extraerBearer };

// Validación de cuerpo para rutas de usuarios (única fuente; authService ya no la repite).
export const REQUIRED_USER_FIELDS = [
  "rol",
  "tipo_documento",
  "documento",
  "nombres",
  "apellidos",
  "usuario_login",
  "clave",
];
export const VALID_ROLES = ["administrador", "operador"];
export const VALID_TIPOS_DOCUMENTO = ["cc", "ce", "nit", "pasaporte"];
const EMAIL = /^[^\s@]+@[^\s@.]+\.[^\s@]+$/;

export const validarClave = (clave) =>
  !clave || String(clave).length < 4
    ? "La clave debe tener al menos 4 caracteres"
    : null;

export const validarDatosUsuario = (body, { requiereClave = true } = {}) => {
  if (!body || typeof body !== "object") return "Cuerpo de solicitud inválido";
  const obligatorios = requiereClave
    ? REQUIRED_USER_FIELDS
    : REQUIRED_USER_FIELDS.filter((c) => c !== "clave");
  for (const campo of obligatorios) {
    const v = body[campo];
    if (v === undefined || v === null || String(v).trim() === "")
      return `El campo "${campo}" es obligatorio`;
  }
  if (!VALID_ROLES.includes(body.rol))
    return "Rol no reconocido. Los valores permitidos son: 'administrador' u 'operador'.";
  if (!VALID_TIPOS_DOCUMENTO.includes(body.tipo_documento)) {
    return "Tipo de documento no reconocido. Use: 'cc', 'ce', 'nit' o 'pasaporte'.";
  }
  const doc = String(body.documento).length;
  if (doc < 5 || doc > 20)
    return "La longitud del documento debe estar entre 5 y 20 caracteres.";
  if (String(body.usuario_login).length < 3)
    return "El usuario de acceso debe tener al menos 3 caracteres.";
  if (requiereClave) {
    const e = validarClave(body.clave);
    if (e) return e;
  }
  if (body.email && !EMAIL.test(String(body.email)))
    return "El correo electrónico no tiene un formato válido";
  return null;
};

const placaCarro = (n) => `CAR${String(n).padStart(3, "0")}`;

/** Inicio de un periodo cuyo fin (inicio + 1 mes - 1 día) sea exactamente `fin`. */
function inicioParaFin(fin) {
  for (let d = 27; d <= 31; d++) {
    const ini = sumarDias(fin, -d);
    if (calcularFin(ini) === fin) return ini;
  }
  return sumarDias(fin, -29);
}

/**
 * Escenarios de demostración por placa (offset de días del fin respecto a hoy).
 *  - al_dia:    vigente con más de 5 días (no puede renovar todavía)
 *  - proximo:   faltan 1..4 días (dentro de la ventana de renovación)
 *  - pendiente: hoy es el último día pagado (aún puede entrar)
 *  - vencida:   venció hace 10 días (Sin mensualidad)
 *  - renovada:  vigente + siguiente periodo ya confirmado
 * El resto de vehículos queda "Sin mensualidad".
 */
function escenarios() {
  const e = [];
  for (let i = 1; i <= 20; i++) e.push([placaCarro(i), "al_dia", 8 + (i % 20)]);
  for (let i = 21; i <= 23; i++) e.push([placaCarro(i), "proximo", i - 20]);
  e.push([placaCarro(24), "pendiente", 0]);
  e.push([placaCarro(25), "vencida", -10]);
  e.push([placaCarro(26), "vencida", -10]);
  e.push([placaCarro(27), "renovada", 3]);
  for (let i = 1; i <= 5; i++) e.push([placaMoto(i), "al_dia", 8 + i * 3]);
  e.push([placaMoto(6), "proximo", 2]);
  e.push([placaMoto(7), "vencida", -10]);
  return e;
}

async function vaciarBase(conn) {
  await conn.query("SET FOREIGN_KEY_CHECKS = 0");
  try {
    for (const tabla of TABLAS) await conn.query(`TRUNCATE TABLE \`${tabla}\``);
  } finally {
    await conn.query("SET FOREIGN_KEY_CHECKS = 1");
  }
}

async function crearUsuarios(conn) {
  const usuarios = [];

  // 1. Admin principal (siempre presente)
  usuarios.push([
    "administrador",
    "cc",
    "1000000000",
    "Administrador",
    "Principal",
    "3000000000",
    "admin@autoscolombia.com",
    "admin",
    await bcrypt.hash("123456", 10),
  ]);

  // 2. Operador principal (siempre presente)
  usuarios.push([
    "operador",
    "cc",
    "1000000001",
    "Operador",
    "Principal",
    "3000000001",
    "operador@autoscolombia.com",
    "operador",
    await bcrypt.hash("123456", 10),
  ]);

  // 3. 10 usuarios adicionales alternando roles válidos
  for (let i = 0; i < 10; i++) {
    const rol = ROLES_VALIDOS[i % ROLES_VALIDOS.length];
    const idx = i + 2; // índice global 2..11
    const nombre = NOMBRES[idx % NOMBRES.length];
    const apellido = APELLIDOS[idx % APELLIDOS.length];
    const usuarioLogin = `${rol.substring(0, 3)}${idx + 1}`;
    usuarios.push([
      rol,
      "cc",
      String(1000000000 + idx),
      nombre,
      apellido,
      `300${String(idx).padStart(7, "0")}`,
      `${nombre.toLowerCase()}.${apellido.toLowerCase()}${idx}@autoscolombia.com`,
      usuarioLogin,
      await bcrypt.hash("123456", 10),
    ]);
  }

  await conn.query(
    `INSERT INTO usuarios (rol, tipo_documento, documento, nombres, apellidos, telefono, email, usuario_login, clave_hash) 
     VALUES ?`,
    [usuarios],
  );
  console.log(
    "Usuarios staff creados: 12 (1 admin + 1 operador principal + 10 adicionales)",
  );
}

async function main() {
  const reset = process.argv.includes("--reset");
  const conn = await pool.getConnection();
  try {
    if (reset) {
      await vaciarBase(conn);
    } else {
      const [checks] = await conn.query(
        "SELECT COUNT(*) as count FROM usuarios",
      );
      if (Number(checks[0].count) > 0) {
        console.log("La base ya tiene datos.");
        return;
      }
    }

    await conn.beginTransaction();

    await crearUsuarios(conn);

    // 1. Tipos de vehiculo
    await conn.query(
      `INSERT INTO tipos_vehiculos (codigo, nombre, tarifa_mensual)
       VALUES ('carro', 'Carro', 250000), ('moto', 'Moto', 100000)`,
    );
    const [tipos] = await conn.query(
      "SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos",
    );
    const idTipoCarro = tipos.find(
      (t) => t.codigo === "carro",
    ).id_tipo_vehiculo;
    const idTipoMoto = tipos.find((t) => t.codigo === "moto").id_tipo_vehiculo;

    // 2. Puertas
    await conn.query(
      `INSERT INTO puertas (nombre, ubicacion, disponible_nocturna, activa)
       VALUES ('Puerta 1', 'Principal', TRUE, TRUE), ('Puerta 2', 'Secundaria', FALSE, TRUE)`,
    );

    // 3. Celdas
    const celdas = [];
    for (const letra of ["A", "B", "C", "D", "E", "F", "G"]) {
      for (let n = 1; n <= 10; n++) celdas.push([idTipoCarro, letra, n]);
    }
    for (let n = 1; n <= 10; n++) celdas.push([idTipoMoto, "H", n]);
    await conn.query(
      "INSERT INTO celdas (id_tipo_vehiculo, letra, numero) VALUES ?",
      [celdas],
    );

    // 4. Vehiculos y Propietarios (algunos con doble vehiculo)
    const vehiculos = [];
    const propietarios = [];
    for (let i = 0; i < 50; i++) {
      propietarios.push({
        nombre: `${NOMBRES[i % NOMBRES.length]} ${APELLIDOS[i % APELLIDOS.length]}`,
        doc: String(2000000000 + i),
        tel: `310${String(i).padStart(7, "0")}`,
        email: `cliente${i}@email.com`,
      });
    }

    // 70 carros y 10 motos
    for (let i = 1; i <= 70; i++) {
      const owner = propietarios[i % propietarios.length];
      vehiculos.push([
        idTipoCarro,
        placaCarro(i),
        COLORES[i % COLORES.length],
        MODELOS_POR_TIPO.carro[i % MODELOS_POR_TIPO.carro.length].anio,
        MODELOS_POR_TIPO.carro[i % MODELOS_POR_TIPO.carro.length].nombre,
        owner.nombre,
        "cc",
        owner.doc,
        owner.tel,
        owner.email,
        true,
      ]);
    }
    for (let i = 1; i <= 10; i++) {
      const owner = propietarios[i % propietarios.length];
      vehiculos.push([
        idTipoMoto,
        placaMoto(i),
        COLORES[i % COLORES.length],
        MODELOS_POR_TIPO.moto[i % MODELOS_POR_TIPO.moto.length].anio,
        MODELOS_POR_TIPO.moto[i % MODELOS_POR_TIPO.moto.length].nombre,
        owner.nombre,
        "cc",
        owner.doc,
        owner.tel,
        owner.email,
        true,
      ]);
    }
    await conn.query(
      `INSERT INTO vehiculos (id_tipo_vehiculo, placa, color, modelo, nombre_modelo, propietario_nombre, propietario_tipo_documento, propietario_documento, propietario_telefono, propietario_email, activo) VALUES ?`,
      [vehiculos],
    );

    // 5. Mensualidades + confirmación de pago (mismas reglas que registrarPago)
    const [vehs] = await conn.query(
      `SELECT v.id_vehiculo, v.placa, tv.tarifa_mensual
       FROM vehiculos v INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo`,
    );
    const porPlaca = new Map(vehs.map((v) => [v.placa, v]));
    const [[operador]] = await conn.query(
      "SELECT id_usuario FROM usuarios WHERE usuario_login = 'operador' LIMIT 1",
    );
    const idOperador = operador.id_usuario;

    // Turno abierto del operador (los pagos se registran dentro de un turno)
    const [turno] = await conn.query(
      "INSERT INTO turnos (id_usuario, estado, base_inicial) VALUES (?, 'abierto', 0)",
      [idOperador],
    );
    const idTurno = turno.insertId;

    const hoy = hoyBogota();
    const crearMensualidad = async (v, inicio, fin) => {
      const valor = Number(v.tarifa_mensual);
      const [m] = await conn.query(
        `INSERT INTO mensualidades (id_vehiculo, id_usuario_registro, fecha_inicio, fecha_fin, valor, estado)
         VALUES (?, ?, ?, ?, ?, 'activa')`,
        [v.id_vehiculo, idOperador, inicio, fin, valor],
      );
      // El pago se confirmó el día de inicio (o hoy, si es un periodo futuro)
      const diaPago = inicio < hoy ? inicio : hoy;
      await conn.query(
        `INSERT INTO pagos (id_mensualidad, id_turno, id_usuario, monto, fecha_pago)
         VALUES (?, ?, ?, ?, ?)`,
        [m.insertId, idTurno, idOperador, valor, `${diaPago} 14:00:00`],
      );
    };

    let totalMens = 0;
    for (const [placa, tipo, offset] of escenarios()) {
      const v = porPlaca.get(placa);
      if (!v) continue;
      const fin = sumarDias(hoy, offset);
      const inicio = inicioParaFin(fin);
      await crearMensualidad(v, inicio, calcularFin(inicio));
      totalMens++;
      if (tipo === "renovada") {
        const sigInicio = sumarDias(calcularFin(inicio), 1);
        await crearMensualidad(v, sigInicio, calcularFin(sigInicio));
        totalMens++;
      }
    }
    console.log(`Mensualidades creadas: ${totalMens} (con su pago confirmado)`);

    await conn.commit();
    console.log("Seed completado.");
  } catch (err) {
    await conn.rollback();
    console.error(err);
  } finally {
    await conn.release();
    await pool.end();
  }
}

main();

/** Inicio de un periodo cuyo fin (inicio + 1 mes - 1 día) sea exactamente `fin`. */
function inicioParaFin(fin) {
  for (let d = 27; d <= 31; d++) {
    const ini = sumarDias(fin, -d);
    if (calcularFin(ini) === fin) return ini;
  }
  return sumarDias(fin, -29);
}

async function vaciarBase(conn) {
  await conn.query("SET FOREIGN_KEY_CHECKS = 0");
  try {
    for (const tabla of TABLAS) await conn.query(`TRUNCATE TABLE \`${tabla}\``);
  } finally {
    await conn.query("SET FOREIGN_KEY_CHECKS = 1");
  }
}

export async function cargar(conn, datos) {
  const { hoy, vehiculos, usuarios } = datos;

  // 1. Usuarios
  const hash = await bcrypt.hash(CLAVE, 10);
  await conn.query(
    `INSERT INTO usuarios (rol, tipo_documento, documento, nombres, apellidos, telefono, email, usuario_login, clave_hash, estado)
     VALUES ?`,
    [
      usuarios.map((u) => [
        u.rol,
        "cc",
        u.doc,
        u.nombres,
        u.apellidos,
        `300${u.doc.slice(-7)}`,
        `${u.login}@autoscolombia.com`,
        u.login,
        hash,
        u.estado,
      ]),
    ],
  );
  const [us] = await conn.query(
    "SELECT id_usuario, usuario_login FROM usuarios",
  );
  const idUsuario = Object.fromEntries(
    us.map((u) => [u.usuario_login, u.id_usuario]),
  );

  // 2. Tipos, puertas y celdas
  await conn.query(
    `INSERT INTO tipos_vehiculos (codigo, nombre, tarifa_mensual)
     VALUES ('carro', 'Carro', 250000), ('moto', 'Moto', 100000)`,
  );
  const [tipos] = await conn.query(
    "SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos",
  );
  const idTipo = Object.fromEntries(
    tipos.map((t) => [t.codigo, t.id_tipo_vehiculo]),
  );

  await conn.query(
    `INSERT INTO puertas (nombre, ubicacion, disponible_nocturna, activa)
     VALUES ('Puerta 1', 'Principal', TRUE, TRUE), ('Puerta 2', 'Secundaria', FALSE, TRUE)`,
  );
  const [[puerta]] = await conn.query(
    "SELECT id_puerta FROM puertas ORDER BY id_puerta LIMIT 1",
  );

  const celdas = [];
  for (const letra of ["A", "B", "C", "D", "E", "F", "G"]) {
    for (let k = 1; k <= 10; k++) celdas.push([idTipo.carro, letra, k]);
  }
  for (let k = 1; k <= 10; k++) celdas.push([idTipo.moto, "H", k]);
  await conn.query(
    "INSERT INTO celdas (id_tipo_vehiculo, letra, numero) VALUES ?",
    [celdas],
  );
  const [cel] = await conn.query(
    "SELECT id_celda FROM celdas WHERE letra = 'A' AND numero IN (1, 2) ORDER BY numero",
  );

  // 3. Vehículos
  await conn.query(
    `INSERT INTO vehiculos (id_tipo_vehiculo, placa, color, modelo, nombre_modelo, propietario_nombre,
       propietario_tipo_documento, propietario_documento, propietario_telefono, propietario_email, activo)
     VALUES ?`,
    [
      vehiculos.map((x) => [
        idTipo[x.tipo],
        x.placa,
        x.color,
        x.modelo,
        x.nombre_modelo,
        x.dueno.nombre,
        x.dueno.tipo_documento,
        x.dueno.documento,
        x.dueno.telefono,
        x.dueno.email,
        x.activo,
      ]),
    ],
  );
  const [vs] = await conn.query(
    `SELECT v.id_vehiculo, v.placa, tv.tarifa_mensual
     FROM vehiculos v INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo`,
  );
  const porPlaca = new Map(vs.map((x) => [x.placa, x]));

  // 4. Turno abierto de operador_prueba (operador_dos y el admin quedan SIN turno a propósito,
  //    para probar que el primer pago abre el turno solo).
  const idOperador = idUsuario.operador_prueba;
  const [t] = await conn.query(
    "INSERT INTO turnos (id_usuario, estado, base_inicial) VALUES (?, 'abierto', 0)",
    [idOperador],
  );
  const idTurno = t.insertId;

  // 5. Mensualidades con su pago (igual que registrarPago)
  const crearMensualidad = async (veh, inicio, fin, estado = "activa") => {
    const valor = Number(veh.tarifa_mensual);
    const [m] = await conn.query(
      `INSERT INTO mensualidades (id_vehiculo, id_usuario_registro, fecha_inicio, fecha_fin, valor, estado)
       VALUES (?, ?, ?, ?, ?, ?)`,
      [veh.id_vehiculo, idOperador, inicio, fin, valor, estado],
    );
    const diaPago = inicio < hoy ? inicio : hoy;
    await conn.query(
      `INSERT INTO pagos (id_mensualidad, id_turno, id_usuario, monto, fecha_pago) VALUES (?, ?, ?, ?, ?)`,
      [m.insertId, idTurno, idOperador, valor, `${diaPago} 14:00:00`],
    );
  };

  let totalMens = 0;
  for (const x of vehiculos) {
    const veh = porPlaca.get(x.placa);
    let finAnterior = null;
    for (const m of x.mens) {
      let inicio;
      let fin;
      if (m.siguiente) {
        inicio = sumarDias(finAnterior, 1);
        fin = calcularFin(inicio);
      } else if (m.inicio !== undefined) {
        inicio = sumarDias(hoy, m.inicio);
        fin = calcularFin(inicio);
      } else {
        fin = sumarDias(hoy, m.fin);
        inicio = inicioParaFin(fin);
        fin = calcularFin(inicio);
      }
      await crearMensualidad(veh, inicio, fin, m.estado ?? "activa");
      finAnterior = fin;
      totalMens++;
    }
  }

  // 6. Accesos: ABC107 dentro del parqueadero; ABC112 con un ingreso/salida anterior
  for (const x of vehiculos.filter((q) => q.acceso)) {
    const veh = porPlaca.get(x.placa);
    if (x.acceso === "dentro") {
      await conn.query(
        `INSERT INTO accesos_vehiculos (id_vehiculo, id_celda, id_puerta_ingreso, id_operador_ingreso, id_turno_ingreso)
         VALUES (?, ?, ?, ?, ?)`,
        [
          veh.id_vehiculo,
          cel[0].id_celda,
          puerta.id_puerta,
          idOperador,
          idTurno,
        ],
      );
    } else {
      await conn.query(
        `INSERT INTO accesos_vehiculos (id_vehiculo, id_celda, id_puerta_ingreso, id_operador_ingreso, id_turno_ingreso,
           fecha_ingreso, id_puerta_salida, id_operador_salida, id_turno_salida, fecha_salida)
         VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
        [
          veh.id_vehiculo,
          cel[1].id_celda,
          puerta.id_puerta,
          idOperador,
          idTurno,
          `${sumarDias(hoy, -3)} 15:00:00`,
          puerta.id_puerta,
          idOperador,
          idTurno,
          `${sumarDias(hoy, -3)} 17:30:00`,
        ],
      );
    }
  }
  return { totalMens };
}

function resumen(datos, totalMens) {
  const { vehiculos } = datos;
  console.log("\nUsuarios (clave: SEED_CLAVE o 123456):");
  for (const u of datos.usuarios)
    console.log(
      `  ${u.login.padEnd(18)} ${u.rol}${u.estado === "inactivo" ? " (inactivo)" : ""}`,
    );
  console.log("\nVehículos de prueba:");
  for (const x of vehiculos.filter((q) => q.nota !== "Relleno de cupo")) {
    console.log(`  ${x.placa}  ${x.tipo.padEnd(5)} ${x.nota}`);
  }
  const rell = vehiculos.filter((q) => q.nota === "Relleno de cupo").length;
  if (rell)
    console.log(`  (+ ${rell} vehículos de relleno RLL…/RLM… para el cupo)`);
  console.log(
    `\nVehículos: ${vehiculos.length} · Mensualidades con pago: ${totalMens}`,
  );
  console.log(
    "Placas libres para los casos que registran: ABC120, ABC124, XYZ15C. No registrada: ABC999.",
  );
}

async function main() {
  const args = process.argv.slice(2);
  const cupoArg = (
    args.find((a) => a.startsWith("--cupo=")) ?? "--cupo=ninguno"
  ).split("=")[1];
  if (!CUPOS_VALIDOS.includes(cupoArg)) {
    console.error(`--cupo inválido. Use uno de: ${CUPOS_VALIDOS.join(", ")}`);
    process.exitCode = 1;
    return;
  }
  if (!/test/i.test(String(env.DB_NAME)) && !args.includes("--force")) {
    console.error(
      `Este seed vacía las tablas y la base "${env.DB_NAME}" no parece de pruebas. ` +
        `Use una base con "test" en el nombre o agregue --force.`,
    );
    process.exitCode = 1;
    return;
  }

  const datos = construirDatos(hoyBogota(), cupoArg);
  const conn = await pool.getConnection();
  try {
    await vaciarBase(conn);
    await conn.beginTransaction();
    const { totalMens } = await cargar(conn, datos);
    await conn.commit();
    console.log(
      `Seed de pruebas listo en "${env.DB_NAME}" (hoy = ${datos.hoy}, cupo = ${cupoArg}).`,
    );
    resumen(datos, totalMens);
  } catch (err) {
    await conn.rollback();
    console.error("Seed de pruebas falló, se deshizo todo:", err);
    process.exitCode = 1;
  } finally {
    conn.release();
    await pool.end();
  }
}

  main();

import bcrypt from "bcryptjs";

export const MAX_INTENTOS_FALLIDOS = 5;
export const VENTANA_INTENTOS_MINUTOS = 15;
// Hash falso para gastar el mismo tiempo cuando el usuario no existe (evita enumerar usuarios por latencia).
const HASH_FALSO = bcrypt.hashSync("clave-falsa-para-igualar-tiempos", 10);

/**
 * IP del cliente. Se usa req.ip (respeta TRUST_PROXY). Antes se confiaba ciegamente en el
 * header X-Forwarded-For, así que cualquiera esquivaba el bloqueo por IP cambiándolo.
 */
export const obtenerIp = (req) =>
  req.ip || req.socket?.remoteAddress || "desconocida";

const errorAuth = () => ({ status: 401, error: "Usuario o clave incorrectos" });
const perfil = (u) => ({
  id_usuario: u.id_usuario,
  usuario_login: u.usuario_login,
  rol: u.rol,
  nombres: u.nombres,
  apellidos: u.apellidos,
  nombreCompleto: `${u.nombres} ${u.apellidos}`,
  estado: u.estado,
});

export const login = async (req, { usuario_login, clave } = {}) => {
  const login = String(usuario_login ?? "")
    .trim()
    .slice(0, 40);
  if (!login || !clave)
    return { status: 422, error: "Usuario y clave son obligatorios" };

  const ip = obtenerIp(req);
  const intento = (exitoso) =>
    userRepository.registrarIntento({
      usuario_login: login,
      exitoso,
      ip_address: ip,
    });

  const [porUsuario, porIp] = await Promise.all([
    userRepository.contarFallidosRecientes({
      usuario_login: login,
      minutos: VENTANA_INTENTOS_MINUTOS,
    }),
    userRepository.contarFallidosRecientes({
      ip_address: ip,
      minutos: VENTANA_INTENTOS_MINUTOS,
    }),
  ]);
  if (porUsuario >= MAX_INTENTOS_FALLIDOS || porIp >= MAX_INTENTOS_FALLIDOS) {
    // No se registra otro intento: antes cada intento bloqueado ampliaba el bloqueo indefinidamente.
    return {
      status: 423,
      error:
        "Acceso bloqueado temporalmente por múltiples intentos fallidos. Intente más tarde.",
    };
  }

  const usuario = await userRepository.findByLogin(login);
  const coincide = await bcrypt.compare(
    String(clave),
    usuario?.clave_hash ?? HASH_FALSO,
  );
  if (!usuario || !coincide) {
    await intento(false);
    return errorAuth();
  }
  if (usuario.estado !== "activo") {
    await intento(false);
    return { status: 403, error: "Usuario inactivo. No puede iniciar sesión." };
  }

  await intento(true);
  await userRepository.registrarUltimoAcceso(usuario.id_usuario);

  // Seguridad: Revocar sesiones previas al iniciar sesión para garantizar sesión única
  await refreshTokenRepository.revocarRefreshTokensUsuario(usuario.id_usuario);
  await userRepository.cerrarSesionActiva(usuario.id_usuario);

  await userRepository.registrarSesionActiva(usuario.id_usuario);
  const token = generarToken(usuario.id_usuario);
  const refresh_token = await refreshTokenRepository.crearRefreshToken(
    usuario.id_usuario,
  );
  await auditRepository.registrarAudit({
    id_usuario: usuario.id_usuario,
    usuario_login: usuario.usuario_login,
    accion: "LOGIN",
    recurso: "auth",
    detalle: "Inicio de sesión exitoso",
    ip_address: ip,
  });
  return {
    status: 200,
    body: { token, refresh_token, usuario: perfil(usuario) },
  };
};

/** Campo que provocó el duplicado (antes podía quedar vacío: "ese ."). */
export function campoDuplicado(dup, datos) {
  if (
    dup.tipo_documento === datos.tipo_documento &&
    String(dup.documento) === String(datos.documento)
  )
    return "documento";
  if (
    String(dup.usuario_login).toLowerCase() ===
    String(datos.usuario_login).toLowerCase()
  )
    return "usuario de acceso";
  if (
    datos.email &&
    dup.email &&
    dup.email.toLowerCase() === String(datos.email).toLowerCase()
  )
    return "correo";
  return "dato único";
}

/** Crea el usuario. La validación de campos ya la hizo validarDatosUsuario en el controlador. `actor` = admin que lo crea. */
export const registrar = async (datos, actor = null) => {
  const dup = await userRepository.findDuplicate({
    tipo_documento: datos.tipo_documento,
    documento: datos.documento,
    usuario_login: datos.usuario_login,
    email: datos.email || undefined,
  });
  if (dup)
    return {
      status: 409,
      error: `Ya existe un usuario registrado con ese ${campoDuplicado(dup, datos)}.`,
    };

  const clave_hash = await bcrypt.hash(String(datos.clave), 10);
  const { insertId } = await userRepository.create({ ...datos, clave_hash });

  // Antes el audit se guardaba a nombre del usuario recién creado, no de quien lo creó.
  await auditRepository.registrarAudit({
    id_usuario: actor?.id_usuario ?? null,
    usuario_login: actor?.usuario_login ?? null,
    accion: "CREATE_USER",
    recurso: "usuarios",
    detalle: `Usuario creado: ${datos.usuario_login} (${datos.rol})`,
  });
  const c = await userRepository.findById(insertId);
  return {
    status: 201,
    body: {
      id_usuario: c.id_usuario,
      usuario_login: c.usuario_login,
      rol: c.rol,
      nombres: c.nombres,
      apellidos: c.apellidos,
      email: c.email,
    },
  };
};

export const restablecerClave = async ({ idUsuario, claveNueva, adminId }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (!usuario) return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };

  await userRepository.cambiarClave(
    idUsuario,
    await bcrypt.hash(String(claveNueva), 10),
  );
  await refreshTokenRepository.revocarRefreshTokensUsuario(idUsuario);
  await userRepository.cerrarSesionActiva(idUsuario);

  const admin = adminId ? await userRepository.findById(adminId) : null;
  await auditRepository.registrarAudit({
    id_usuario: adminId ?? null,
    usuario_login: admin?.usuario_login ?? "sistema",
    accion: "RESET_PASSWORD",
    recurso: "usuarios",
    detalle: `Clave restablecida y sesiones revocadas para ${usuario.usuario_login}`,
  });
  return {
    status: 200,
    body: {
      mensaje: `Clave restablecida para el usuario ${usuario.usuario_login}. Sesiones activas cerradas.`,
    },
  };
};

/** Re-autenticación (step-up). Si `clave` falta devuelve 422 sin llamar a bcrypt con "undefined". */
export const verificarClaveUsuario = async ({ usuario_login, clave }) => {
  if (!clave) return { status: 422, error: "La clave es obligatoria" };
  const usuario = await userRepository.findByLogin(usuario_login);
  if (!usuario) return { status: 404, error: MSG.NO_ENCONTRADO("Usuario") };
  if (!(await bcrypt.compare(String(clave), usuario.clave_hash)))
    return { status: 400, error: "La clave es incorrecta" };
  return { status: 200, body: { ok: true } };
};

export const logout = async ({ idUsuario, token }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (token) {
    try {
      const d = verificarToken(token);
      if (d?.jti && d?.exp) {
        await revokedTokenRepository.revocarToken({
          jti: d.jti,
          id_usuario: idUsuario,
          expires_at: new Date(d.exp * 1000),
        });
      }
    } catch (e) {
      console.warn("LOGOUT: no se pudo revocar el token:", e.message);
    }
  }
  await refreshTokenRepository.revocarRefreshTokensUsuario(idUsuario);
  await userRepository.cerrarSesionActiva(idUsuario);
  await auditRepository.registrarAudit({
    id_usuario: idUsuario,
    usuario_login: usuario?.usuario_login ?? null,
    accion: "LOGOUT",
    recurso: "auth",
    detalle: "Cierre de sesión",
  });
  return { status: 200, body: { ok: true } };
};

export const refresh = async ({ refresh_token }) => {
  if (!refresh_token) return { status: 422, error: "Refresh token requerido" };
  const row = await refreshTokenRepository.validarRefreshToken(refresh_token);
  if (!row) return { status: 401, error: "Refresh token inválido o expirado" };

  // Se valida al usuario ANTES de rotar (antes se emitía y revocaba tokens de usuarios inactivos).
  const usuario = await userRepository.findById(row.id_usuario);
  if (!usuario || usuario.estado !== "activo")
    return { status: 403, error: "Usuario inactivo" };

  await refreshTokenRepository.revocarRefreshToken(refresh_token);
  const nuevo = await refreshTokenRepository.crearRefreshToken(
    usuario.id_usuario,
  );
  return {
    status: 200,
    body: {
      token: generarToken(usuario.id_usuario),
      refresh_token: nuevo,
      usuario: perfil(usuario),
    },
  };
};

// La app NO cobra: solo confirma que el pago (hecho por fuera) se realizó.

import { validarPlaca } from "../validators/placa.js";
import { SQL_HOY_BOGOTA } from "../utils/fechas.js";
import {
  CUPOS_POR_TIPO,
  DIAS_ANTICIPACION_MAX,
  SQL_ULTIMA_MENSUALIDAD,
  planificarPeriodo,
  hoyBogota,
  aYMD,
} from "../utils/mensualidad.js";

/**
 * Vehículos distintos con mensualidad que cubre hoy o futura, por tipo.
 * `db` puede ser el pool o una conexión (ambos tienen .query -> [rows]).
 */
export async function contarOcupados(db, idTipoVehiculo) {
  const [rows] = await db.query(
    `SELECT COUNT(DISTINCT m.id_vehiculo) AS total
     FROM mensualidades m
     INNER JOIN vehiculos v ON v.id_vehiculo = m.id_vehiculo
     WHERE v.id_tipo_vehiculo = ?
       AND v.activo = TRUE
       AND m.estado <> 'cancelada'
       AND m.fecha_fin >= ${SQL_HOY_BOGOTA}`,
    [idTipoVehiculo],
  );
  return Number(rows[0].total);
}

/**
 * NUEVO: cupos ocupados de todos los tipos en una sola consulta.
 * Devuelve algo como { carro: 12, moto: 3 }. Lo usa el listado (RF06.6).
 */
export async function ocupadosPorTipo(db) {
  const [rows] = await db.query(
    `SELECT tv.codigo, COUNT(DISTINCT m.id_vehiculo) AS total
     FROM mensualidades m
     INNER JOIN vehiculos v ON v.id_vehiculo = m.id_vehiculo
     INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
     WHERE v.activo = TRUE
       AND m.estado <> 'cancelada'
       AND m.fecha_fin >= ${SQL_HOY_BOGOTA}
     GROUP BY tv.codigo`,
  );
  const r = {};
  for (const f of rows) r[f.codigo] = Number(f.total);
  return r;
}

/** Verifica cupo para una mensualidad NUEVA o tras vencimiento (RF05.9). */
export async function validarCupo(conn, idTipoVehiculo, tipoCodigo) {
  const max = CUPOS_POR_TIPO[tipoCodigo];
  if (!max) return;
  // Serializa pagos concurrentes del mismo tipo para no pasarse del cupo.
  await conn.query(
    `SELECT id_tipo_vehiculo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ? FOR UPDATE`,
    [idTipoVehiculo],
  );
  const ocupados = await contarOcupados(conn, idTipoVehiculo);
  if (ocupados >= max) {
    throw new ErrorNegocio(
      409,
      `Sin cupo disponible para ${tipoCodigo}s (${ocupados}/${max}). No es posible registrar la mensualidad.`,
    );
  }
}

/**
 * Confirma que se recibió el pago de una mensualidad (RF05.1 a RF05.10).
 * El valor sale SIEMPRE de tipos_vehiculos.tarifa_mensual; no se recibe monto ni método.
 * (Sin cambios respecto a la versión anterior.)
 */
export async function registrarPago({ idUsuario, idTurno, placa }) {
  const formato = validarPlaca(placa);
  if (!formato.valida) throw new ErrorNegocio(422, formato.error);
  if (!idUsuario) throw new ErrorNegocio(401, "Usuario no identificado");
  if (!idTurno)
    throw new ErrorNegocio(
      400,
      "Debe tener un turno abierto para confirmar el pago",
    );

  return conTransaccion(async (conn) => {
    // 1. Vehículo
    const [vehRows] = await conn.query(
      `SELECT v.id_vehiculo, v.placa, v.id_tipo_vehiculo, v.activo,
              tv.codigo AS tipo_codigo, tv.nombre AS tipo, tv.tarifa_mensual
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       WHERE v.placa = ? LIMIT 1 FOR UPDATE`,
      [formato.placa],
    );
    if (!vehRows.length) throw new ErrorNegocio(404, "Vehículo no encontrado");
    const v = vehRows[0];
    if (!v.activo) throw new ErrorNegocio(400, "El vehículo está inactivo");

    // 2. Coherencia placa/tipo (RF05.7)
    if (!validarPlaca(v.placa, v.tipo_codigo).valida)
      throw new ErrorNegocio(
        422,
        `La placa ${v.placa} no corresponde al tipo ${v.tipo}`,
      );

    // 3. Valor de referencia (no modificable desde la app)
    const valor = Number(v.tarifa_mensual);
    if (!Number.isFinite(valor) || valor <= 0)
      throw new ErrorNegocio(422, "La tarifa mensual del tipo no es válida");

    // 4. Mensualidad vigente (la que cubre hoy; si no, la más reciente)
    const [mensRows] = await conn.query(
      `${SQL_ULTIMA_MENSUALIDAD} FOR UPDATE`,
      [v.id_vehiculo],
    );
    const vigente = mensRows[0] ?? null;

    // 5. ¿Ya tiene confirmado el siguiente periodo? (RF05.6)
    if (vigente) {
      const [siguientes] = await conn.query(
        `SELECT id_mensualidad FROM mensualidades
         WHERE id_vehiculo = ? AND fecha_inicio > ? AND estado <> 'cancelada'
         LIMIT 1`,
        [v.id_vehiculo, aYMD(vigente.fecha_fin)],
      );
      if (siguientes.length)
        throw new ErrorNegocio(
          409,
          "El vehículo ya tiene confirmado el siguiente periodo",
        );
    }

    // 6. Periodo (misma lógica que la previsualización)
    const plan = planificarPeriodo(vigente, hoyBogota());
    if (!plan.puedePagar)
      throw new ErrorNegocio(
        409,
        `La mensualidad está vigente. Podrá renovar cuando falten ${DIAS_ANTICIPACION_MAX} días o menos (faltan ${plan.diasRestantes}).`,
      );

    // 7. Cupo solo si NO es renovación (RF05.9 / RF05.10)
    if (!plan.esRenovacion)
      await validarCupo(conn, v.id_tipo_vehiculo, v.tipo_codigo);

    // 8. Evitar duplicado por misma fecha de inicio
    const [existentes] = await conn.query(
      `SELECT id_mensualidad FROM mensualidades
       WHERE id_vehiculo = ? AND fecha_inicio = ? AND estado <> 'cancelada' LIMIT 1`,
      [v.id_vehiculo, plan.inicio],
    );
    if (existentes.length)
      throw new ErrorNegocio(
        409,
        "Ya existe una mensualidad registrada para este vehículo en esta fecha",
      );

    // 9. Mensualidad
    let mInsertId;
    try {
      const [mInsert] = await conn.query(
        `INSERT INTO mensualidades
           (id_vehiculo, id_usuario_registro, fecha_inicio, fecha_fin, estado, valor)
         VALUES (?, ?, ?, ?, 'activa', ?)`,
        [v.id_vehiculo, idUsuario, plan.inicio, plan.fin, valor],
      );
      mInsertId = mInsert.insertId;
    } catch (err) {
      if (
        err.code === "ER_DUP_ENTRY" &&
        err.sqlMessage.includes("uq_mens_vehiculo_inicio")
      ) {
        const [old] = await conn.query(
          `SELECT id_mensualidad FROM mensualidades WHERE id_vehiculo = ? AND fecha_inicio = ? AND estado = 'cancelada' LIMIT 1`,
          [v.id_vehiculo, plan.inicio],
        );
        if (old.length) {
          await conn.query(
            `UPDATE mensualidades SET estado = 'activa', id_usuario_registro = ?, valor = ? WHERE id_mensualidad = ?`,
            [idUsuario, valor, old[0].id_mensualidad],
          );
          mInsertId = old[0].id_mensualidad;
        } else throw err;
      } else throw err;
    }

    // 10. Confirmación de pago (quién y en qué turno)
    const [pInsert] = await conn.query(
      `INSERT INTO pagos (id_mensualidad, fecha_pago, monto, id_turno, id_usuario)
       VALUES (?, UTC_TIMESTAMP(), ?, ?, ?)`,
      [mInsertId, valor, idTurno, idUsuario],
    );

    return {
      id_mensualidad: mInsertId,
      id_pago: pInsert.insertId,
      placa: v.placa,
      tipo: v.tipo,
      propietario: null, // lo completa el controller
      periodo: { inicio: plan.inicio, fin: plan.fin },
      valor,
      es_renovacion: plan.esRenovacion,
    };
  });
}

/**
 * NUEVO (RF05.11 y RF05.12): cancela la mensualidad activa de un vehículo.
 * - No se puede si el vehículo está dentro del parqueadero.
 * - No se puede si no tiene mensualidad activa.
 * Cancela la que cubre hoy y también la siguiente si ya estaba pagada.
 * El vehículo queda "Sin mensualidad" y se libera el cupo.
 */
export async function cancelarMensualidad({ placa }) {
  const formato = validarPlaca(placa);
  if (!formato.valida) throw new ErrorNegocio(422, formato.error);

  return conTransaccion(async (conn) => {
    const [vehRows] = await conn.query(
      `SELECT id_vehiculo, placa FROM vehiculos WHERE placa = ? LIMIT 1 FOR UPDATE`,
      [formato.placa],
    );
    if (!vehRows.length) throw new ErrorNegocio(404, "Vehículo no encontrado");
    const v = vehRows[0];

    const [dentro] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos WHERE id_vehiculo = ? AND fecha_salida IS NULL LIMIT 1`,
      [v.id_vehiculo],
    );
    if (dentro.length)
      throw new ErrorNegocio(
        400,
        "No se puede cancelar: el vehículo está dentro del parqueadero",
      );

    const [activas] = await conn.query(
      `SELECT id_mensualidad, fecha_inicio, fecha_fin, valor
       FROM mensualidades
       WHERE id_vehiculo = ?
         AND estado <> 'cancelada'
         AND fecha_fin >= ${SQL_HOY_BOGOTA}
       ORDER BY fecha_inicio
       FOR UPDATE`,
      [v.id_vehiculo],
    );
    if (!activas.length)
      throw new ErrorNegocio(
        409,
        "El vehículo no tiene una mensualidad activa para cancelar",
      );

    await conn.query(
      `UPDATE mensualidades SET estado = 'cancelada' WHERE id_mensualidad IN (?)`,
      [activas.map((a) => a.id_mensualidad)],
    );

    return {
      placa: v.placa,
      nuevo_estado: "Sin mensualidad",
      canceladas: activas.length,
      periodo: {
        inicio: aYMD(activas[0].fecha_inicio),
        fin: aYMD(activas[activas.length - 1].fecha_fin),
      },
      valor: activas.reduce((s, a) => s + Number(a.valor), 0),
    };
  });
}

/**
 * RF05.16: elimina un vehículo SIN historial (antes esta función se llamaba
 * "cancelarMensualidad", pero en realidad borraba el vehículo).
 * No permite si está dentro, si tiene accesos o si ya tiene mensualidades.
 */
export async function eliminarVehiculo({ placa }) {
  const formato = validarPlaca(placa);
  if (!formato.valida) throw new ErrorNegocio(422, formato.error);

  return conTransaccion(async (conn) => {
    const [vehRows] = await conn.query(
      `SELECT v.id_vehiculo, v.placa FROM vehiculos v WHERE v.placa = ? LIMIT 1 FOR UPDATE`,
      [formato.placa],
    );
    if (!vehRows.length) throw new ErrorNegocio(404, "Vehículo no encontrado");
    const v = vehRows[0];

    const [dentro] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos WHERE id_vehiculo = ? AND fecha_salida IS NULL LIMIT 1`,
      [v.id_vehiculo],
    );
    if (dentro.length)
      throw new ErrorNegocio(
        400,
        "No se puede eliminar: el vehículo está dentro del parqueadero",
      );

    const [accesos] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos WHERE id_vehiculo = ? LIMIT 1`,
      [v.id_vehiculo],
    );
    if (accesos.length)
      throw new ErrorNegocio(
        400,
        "No se puede eliminar: el vehículo tiene historial de accesos.",
      );

    // Si tiene mensualidades, también tiene pagos: no se elimina.
    const [mens] = await conn.query(
      "SELECT 1 FROM mensualidades WHERE id_vehiculo = ? LIMIT 1",
      [v.id_vehiculo],
    );
    if (mens.length)
      throw new ErrorNegocio(
        400,
        "No se puede eliminar: el vehículo ya tiene mensualidades o pagos registrados.",
      );

    await conn.query("DELETE FROM vehiculos WHERE id_vehiculo = ?", [
      v.id_vehiculo,
    ]);
    return { placa: v.placa, nuevo_estado: "Eliminado" };
  });
}

/** Normaliza page/limit. Nunca devuelve offsets negativos. */
export function paginar(
  { page, limit } = {},
  { porDefecto = 20, maximo = 100 } = {},
) {
  const p = Math.max(Number.parseInt(page, 10) || 1, 1);
  const l = Math.min(
    Math.max(Number.parseInt(limit, 10) || porDefecto, 1),
    maximo,
  );
  return { page: p, limit: l, offset: (p - 1) * l };
}

/** Escapa % y _ para que el usuario no inyecte comodines en un LIKE. */
export const likeSeguro = (texto) =>
  `%${String(texto).replace(/[\\%_]/g, "\\$&")}%`;

/** "true"/"false"/1/0/booleanos -> boolean; null si no es válido. */
export function aBooleano(valor) {
  if (valor === true || valor === "true" || valor === 1 || valor === "1")

// Zona horaria y formato de fechas (antes repetido en 3 archivos).
export const ZONA_HORARIA = "America/Bogota";
export const OFFSET_BOGOTA_HORAS = 5; // Colombia no usa horario de verano

export const SQL_HOY_BOGOTA = `DATE(UTC_TIMESTAMP() - INTERVAL ${OFFSET_BOGOTA_HORAS} HOUR)`;
export const sqlFechaBogota = (col) =>
  `DATE(${col} - INTERVAL ${OFFSET_BOGOTA_HORAS} HOUR)`;

export const formatearFechaHora = (d = new Date()) => {
  const f = new Date(d);
  return {
    fecha: f.toLocaleDateString("es-CO", { timeZone: ZONA_HORARIA }),
    hora: f.toLocaleTimeString("es-CO", {
      timeZone: ZONA_HORARIA,
      hour: "2-digit",
      minute: "2-digit",
    }),
  };
};

export const formatearPermanencia = (min) => {
  const m = Math.max(Number(min) || 0, 0);
  const d = Math.floor(m / 1440);
  const h = Math.floor((m % 1440) / 60);
  const r = m % 60;
  return [d && `${d} d`, (d || h) && `${h} h`, `${r} min`]
    .filter(Boolean)
    .join(" ");
};

export const ESTADO_MENSUALIDAD = {
  AL_DIA: "Al día",
  PENDIENTE: "Pendiente", // último día pagado (fecha_fin): aún puede entrar
  SIN_MENSUALIDAD: "Sin mensualidad",
};

// ---------- Fechas (texto YYYY-MM-DD) ----------

/** Hoy en Bogotá como "YYYY-MM-DD". */
export const hoyBogota = () =>
  new Date().toLocaleDateString("en-CA", { timeZone: ZONA_HORARIA });

/** Convierte Date (DATE de MySQL llega como medianoche UTC) o string a "YYYY-MM-DD". */
export const aYMD = (v) => {
  if (!v) return null;
  if (v instanceof Date) return v.toISOString().slice(0, 10);
  return String(v).slice(0, 10);
};

const utc = (ymd) => {
  const [y, m, d] = ymd.split("-").map(Number);
  return Date.UTC(y, m - 1, d);
};
const DIA_MS = 24 * 60 * 60 * 1000;

export const sumarDias = (ymd, n) =>
  new Date(utc(ymd) + n * DIA_MS).toISOString().slice(0, 10);

/** Días entre dos fechas (b - a). */
export const diasEntre = (a, b) => Math.round((utc(b) - utc(a)) / DIA_MS);

/** Fin del periodo = inicio + 1 mes - 1 día (ajusta meses cortos). */
export function calcularFin(inicio) {
  const [y, m, d] = inicio.split("-").map(Number);
  const ultimoDiaSiguiente = new Date(Date.UTC(y, m + 1, 0)).getUTCDate();
  const dia = Math.min(d, ultimoDiaSiguiente);
  return sumarDias(
    new Date(Date.UTC(y, m, dia)).toISOString().slice(0, 10),
    -1,
  );
}

// ---------- Estado ----------

/**
 * Estado de una mensualidad (RF06.1).
 * - Fuera de [inicio, fin] o cancelada → Sin mensualidad
 * - hoy == fin → Pendiente (último día pagado)
 * - dentro del rango → Al día
 */
export function derivarEstado(fila, hoy = hoyBogota()) {
  if (!fila || fila.estado === "cancelada")
    return ESTADO_MENSUALIDAD.SIN_MENSUALIDAD;
  const ini = aYMD(fila.fecha_inicio);
  const fin = aYMD(fila.fecha_fin);
  if (!ini || !fin || hoy < ini || hoy > fin)
    return ESTADO_MENSUALIDAD.SIN_MENSUALIDAD;
  if (hoy === fin) return ESTADO_MENSUALIDAD.PENDIENTE;
  return ESTADO_MENSUALIDAD.AL_DIA;
}

export const estadoMensualidad = (fila) => derivarEstado(fila);

/** Estado de una fila del historial (mira otras filas para saber si hay periodo siguiente pagado). */
export function estadoFila(fila, filas, hoy = hoyBogota()) {
  if (!fila || fila.estado === "cancelada") return "cancelada";
  const ini = aYMD(fila.fecha_inicio);
  const fin = aYMD(fila.fecha_fin);
  if (ini > hoy) return ESTADO_MENSUALIDAD.AL_DIA; // pagada, aún no inicia
  const base = derivarEstado(fila, hoy);
  const haySiguiente = (filas ?? []).some(
    (f) => f.estado !== "cancelada" && aYMD(f.fecha_inicio) > fin,
  );
  return base === ESTADO_MENSUALIDAD.PENDIENTE && haySiguiente
    ? ESTADO_MENSUALIDAD.AL_DIA
    : base;
}

/** Estado global del vehículo a partir de todas sus mensualidades. */
export function estadoEfectivo(filas, hoy = hoyBogota()) {
  const vigente = elegirVigente(filas, hoy);
  if (!vigente)
    return { vigente: null, estado: ESTADO_MENSUALIDAD.SIN_MENSUALIDAD, fechaFin: null, siguientePagado: false };

  const finVigente = aYMD(vigente.fecha_fin);
  const ultimoFin = (filas ?? [])
    .filter((f) => f.estado !== "cancelada")
    .map((f) => aYMD(f.fecha_fin))
    .sort()
    .at(-1);

  return {
    vigente,
    estado: estadoFila(vigente, filas, hoy),
    fechaFin: ultimoFin, // hasta cuándo está realmente pagado
    siguientePagado: ultimoFin > finVigente,
  };
}

/** Días restantes para vencer (negativo si ya venció). */
export const diasParaVencer = (fechaFin, hoy = hoyBogota()) =>
  diasEntre(hoy, aYMD(fechaFin));

/** ¿Está dentro de la ventana de renovación? (0..5 días) */
export function puedeRenovarAnticipado(fechaFinVigente, hoy = hoyBogota()) {
  if (!fechaFinVigente) return false;
  const dias = diasParaVencer(fechaFinVigente, hoy);
  return dias >= 0 && dias <= DIAS_ANTICIPACION_MAX;
}

/**
 * Elige la mensualidad "vigente" de una lista (en JS):
 * 1. La que cubre hoy (inicio <= hoy <= fin)
 * 2. Si no hay, la MÁS RECIENTE que ya esté pagada (fecha_inicio > hoy, estado='activa') -> renovación anticipada
 * 3. Si no hay, la de mayor fecha_fin (historial reciente)
 * Ignora canceladas.
 */
export function elegirVigente(filas, hoy = hoyBogota()) {
  const ok = (filas ?? []).filter((f) => f.estado !== "cancelada");
  if (!ok.length) return null;

  // Ordenar por inicio DESC (la más reciente primero)
  const ordenadas = [...ok].sort((a, b) => aYMD(b.fecha_inicio).localeCompare(aYMD(a.fecha_inicio)));

  // 1. La que cubre hoy
  const cubre = ordenadas.find(
    (f) => aYMD(f.fecha_inicio) <= hoy && aYMD(f.fecha_fin) >= hoy,
  );
  if (cubre) return cubre;

  // 2. La más reciente pagada que empieza en el futuro (renovación anticipada ya pagada)
  const futura = ordenadas.find((f) => aYMD(f.fecha_inicio) > hoy);
  if (futura) return futura;

  // 3. La de mayor fecha_fin (historial)
  return ordenadas[0];
}

/**
 * ÚNICA fuente de verdad para el periodo a confirmar (la usan preview y registro).
 * - Sin mensualidad o ya vencida → inicia hoy.
 * - Con mensualidad que aún cubre → renovación: inicia el día siguiente a su fin,
 *   solo permitida si faltan 0..5 días.
 */
export function planificarPeriodo(vigente, hoy = hoyBogota()) {
  const finVigente =
    vigente && vigente.estado !== "cancelada" ? aYMD(vigente.fecha_fin) : null;
  const cubierta = !!finVigente && finVigente >= hoy;

  if (!cubierta) {
    return {
      esRenovacion: false,
      puedePagar: true,
      diasRestantes: null,
      inicio: hoy,
      fin: calcularFin(hoy),
    };
  }
  const diasRestantes = diasEntre(hoy, finVigente);
  const inicio = sumarDias(finVigente, 1);
  return {
    esRenovacion: true,
    puedePagar: diasRestantes <= DIAS_ANTICIPACION_MAX,
    diasRestantes,
    inicio,
    fin: calcularFin(inicio),
  };
}

/** ORDER BY para elegir la mensualidad vigente (la que cubre hoy primero). */
export const sqlOrdenVigente = (alias) =>
  `(${alias}.fecha_inicio <= ${SQL_HOY_BOGOTA} AND ${alias}.fecha_fin >= ${SQL_HOY_BOGOTA}) DESC, ${alias}.fecha_fin DESC`;

/** Mensualidad vigente por vehículo (1 parámetro: id_vehiculo). */
export const SQL_ULTIMA_MENSUALIDAD = `
  SELECT m.id_mensualidad, m.id_vehiculo, m.fecha_inicio, m.fecha_fin, m.estado,
         v.placa, v.id_tipo_vehiculo, tv.codigo AS tipo_codigo, tv.nombre AS tipo,
         tv.tarifa_mensual, v.propietario_nombre, v.propietario_documento
  FROM mensualidades m
  INNER JOIN vehiculos v ON v.id_vehiculo = m.id_vehiculo
  INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
  WHERE m.id_vehiculo = ?
    AND m.estado <> 'cancelada'
  ORDER BY ${sqlOrdenVigente("m")}
  LIMIT 1`;

export const responder = (res, status, texto, extra = null) => {
  const esExito = status >= 200 && status < 300;
  let payload;
  if (!esExito) {
    payload = { error: texto };
  } else {
    payload = { mensaje: texto };
    if (Array.isArray(extra)) {
      payload.data = extra;
    } else if (extra) {
      Object.assign(payload, extra);
    }
  }
  return res.status(status).json(payload);
};

export async function getOrCreateTurno(conn, idUsuario) {
  const [turnos] = await conn.query(
    "SELECT id_turno FROM turnos WHERE id_usuario = ? AND estado = 'abierto' LIMIT 1",
    [idUsuario]
  );
  if (turnos.length) return turnos[0].id_turno;
  const [r] = await conn.query(
    "INSERT INTO turnos (id_usuario, estado, base_inicial) VALUES (?, 'abierto', 0)",
    [idUsuario]
  );
  return r.insertId;
}

// Validacion de placas colombianas.
//   - Carro: 3 letras + 3 numeros          -> ABC123  (ABC-123)
//   - Moto:  3 letras + 2 numeros + letra  -> ABC12C  (ABC-12C)

/** @type {Object.<string, RegExp>} */
export const FORMATOS_POR_TIPO = {
  carro: /^([A-Z]{3})-?([0-9]{3})$/,
  moto: /^([A-Z]{3})-?([0-9]{2})([A-Z])$/,
};

export const FORMATOS = [FORMATOS_POR_TIPO.carro, FORMATOS_POR_TIPO.moto];

/**
 * Normaliza una placa: mayúsculas, sin espacios ni guiones.
 * @param {string} placa 
 * @returns {string}
 */
export const normalizarPlaca = (placa) =>
  String(placa ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");

/**
 * Verifica si una placa es válida según el tipo.
 * @param {string} placa 
 * @param {string|null} tipo - 'carro' | 'moto' | null
 * @returns {boolean}
 */
export const esPlacaValida = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) return false;
  if (tipo && FORMATOS_POR_TIPO[tipo]) return FORMATOS_POR_TIPO[tipo].test(p);
  return FORMATOS.some((re) => re.test(p));
};

/**
 * Valida una placa y devuelve objeto con detalles.
 * @param {string} placa 
 * @param {string|null} tipo 
 * @returns {{ valida: boolean, placa: string, tipo: string|null, error: string|null }}
 */
export const validarPlaca = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) {
    return { valida: false, placa: p, tipo, error: "La placa es obligatoria" };
  }

  if (tipo && FORMATOS_POR_TIPO[tipo]) {
    if (!FORMATOS_POR_TIPO[tipo].test(p)) {
      return {
        valida: false,
        placa: p,
        tipo,
        error:
          tipo === "moto"
            ? "Formato de placa inválido para moto. Ejemplo: ABC12C"
            : "Formato de placa inválido para carro. Ejemplo: ABC123",
      };
    }
    return { valida: true, placa: p, tipo, error: null };
  }

  if (!FORMATOS.some((re) => re.test(p))) {
    return {
      valida: false,
      placa: p,
      tipo,
      error:
        "Formato de placa inválido. Ejemplo: ABC123 (carro) o ABC12C (moto)",
    };
  }

  const tipoDetectado = FORMATOS_POR_TIPO.moto.test(p) ? "moto" : "carro";
  return { valida: true, placa: p, tipo: tipoDetectado, error: null };
};

import fs from 'fs/promises';
import path from 'path';

/**
 * Sanitiza datos sensibles antes de guardar evidencia.
 */
const sanitizar = (data) => {
  const clone = JSON.parse(JSON.stringify(data));
  if (clone && typeof clone === 'object') {
    if (clone.token) clone.token = '[REDACTED]';
    if (clone.refresh_token) clone.refresh_token = '[REDACTED]';
    if (clone.body) {
      if (clone.body.token) clone.body.token = '[REDACTED]';
      if (clone.body.refresh_token) clone.body.refresh_token = '[REDACTED]';
      if (clone.body.clave) clone.body.clave = '[REDACTED]';
      if (clone.body.claveAdmin) clone.body.claveAdmin = '[REDACTED]';
    }
  }
  return clone;
};

/**
 * Guarda la respuesta de una prueba en un archivo JSON dentro de docs/test-results/
 * @param {string} testId - ID del caso de prueba (ej: CE-11)
 * @param {Object} data - Objeto de respuesta o error a guardar
 */
export const guardarEvidencia = async (testId, data) => {
  const dir = path.join(process.cwd(), 'docs', 'test-results');
  try {
    await fs.mkdir(dir, { recursive: true });
    const safeData = sanitizar(data);
    await fs.writeFile(
      path.join(dir, `${testId}.json`),
      JSON.stringify(safeData, null, 2)
    );
    console.log(`✅ Evidencia guardada para ${testId}: docs/test-results/${testId}.json`);
  } catch (err) {
    console.error(`❌ Error al guardar evidencia para ${testId}:`, err);
  }
};
