# 🅿️ Auto Colombia — Sistema de Parqueadero Vehicular

[![Node.js](https://img.shields.io/badge/Node.js-18%2B-339933?style=for-the-badge&logo=node.js&logoColor=white)](https://nodejs.org/)
[![Express](https://img.shields.io/badge/Express-5.3.0-000000?style=for-the-badge&logo=express&logoColor=white)](https://expressjs.com/)
[![MySQL](https://img.shields.io/badge/MySQL-8.0%2B-4479A1?style=for-the-badge&logo=mysql&logoColor=white)](https://www.mysql.com/)
[![React](https://img.shields.io/badge/React-19.3.1-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-8.3.4-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)
[![Material UI](https://img.shields.io/badge/Material%20UI-9.5.0-007FFF?style=for-the-badge&logo=mui&logoColor=white)](https://mui.com/)
[![License: ISC](https://img.shields.io/badge/License-ISC-blue.svg?style=for-the-badge)](https://opensource.org/licenses/ISC)

Sistema de gestión de ingresos y salidas de vehículos para parqueaderos por mensualidad con celdas numeradas, desarrollado con **backend en Node.js + Express + MySQL** (sin ORM, consultas SQL nativas mediante `mysql2`) y **frontend en React + Vite + Material UI**.

Permite registrar el ingreso y salida de vehículos (carros y motos), validar placas con formato colombiano, controlar mensualidades (al día / en mora / sin mensualidad) **bloqueando el ingreso cuando no hay mensualidad vigente**, asignar celdas rotativas por tipo de vehículo, **reubicar vehículos dentro del parqueadero**, gestionar usuarios con roles (administrador / operador) con **re-autenticación del administrador en acciones sensibles**, y mantener un historial auditable de accesos.

La API está protegida con **JWT (Bearer)** y control de roles. El operador y el turno se resuelven a partir del usuario autenticado.

## 1. Descripción del proyecto

**Auto Colombia** es un sistema de control de acceso vehicular para parqueaderos por mensualidad que gestiona:

- ✅ **Ingreso y salida de vehículos** (carros y motos) con selección de celda libre del mismo tipo del vehículo.
- ✅ **Validación de placas** según formato colombiano (`AAA###` para carro, `AAA##X` para moto), en backend y frontend.
- ✅ **Control de mensualidades**: al día, en mora o sin mensualidad. **El ingreso se bloquea (403)** si el vehículo está en mora o no tiene mensualidad activa.
- ✅ **Consulta de estado** del vehículo (adentro/fuera, modelo, año, color, propietario, tipo, tarifa y estado de mensualidad).
- ✅ **Consulta de celdas disponibles** filtradas por tipo de vehículo.
- ✅ **Reubicación de vehículos**: el administrador puede mover un vehículo que ya está dentro a otra celda libre compatible (botón _reubicar_ en la pantalla de Celdas).
- ✅ **Autenticación JWT** con roles `administrador` y `operador`, tokens de acceso y refresh con rotación, y **renovación automática del token en el frontend**.
- ✅ **Gestión de usuarios** (alta, edición, activación/desactivación, restablecimiento de clave) solo por administrador, con **re-autenticación con la clave del administrador** antes de crear, editar o restablecer claves.
- ✅ **Indicador de sesión** (Conectado / Desconectado) y último acceso por usuario.
- ✅ **Gestión de celdas** (creación con límites por tipo, cambio de tipo, activación/inactivación, mantenimiento con duración y liberación automática, eliminación, resumen y vista por bloques).
- ✅ **Gestión de vehículos y propietarios** vía API (registro, edición, activación/desactivación, búsqueda).
- ✅ **Historial de accesos** filtrable por placa, celda, operador, estado (adentro/fuera) y rango de fechas, con paginación.
- ✅ **Dashboards por rol** (administrador y operador) con resumen de celdas actualizado automáticamente cada 5 segundos.
- ✅ **Auditoría** de login/logout y de movimientos (entrada, salida, reubicación), y registro de intentos fallidos (anti fuerza bruta).
- ✅ **Prevención de sobrecupo**: índices únicos en la base de datos impiden que un vehículo o una celda tengan más de un acceso abierto simultáneamente.
- ✅ **Seguridad HTTP**: Helmet, rate limiting global y específico para login.

> **Cambio de modelo:** el parqueadero usa **celdas rotativas**. Las _celdas fijas_ por vehículo fueron retiradas: los endpoints `PUT/DELETE /api/vehiculos/:placa/celda` responden `410 Gone` y el estado de celda `asignada` ya no se genera.

## 2. Tipo de proyecto y arquitectura

### 2.1 Tipo de proyecto

Aplicación web full-stack dividida en dos carpetas independientes en la raíz:

| Componente        | Responsabilidad                                                                                      | Tecnología principal       |
| ----------------- | ---------------------------------------------------------------------------------------------------- | -------------------------- |
| **Backend**       | API REST, lógica de negocio, acceso a datos MySQL, autenticación JWT                                 | Node.js + Express + mysql2 |
| **Frontend**      | Interfaz de usuario (SPA) con rutas protegidas por rol                                               | React + Vite + Material UI |
| **Base de datos** | Almacenamiento relacional de vehículos, celdas, accesos, usuarios, mensualidades, tokens y auditoría | MySQL 8.0+                 |

No se utiliza ORM; el backend ejecuta consultas SQL parametrizadas directamente mediante el pool de conexiones de `mysql2/promise`.

## 6. Instalación paso a paso

El proyecto se divide en dos partes independientes: **backend** y **frontend**. Cada una tiene su propio `package.json` y se instala por separado.

### Paso 1: Clonar el repositorio

```bash
git clone https://github.com/cirocarrillo01/Autos-colombia.git
cd Autos-colombia
```

### Paso 2: Instalar dependencias del backend

```bash
cd backend
npm install
```

### Paso 3: Instalar dependencias del frontend

```bash
cd ../frontend
npm install
```

### Paso 4: Configurar variables de entorno

**Backend:**

```bash
cd backend
cp .env.example .env
# Editar .env con las credenciales de MySQL y JWT_SECRET
```

**Frontend:**

```bash
cd ../frontend
echo "VITE_API_URL=http://localhost:3000/api" > .env
```

### Paso 5: Crear la base de datos

```bash
mysql -u root -p < backend/Script/parqueadero.sql
```

### Paso 6: Aplicar migraciones (solo si partes de un esquema anterior)

```bash
mysql -u root -p autos_colombia < backend/migrations/002_add_sesion_activa.sql
mysql -u root -p autos_colombia < backend/migrations/003_add_mantenimiento_hasta.sql
mysql -u root -p autos_colombia < backend/migrations/004_create_audit_log.sql
mysql -u root -p autos_colombia < backend/migrations/005_create_revoked_tokens.sql
mysql -u root -p autos_colombia < backend/migrations/006_create_refresh_tokens.sql
```

> El script `parqueadero.sql` actual ya incluye todas estas tablas/columnas. Las migraciones se mantienen para actualizar bases creadas con versiones anteriores.

### Paso 7: Sembrar datos iniciales

Desde `backend/`:

```bash
npm run seed           # Siembra solo si la base está vacía
npm run seed:reset     # Vacía todas las tablas y vuelve a sembrar
```

## 7. Variables de entorno

El backend lee `backend/.env` con un cargador propio (`envLoader.js`, sin `dotenv`). Si falta `DB_USER` o `DB_NAME` el servidor no arranca y muestra cuál falta; si falta `JWT_SECRET` el middleware de autenticación lanza un error al iniciar.

### Backend (`backend/.env`)

| Variable         | Valor por defecto       | Descripción                                                                                                                |
| ---------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`       | `development`           | Entorno de ejecución. En `development` el rate limit global sube a 300 peticiones/15 min                                   |
| `PORT`           | `3000`                  | Puerto del servidor Express                                                                                                |
| `DB_HOST`        | `localhost`             | Host de MySQL                                                                                                              |
| `DB_PORT`        | `3306`                  | Puerto de MySQL                                                                                                            |
| `DB_USER`        | — (obligatoria)         | Usuario de MySQL                                                                                                           |
| `DB_PASSWORD`    | vacío                   | Contraseña de MySQL                                                                                                        |
| `DB_NAME`        | — (obligatoria)         | Nombre de la base de datos (`autos_colombia`)                                                                              |
| `TRUST_PROXY`    | `0`                     | Número de proxies delante de la app (`0` ninguno, `1` Nginx/LB, etc.) para que `req.ip` y el rate limiting usen la IP real |
| `CORS_ORIGIN`    | `http://localhost:5173` | Origen del frontend (ver nota en la sección 20)                                                                            |

## 10. Autenticación y autorización

La API utiliza **JWT (Bearer)**. Las rutas protegidas requieren el header:

```http
Authorization: Bearer <token>
```

En cada petición el middleware `autenticar` valida el token, verifica que su `jti` no esté revocado, carga el usuario desde la base de datos y rechaza usuarios inactivos (403).

### 10.1 Roles

| Rol             | Permisos principales                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `administrador` | Todo: gestión de usuarios, celdas (crear, editar tipo, estado, mantenimiento, eliminar), reubicación de vehículos, además de lo que hace el operador |
| `operador`      | Ingreso/salida de vehículos, consulta de vehículos, celdas y historial, creación/edición/activación de vehículos                                     |

### 10.2 Endpoints de autenticación

| Método | Endpoint                    | Descripción                                                            | Autenticación              |
| ------ | --------------------------- | ---------------------------------------------------------------------- | -------------------------- |
| `POST` | `/api/auth/login`           | Iniciar sesión (devuelve `token` y `refresh_token`)                    | No                         |
| `POST` | `/api/auth/refresh`         | Renovar token de acceso (rota el refresh token)                        | No (refresh token en body) |
| `POST` | `/api/auth/register`        | Registrar usuario                                                      | Sí (admin)                 |
| `GET`  | `/api/auth/me`              | Datos del usuario autenticado                                          | Sí                         |
| `POST` | `/api/auth/verify-password` | Re-autenticar al administrador (antes de acciones sensibles)           | Sí (admin)                 |
| `POST` | `/api/auth/logout`          | Cerrar sesión (revoca el token y todos los refresh tokens del usuario) | Sí                         |

> No existe cambio de clave "propia": las claves solo las restablece un administrador desde `PATCH /api/users/:id/password`.

### 10.3 Ejemplo de login

**`POST /api/auth/login`**

Cuerpo:

```json
{
  "usuario_login": "admin",
  "clave": "123456"
}
```

Respuesta exitosa (200):

```json
{
  "token": "<jwt>",
  "refresh_token": "<refresh>",
  "usuario": {
    "id_usuario": 2,
    "usuario_login": "admin",
    "rol": "administrador",
    "nombres": "Administrador",
    "apellidos": "Principal",
    "nombreCompleto": "Administrador Principal",
    "estado": "activo"
  }
}
```

### 10.4 Seguridad adicional

- **Rate limiting**: 100 req/15 min por IP (300 en `development`) y 10 req/15 min para `/api/auth/login`. `/api/health` no cuenta.
- **Anti fuerza bruta**: bloqueo temporal (423) tras 5 intentos fallidos en 15 minutos (por usuario o por IP).
- **Tokens revocados**: el logout agrega el `jti` del JWT a `revoked_tokens`.
- **Refresh token rotation**: cada refresh revoca el token anterior y emite uno nuevo (duración 7 días).
- **Refresh automático en el cliente**: si una petición recibe 401 y hay refresh token, el frontend renueva el access token y reintenta **una sola vez**; las renovaciones concurrentes se serializan para no invalidar el refresh token.
- **Re-autenticación del administrador**: crear usuarios, editar usuarios y restablecer claves piden la clave del administrador (ver 12.3).
- **Auditoría**: login/logout y movimientos (entrada, salida, reubicación) se registran en `audit_log`.
- **Sesión activa**: `usuarios.sesion_activa` se marca al iniciar sesión y se limpia al cerrar sesión o desactivar al usuario.

### 11.11 Gestión de usuarios (administrador)

Responde 409 si documento, login o correo ya existen.
- **`PUT /api/users/:id`** — requiere `claveAdmin` en el cuerpo (422 si falta, 400 si es incorrecta). No permite que un administrador cambie su propio rol. El estado no se modifica por esta ruta.

- **`PATCH /api/users/:id/password`** — `{ clave, claveAdmin }`; la nueva clave debe tener al menos 4 caracteres.

## 12. Flujos del sistema

### 12.1 Ingreso de vehículo

1. El operador (autenticado) ingresa la placa; el frontend valida el formato y consulta el vehículo.
2. Si la placa ya está adentro, se avisa y no se permite el ingreso. Si la mensualidad está **en mora o no existe**, el vehículo se muestra pero el botón de ingreso queda bloqueado.
3. El frontend lista solo las celdas **libres del mismo tipo** del vehículo y el operador elige una.
4. El backend revalida: formato de placa, vehículo activo, placa coherente con su tipo, que no esté ya adentro y que tenga **mensualidad activa y vigente** (403 en caso contrario).
5. Verifica que la celda exista, esté activa, no esté en mantenimiento, sea compatible con el tipo y esté libre.
6. Resuelve el operador autenticado, su turno abierto (crea uno si no existe) y la primera puerta activa.
7. Registra el acceso en `accesos_vehiculos` y la auditoría dentro de una transacción.
8. La celda pasa a estado `ocupada` hasta que se registre la salida.

Los formularios de ingreso y salida se **limpian solos tras 35 segundos** de inactividad.

### 12.2 Salida de vehículo

1. El operador ingresa la placa; el frontend verifica que el vehículo esté adentro.
2. El backend valida el formato, que el vehículo exista y que tenga un acceso abierto.
3. Resuelve operador, turno y puerta.
4. Cierra el acceso (`fecha_salida`, operador, puerta y turno de salida), registra la auditoría y libera la celda inmediatamente.

### 12.3 Creación y gestión de usuarios (administrador)

El rol `administrador` gestiona el personal del parqueadero (operadores y otros administradores). Los clientes del parqueadero no son usuarios; sus datos viven en `vehiculos`.

1. En **Usuarios → Nuevo usuario** el sistema pide primero la **clave del administrador** (`POST /api/auth/verify-password`) y luego abre el formulario.
2. Se completan rol, tipo y número de documento, nombres, apellidos, correo, teléfono, usuario de login y clave (con confirmación).
3. `POST /api/auth/register` valida los campos y que documento, login y correo no estén duplicados.
4. La clave se guarda cifrada con bcrypt en `clave_hash`; el usuario queda `activo`.
5. **Editar** y **Clave (restablecer)** también piden confirmar la clave del administrador en el frontend, y el backend la vuelve a validar (`claveAdmin`) como segunda capa.
6. El listado muestra si cada usuario está **Conectado / Desconectado** y su último acceso, y se refresca cada 5 segundos.

| Rol             | Qué puede hacer                                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------------------------------- |
| `administrador` | Gestiona usuarios, celdas, reubicaciones, consulta historial y dashboard completo; accede a todas las rutas.     |
| `operador`      | Registra ingresos y salidas, consulta vehículos, celdas, historial y su dashboard; crea/edita vehículos por API. |

### 12.4 Creación y gestión de celdas (administrador)

1. En **Celdas** el administrador crea una celda indicando bloque (A–Z), número y tipo (`POST /api/celdas`).
2. El backend valida la posición única y los límites por tipo (70 carro / 10 moto). El código se genera automáticamente (`LETRA-NÚMERO`, ej. `A-05`).
3. Desde la lista puede **cambiar el tipo**, **inactivar/activar**, **eliminar** (solo celdas libres sin historial) o poner en **mantenimiento** indicando horas y minutos.
4. Al vencer `mantenimiento_hasta` la celda se libera automáticamente (se procesa en cada consulta de celdas).
5. La vista **Por bloques** muestra todas las celdas coloreadas por estado.

| Estado             | Qué significa                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `libre`            | Activa, fuera de mantenimiento y sin acceso abierto. Puede usarse para ingresos.           |
| `ocupada`          | Tiene un acceso abierto (`fecha_salida IS NULL`). Bloquea nuevos ingresos hasta la salida. |
| `en mantenimiento` | Fuera de servicio temporal hasta `mantenimiento_hasta`.                                    |
| `inactiva`         | Deshabilitada hasta que se reactive.                                                       |

### 12.5 Reubicación de un vehículo (administrador)

1. En **Celdas → Lista**, las celdas `ocupada` muestran el botón **reubicar**.
2. El sistema consulta las celdas libres del mismo tipo y localiza el acceso abierto de esa celda en el historial.
3. El administrador elige la celda destino y confirma.
4. `PATCH /api/movimientos/:id_acceso/celda` valida que la celda esté habilitada, libre y sea del tipo del vehículo, actualiza el acceso y registra la acción `reubicacion` en `audit_log`.

## 13. Reglas de negocio y restricciones

| Área                        | Regla                                                                                                                                                                      |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Placas**                  | Carro: `AAA###` · Moto: `AAA##X` (validación en backend y frontend) y debe coincidir con el tipo del vehículo                                                              |
| **Celdas**                  | Una celda está ocupada si existe un acceso con `fecha_salida IS NULL`                                                                                                      |
| **Celdas rotativas**        | No hay celdas fijas por vehículo; cada ingreso elige una celda libre del mismo tipo                                                                                        |
| **Límites de celdas**       | Máximo 70 celdas de carro y 10 de moto al crear nuevas                                                                                                                     |
| **Sobrecupo**               | Índices únicos `uq_acceso_vehiculo_dentro` y `uq_acceso_celda_ocupada` impiden duplicados incluso con peticiones simultáneas                                               |
| **Mensualidades**           | Se toma la mensualidad `activa` con mayor `fecha_fin`; está vigente si `fecha_fin >=` la fecha de hoy en Bogotá (UTC‑5). Estados: Al día / En mora / Sin mensualidad       |
| **Ingreso**                 | Solo con mensualidad activa y vigente; en mora o sin mensualidad el backend responde 403                                                                                   |
| **Cobro**                   | Solo por mensualidad (tarifa en `tipos_vehiculos.tarifa_mensual`). No existen tarifas por hora/día                                                                         |
| **Operador/Turno**          | Resueltos a partir del usuario autenticado (JWT). Se crea un turno abierto si no existe                                                                                    |
| **Puerta**                  | Se usa la primera puerta activa configurada en la base de datos                                                                                                            |
| **Mantenimiento**           | Una celda en mantenimiento no recibe vehículos; tiene fecha de fin y se libera automáticamente. No se puede aplicar a una celda ocupada                                    |
| **Inactivar vehículo**      | No se permite si el vehículo está dentro del parqueadero                                                                                                                   |
| **Eliminar celda**          | Solo si no está ocupada y no tiene historial de accesos                                                                                                                    |
| **Reubicación**             | Solo administrador; la celda destino debe estar libre, habilitada y ser del mismo tipo                                                                                     |
| **Usuarios (crear)**        | Solo `administrador` vía `POST /api/auth/register`. Valida unicidad de documento, login y correo; clave de mínimo 4 caracteres cifrada con bcrypt; estado inicial `activo` |
| **Usuarios (editar/clave)** | Requieren `claveAdmin`. Un administrador no puede cambiar su propio rol ni desactivarse                                                                                    |
| **Intentos de login**       | 5 fallidos en 15 min (por usuario o IP) bloquean el acceso temporalmente (423)                                                                                             |
| **Roles**                   | `administrador` y `operador`; las rutas sensibles requieren rol específico                                                                                                 |
| **Zona horaria**            | Las fechas se almacenan en UTC y se presentan en `America/Bogota`                                                                                                          |

## 20. Notas importantes

- **Sin ORM:** El backend utiliza `mysql2/promise` con consultas SQL parametrizadas nativas.
- **JWT:** Configura un `JWT_SECRET` largo y aleatorio en producción. El código exige que exista, pero no valida su longitud.
- **Rate limiting:** 100 req/15 min global (300 en desarrollo) y 10 req/15 min para login.
- **Variables de entorno:** Nunca subas `.env` al repositorio. Usa `.env.example` como referencia.
- **CORS:** `app.js` está configurado actualmente para aceptar cualquier origen; `CORS_ORIGIN` se carga en `envLoader.js` pero no se aplica. Antes de producción conviene restringir el origen al dominio del frontend.
- **Zona horaria:** Las fechas se guardan en UTC (el pool usa `timezone: "Z"`) y se presentan en `America/Bogota`.
- **Base de datos primero:** Debes crear la base con `Script/parqueadero.sql` antes de ejecutar `npm run seed` o iniciar el servidor.
- **Tokens en el navegador:** el frontend guarda el token de acceso, el refresh token y los datos básicos del usuario en `localStorage`.
- **Dependencias sin uso:** `axios` está declarado en `frontend/package.json`, pero el cliente HTTP usa `fetch`.
- **Pruebas:** Ejecuta `npm test` en `backend/` (requiere BD configurada y sembrada).

// Configuracion de Express. La API usa autenticacion JWT (Bearer) en rutas protegidas.

import express from "express";
import cors from "cors";
import helmet from "helmet";
import rateLimit from "express-rate-limit";
import { env } from "./config/envLoader.js";
import routes from "./routes/index.js";

const app = express();

// Detrás de Nginx / load balancer, confiar en X-Forwarded-For para que
// req.ip sea la IP real del cliente (necesario para rate limiting y para
// login_attempts.ip_address). Se configura con TRUST_PROXY en .env:
//   0       -> sin proxy (default, desarrollo)
//   1       -> un proxy delante
//   2       -> dos (ej. Cloudflare + Nginx)
//   loopback|1.2.3.4 -> confiar solo en esas direcciones
if (env.TRUST_PROXY && env.TRUST_PROXY !== "0") {
  const n = Number.parseInt(env.TRUST_PROXY, 10);
  app.set("trust proxy", Number.isFinite(n) ? n : env.TRUST_PROXY);
}

// Headers de seguridad (CSP, HSTS, X-Frame-Options, etc.)
app.use(helmet());

// CORS debe ir ANTES de rate limiting para que las preflight OPTIONS
// reciban Access-Control-Allow-Origin sin ser bloqueadas por el limitador.
app.use(cors({ origin: (origin, cb) => cb(null, true) }));
app.use(express.json());

// Rate limiting global básico.
// En desarrollo se usa un límite más alto para evitar 429 por recargas
// y StrictMode de React (que monta componentes dos veces).
const isDev = env.NODE_ENV === "development";
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: isDev ? 300 : 100,
  standardHeaders: true,
  legacyHeaders: false,
  // /api/health no cuenta para el límite
  skip: (req) => req.path === "/api/health",
});
app.use(limiter);

// Rate limiting más estricto para login (10 req / 15 min por IP)
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 10,
  standardHeaders: true,
  legacyHeaders: false,
});
app.use("/api/auth/login", loginLimiter);

app.use("/api", routes);
app.use("/api", (_req, res) =>
  res.status(404).json({ error: "Ruta no encontrada" }),
);

// Manejador final: siempre responde JSON (Express 5 reenvía los errores async aquí)
app.use((err, _req, res, _next) => {
  console.error(err);
  const status = err.status ?? 500;
  res.status(status).json({
    error: status === 500 ? "Error interno del servidor" : err.message,
  });
});

export default app;

import { readFileSync } from "fs";

const __dirname = fileURLToPath(new URL(".", import.meta.url));
const envPath = join(__dirname, "..", "..", ".env");

try {
  const contenido = readFileSync(envPath, "utf8");
  for (const linea of contenido.split(/\r?\n/)) {
    const texto = linea.trim();
    if (!texto || texto.startsWith("#")) continue;
    const igual = texto.indexOf("=");
    if (igual === -1) continue;
    const clave = texto.slice(0, igual).trim();
    let valor = texto.slice(igual + 1).trim();
    if (
      (valor.startsWith('"') && valor.endsWith('"')) ||
      (valor.startsWith("'") && valor.endsWith("'"))
    ) {
      valor = valor.slice(1, -1);
    }
    if (!(clave in process.env)) process.env[clave] = valor;
  }
} catch {
  console.warn(
    "No se encontro backend/.env: se usan las variables del sistema.",
  );
}

// Gestión completa de celdas (RF3).
//   GET    /api/celdas                 listar con filtros (tipo, bloque, estado) y paginación

//   PATCH  /api/celdas/:id/estado      activar/inactivar / mantenimiento (RF3.7)
//   GET    /api/celdas/resumen         resumen por tipo: total, libres, asignadas, ocupadas, no disponibles (RF3.9)

import { query } from "../config/db.js";

/**
 * Deriva el estado de una celda en SQL:
 *   inactiva, en mantenimiento, ocupada (acceso abierto), asignada (celda fija de vehículo activo), libre.
 */
async function liberarMantenimientosExpirados() {
  await query(
    `UPDATE celdas
     SET en_mantenimiento = FALSE, mantenimiento_hasta = NULL
     WHERE en_mantenimiento = TRUE
       AND mantenimiento_hasta IS NOT NULL
       AND mantenimiento_hasta <= UTC_TIMESTAMP()`,
  );
}

const ESTADO_SQL = `
  CASE
    WHEN c.activa = FALSE THEN 'inactiva'
    WHEN c.en_mantenimiento = TRUE AND (c.mantenimiento_hasta IS NULL OR c.mantenimiento_hasta > UTC_TIMESTAMP()) THEN 'en mantenimiento'
    WHEN EXISTS (
      SELECT 1 FROM accesos_vehiculos a
      WHERE a.id_celda = c.id_celda AND a.fecha_salida IS NULL
    ) THEN 'ocupada'
    ELSE 'libre'
  END
`;

/**
 * GET /api/celdas - Listar celdas con filtros y paginación.
 * Filtros: tipo (carro|moto), bloque (letra), estado (libre|asignada|ocupada|en mantenimiento|inactiva).
 */
export const listarCeldas = async (req, res) => {
  try {
    await liberarMantenimientosExpirados();
    const { tipo, bloque, estado, page = 1, limit = 20 } = req.query;
    const p = Math.max(Number.parseInt(page, 10) || 1, 1);
    const l = Math.max(Math.min(Number.parseInt(limit, 10) || 20, 100), 1);
    const offset = (p - 1) * l;

    const conds = [];
    const params = [];

    if (tipo === "carro" || tipo === "moto") {
      conds.push(
        `c.id_tipo_vehiculo = (SELECT id_tipo_vehiculo FROM tipos_vehiculos WHERE codigo = ? LIMIT 1)`,
      );
      params.push(tipo);
    }
    if (bloque) {
      conds.push(`c.letra = ?`);
      params.push(String(bloque).toUpperCase());
    }

    if (estado) {
      const e = String(estado).toLowerCase();
      if (e === "inactiva") {
        conds.push(`c.activa = FALSE`);
      } else if (e === "en mantenimiento") {
        conds.push(`c.en_mantenimiento = TRUE AND c.activa = TRUE`);
      } else if (e === "ocupada") {
        conds.push(
          `EXISTS (SELECT 1 FROM accesos_vehiculos a WHERE a.id_celda = c.id_celda AND a.fecha_salida IS NULL)`,
        );
      } else if (e === "asignada") {
        // Ya no existen celdas fijas, por lo que ninguna celda puede estar "asignada"
        conds.push(`1 = 0`);
      } else if (e === "libre") {
        conds.push(`c.activa = TRUE AND c.en_mantenimiento = FALSE
          AND NOT EXISTS (SELECT 1 FROM accesos_vehiculos a WHERE a.id_celda = c.id_celda AND a.fecha_salida IS NULL)`);
      } else {
        return res.status(400).json({ error: "Estado inválido" });
      }
    }

    const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";

    const rows = await query(
      `SELECT c.id_celda, c.codigo, c.letra, c.numero, c.id_tipo_vehiculo,
              tv.nombre AS tipo, tv.codigo AS tipo_codigo,
              c.activa, c.en_mantenimiento, c.fecha_creacion,
              NULL AS placa_asignada,
              (SELECT v.placa FROM accesos_vehiculos a
                INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
                WHERE a.id_celda = c.id_celda AND a.fecha_salida IS NULL
                LIMIT 1) AS placa_ocupante,
              ${ESTADO_SQL} AS estado
       FROM celdas c
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = c.id_tipo_vehiculo
       ${where}
       ORDER BY c.letra, c.numero
       LIMIT ? OFFSET ?`,
      [...params, l, offset],
    );

    const countRows = await query(
      `SELECT COUNT(*) AS total FROM celdas c ${where}`,
      params,
    );

    res.json({
      rows,
      total: Number(countRows[0]?.total ?? 0),
      page: p,
      limit: l,
    });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Error al listar las celdas" });
  }
};

/**
 * POST /api/celdas - Crear una celda.
 * RF3.1: letra (bloque), nñmero y tipo de vehñculo; el cñdigo (ej. A-01) se genera automñticamente.
 * RF3.2: impide celdas repetidas (letra + nñmero) y nñmeros menores a 1 (BD lo valida con CHECK).
 */
export const crearCelda = async (req, res) => {
  try {
    const { letra, numero, id_tipo_vehiculo } = req.body ?? {};
    if (!letra || !numero || !id_tipo_vehiculo) {
      return res
        .status(400)
        .json({ error: "Letra, numero y tipo de vehiculo son obligatorios" });
    }
    if (!/^[A-Za-z]$/.test(String(letra))) {
      return res
        .status(400)
        .json({ error: "El bloque debe ser una sola letra (A-Z)" });
    }
    const n = Number.parseInt(numero, 10);
    if (!Number.isFinite(n) || n < 1) {
      return res
        .status(400)
        .json({ error: "El numero de celda debe ser mayor o igual a 1" });
    }

    const tipos = await query(
      `SELECT id_tipo_vehiculo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ? LIMIT 1`,
      [id_tipo_vehiculo],
    );
    if (tipos.length === 0) {
      return res.status(400).json({ error: "Tipo de vehiculo invalido" });
    }

    const existentes = await query(
      `SELECT id_celda FROM celdas WHERE letra = ? AND numero = ? LIMIT 1`,
      [String(letra).toUpperCase(), n],
    );
    if (existentes.length > 0) {
      return res
        .status(409)
        .json({ error: "Ya existe una celda con esa letra y numero" });
    }

    const [tipoInfo] = await query(
      `SELECT codigo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ? LIMIT 1`,
      [id_tipo_vehiculo],
    );
    const maxPorTipo =
      tipoInfo?.codigo === "carro"
        ? 70
        : tipoInfo?.codigo === "moto"
          ? 10
          : null;
    if (maxPorTipo !== null) {
      const [countRows] = await query(
        `SELECT COUNT(*) AS total FROM celdas WHERE id_tipo_vehiculo = ?`,
        [id_tipo_vehiculo],
      );
      const totalActual = Number(
        (Array.isArray(countRows) ? countRows[0] : countRows)?.total ?? 0,
      );
      if (totalActual >= maxPorTipo) {
        return res.status(400).json({
          error: `No se pueden crear más de ${maxPorTipo} celdas para ${tipoInfo.codigo}`,
        });
      }
    }

    const r = await query(
      `INSERT INTO celdas (id_tipo_vehiculo, letra, numero) VALUES (?, ?, ?)`,
      [id_tipo_vehiculo, String(letra).toUpperCase(), n],
    );
    const filas = await query(
      `SELECT id_celda, codigo, letra, numero, id_tipo_vehiculo, activa, en_mantenimiento
       FROM celdas WHERE id_celda = ?`,
      [r.insertId],
    );
    res.status(201).json(filas[0]);
  } catch (err) {
    if (err.code === "ER_DUP_ENTRY") {
      return res
        .status(409)
        .json({ error: "Ya existe una celda con esa letra y numero" });
    }
    console.error(err);
    res.status(500).json({ error: "Error al crear la celda" });
  }
};

/**
 * PATCH /api/celdas/:id/estado - Activar/inactivar o marcar en mantenimiento (RF3.7).
 *   body: { activo: boolean }  o  { en_mantenimiento: boolean }
 * RF3.7: no se permite marcar en mantenimiento o inactiva si estñ ocupada.
 *        Si estñ asignada, primero se reasigna el vehñculo.
 */
export const cambiarEstadoCelda = async (req, res) => {
  try {
    const { activa, en_mantenimiento } = req.body ?? {};
    const [celda] = await query(
      `SELECT id_celda, codigo, activa, en_mantenimiento FROM celdas WHERE id_celda = ?`,
      [req.params.id],
    );
    if (!celda) {
      return res.status(404).json({ error: "Celda no encontrada" });
    }

    const cambios = [];
    const params = [];
    if (typeof activa === "boolean") {
      cambios.push(`activa = ?`);
      params.push(activa);
    }
    if (typeof en_mantenimiento === "boolean") {
      cambios.push(`en_mantenimiento = ?`);
      params.push(en_mantenimiento);
      if (en_mantenimiento) {
        const minutos = Number(
          req.body?.minutos_mantenimiento ?? req.body?.duracion_minutos ?? 60,
        );
        if (!Number.isFinite(minutos) || minutos < 1) {
          return res.status(400).json({
            error: "La duracion del mantenimiento debe ser mayor a 0 minutos",
          });
        }
        cambios.push(
          `mantenimiento_hasta = DATE_ADD(UTC_TIMESTAMP(), INTERVAL ? MINUTE)`,
        );
        params.push(minutos);
      } else {
        cambios.push(`mantenimiento_hasta = NULL`);
      }
    }
    if (cambios.length === 0) {
      return res
        .status(400)
        .json({ error: "Debe indicar activa y/o en_mantenimiento" });
    }

    const vaInactiva = typeof activa === "boolean" ? !activa : !celda.activa;
    const vaMantenimiento =
      typeof en_mantenimiento === "boolean"
        ? en_mantenimiento
        : celda.en_mantenimiento;
    if (vaInactiva || vaMantenimiento) {
      const [ocupada] = await query(
        `SELECT id_acceso FROM accesos_vehiculos WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,
        [req.params.id],
      );
      if (ocupada) {
        return res.status(400).json({
          error:
            "No se puede deshabilitar una celda ocupada. Registre la salida primero.",
        });
      }
      const [asignada] = [];
      if (asignada) {
        return res.status(400).json({
          error:
            "La celda tiene un vehiculo asignado. Reasignelo o librelo antes de cambiar el estado.",
        });
      }
    }

    params.push(req.params.id);
    await query(
      `UPDATE celdas SET ${cambios.join(", ")} WHERE id_celda = ?`,
      params,
    );
    res.json({ mensaje: "Estado de la celda actualizado correctamente" });
  } catch (err) {
    console.error(err);
    res
      .status(500)
      .json({ error: "Error al actualizar el estado de la celda" });
  }
};

/**
 * DELETE /api/celdas/:id - Eliminar una celda (solo si no estñ ocupada, asignada ni tiene historial).
 */
export const eliminarCelda = async (req, res) => {
  try {
    const id = req.params.id;
    const [celda] = await query(
      `SELECT id_celda, codigo FROM celdas WHERE id_celda = ?`,
      [id],
    );
    if (!celda) return res.status(404).json({ error: "Celda no encontrada" });

    const [ocupada] = await query(
      `SELECT id_acceso FROM accesos_vehiculos WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,
      [id],
    );
    if (ocupada) {
      return res
        .status(400)
        .json({ error: "No se puede eliminar una celda ocupada" });
    }

    const [asignada] = [];
    if (asignada) {
      return res.status(400).json({
        error: "No se puede eliminar una celda asignada a un vehiculo",
      });
    }

    const [historial] = await query(
      `SELECT id_acceso FROM accesos_vehiculos WHERE id_celda = ? LIMIT 1`,
      [id],
    );
    if (historial) {
      return res.status(400).json({
        error: "No se puede eliminar una celda con historial de accesos",
      });
    }

    await query(`DELETE FROM celdas WHERE id_celda = ?`, [id]);
    res.json({ mensaje: "Celda eliminada correctamente" });
  } catch (err) {
    if (err.code === "ER_ROW_IS_REFERENCED_2") {
      return res.status(400).json({
        error: "No se puede eliminar la celda porque tiene registros asociados",
      });
    }
    console.error(err);
    res.status(500).json({ error: "Error al eliminar la celda" });
  }
};

      `SELECT
         tv.codigo AS tipo,
         COUNT(*) AS total,

         SUM(CASE WHEN ${ESTADO_SQL} = 'ocupada' THEN 1 ELSE 0 END) AS ocupadas,
         SUM(CASE WHEN ${ESTADO_SQL} IN ('inactiva','en mantenimiento') THEN 1 ELSE 0 END) AS no_disponibles
       FROM celdas c
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = c.id_tipo_vehiculo
       GROUP BY tv.codigo
       ORDER BY tv.codigo`,
    );

    const [totalesRows] = await query(
      `SELECT
         COUNT(*) AS total,
         SUM(CASE WHEN ${ESTADO_SQL} = 'libre' THEN 1 ELSE 0 END) AS libres,
         SUM(CASE WHEN ${ESTADO_SQL} = 'asignada' THEN 1 ELSE 0 END) AS asignadas,
         SUM(CASE WHEN ${ESTADO_SQL} = 'ocupada' THEN 1 ELSE 0 END) AS ocupadas,
         SUM(CASE WHEN ${ESTADO_SQL} IN ('inactiva','en mantenimiento') THEN 1 ELSE 0 END) AS no_disponibles
       FROM celdas c`,
    );
    const totales = totalesRows;

    res.json({ porTipo: filas, totales });

// #16: puerta activa se resuelve desde la BD, no hardcodeada a id=1.
async function puertaActiva(conn) {
  const [rows] = await conn.query(
    `SELECT id_puerta FROM puertas WHERE activa = TRUE
     ORDER BY id_puerta ASC LIMIT 1`,
  );
  if (rows.length === 0) {
    throw new ErrorNegocio(

      "No hay puertas activas configuradas en el parqueadero",
    );
  }
  return rows[0].id_puerta;

// #15: el operador viene SIEMPRE de req.user (middleware autenticar).
// Antes existía un fallback al "primer usuario de la tabla" que podía
// atribuir movimientos a un admin o a un usuario inactivo.
async function operadorYTurno(conn, idUsuario) {
  if (!idUsuario) {
    throw new ErrorNegocio(
      401,
      "Sesión requerida para registrar el movimiento",
    );
  }

  const [turnos] = await conn.query(
    `SELECT id_turno FROM turnos
     WHERE id_usuario = ? AND estado = 'abierto' LIMIT 1`,
    [idUsuario],
  );
  if (turnos.length > 0)
    return { idOperador: idUsuario, idTurno: turnos[0].id_turno };

  const [r] = await conn.query(
    `INSERT INTO turnos (id_usuario, estado, base_inicial) VALUES (?, 'abierto', 0)`,
    [idUsuario],
  );
  return { idOperador: idUsuario, idTurno: r.insertId };
}

async function ejecutar(res, trabajo) {
  const conn = await pool.getConnection();
  try {
    await conn.beginTransaction();
    const { status, body } = await trabajo(conn);
    await conn.commit();
    res.status(status).json(body);
  } catch (err) {
    try {
      await conn.rollback();
    } catch {
      /* conexión ya cerrada */
    }
    if (err instanceof ErrorNegocio) {
      return res.status(err.status).json({ error: err.message });
    }
    if (err.code === "ER_DUP_ENTRY") {
      return res.status(409).json({
        error: "El vehículo ya está adentro o la celda ya fue ocupada",
      });
    }
    console.error("Error en movimiento:", err);
    res.status(500).json({ error: "Error interno al registrar el movimiento" });
  } finally {
    conn.release();
  }
}

export const registrarEntrada = (req, res) => {
  const { placa, id_celda } = req.body ?? {};
  if (!placa || !id_celda) {
    return res.status(400).json({ error: "Placa y celda requeridos" });
  }

  return ejecutar(res, async (conn) => {
    const formato = validarPlaca(placa);
    if (!formato.valida) throw new ErrorNegocio(400, formato.error);

    const [vehiculos] = await conn.query(
      `SELECT v.id_vehiculo, v.placa, v.id_tipo_vehiculo,
              tv.nombre AS tipo, tv.codigo AS tipo_codigo
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       WHERE v.placa = ? AND v.activo = TRUE
       LIMIT 1`,
      [formato.placa],
    );
    if (vehiculos.length === 0)
      throw new ErrorNegocio(404, "Vehículo no encontrado");
    const v = vehiculos[0];

    if (!validarPlaca(v.placa, v.tipo_codigo).valida) {
      throw new ErrorNegocio(
        400,
        `La placa ${v.placa} no tiene el formato válido para ${v.tipo}`,
      );
    }

    const [dentro] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos
       WHERE id_vehiculo = ? AND fecha_salida IS NULL LIMIT 1`,
      [v.id_vehiculo],
    );
    if (dentro.length > 0)
      throw new ErrorNegocio(400, "El vehículo ya está adentro");

    const [mensualidad] = await conn.query(
      `SELECT (fecha_fin >= DATE(UTC_TIMESTAMP() - INTERVAL 5 HOUR)) AS vigente
       FROM mensualidades
       WHERE id_vehiculo = ? AND estado = 'activa'
       ORDER BY fecha_fin DESC LIMIT 1`,
      [v.id_vehiculo],
    );
    if (!mensualidad.length) {
      throw new ErrorNegocio(403, "El vehículo no tiene mensualidad activa");
    }
    if (!mensualidad[0].vigente) {
      throw new ErrorNegocio(403, "La mensualidad del vehículo está en mora");
    }

    const [celdas] = await conn.query(
      `SELECT id_celda, codigo, id_tipo_vehiculo FROM celdas
       WHERE id_celda = ? AND activa = TRUE AND en_mantenimiento = FALSE
       LIMIT 1`,
      [id_celda],
    );
    if (celdas.length === 0) {
      throw new ErrorNegocio(400, "La celda no existe o no está habilitada");
    }
    const c = celdas[0];
    if (c.id_tipo_vehiculo !== v.id_tipo_vehiculo) {
      throw new ErrorNegocio(
        400,
        "La celda no es compatible con el tipo de vehículo",
      );
    }

    const [ocupada] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos
       WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,
      [c.id_celda],
    );
    if (ocupada.length > 0)
      throw new ErrorNegocio(400, "La celda ya está ocupada");

    const { idOperador, idTurno } = await operadorYTurno(
      conn,
      req.user?.id_usuario,
    );
    const idPuerta = await puertaActiva(conn);

    const [r] = await conn.query(
      `INSERT INTO accesos_vehiculos
         (id_vehiculo, id_celda, id_puerta_ingreso, id_operador_ingreso, id_turno_ingreso)
       VALUES (?, ?, ?, ?, ?)`,
      [v.id_vehiculo, c.id_celda, idPuerta, idOperador, idTurno],
    );
    const idAcceso = r.insertId;

    await auditar(conn, {
      idUsuario: idOperador,
      login: req.user?.usuario_login,
      accion: "entrada",
      detalle: `Vehículo ${v.placa} ingresó a celda ${c.codigo}`,
      ip: req.ip,
    });

    return {
      status: 201,
      body: {
        id: idAcceso,
        placa: v.placa,
        tipo: v.tipo,
        celda: c.codigo,
        accion: "entrada",
        ...fechaHoraActual(),
      },
    };
  });
};

export const registrarSalida = (req, res) => {
  const { placa } = req.body ?? {};
  if (!placa) return res.status(400).json({ error: "Placa requerida" });

  return ejecutar(res, async (conn) => {
    const formato = validarPlaca(placa);
    if (!formato.valida) throw new ErrorNegocio(400, formato.error);

    const [vehiculos] = await conn.query(
      `SELECT v.id_vehiculo, v.placa, tv.nombre AS tipo, tv.codigo AS tipo_codigo
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       WHERE v.placa = ?
       LIMIT 1`,
      [formato.placa],
    );
    if (vehiculos.length === 0)
      throw new ErrorNegocio(404, "Vehículo no encontrado");
    const v = vehiculos[0];

    if (!validarPlaca(v.placa, v.tipo_codigo).valida) {
      throw new ErrorNegocio(
        400,
        `La placa ${v.placa} no tiene el formato válido para ${v.tipo}`,
      );
    }

    const [accesos] = await conn.query(
      `SELECT a.id_acceso, c.codigo AS celda
       FROM accesos_vehiculos a
       INNER JOIN celdas c ON c.id_celda = a.id_celda
       WHERE a.id_vehiculo = ? AND a.fecha_salida IS NULL
       ORDER BY a.fecha_ingreso DESC
       LIMIT 1`,
      [v.id_vehiculo],
    );
    if (accesos.length === 0)
      throw new ErrorNegocio(400, "El vehículo no está adentro");
    const acceso = accesos[0];

    const { idOperador, idTurno } = await operadorYTurno(
      conn,
      req.user?.id_usuario,
    );
    const idPuerta = await puertaActiva(conn);

    await conn.query(
      `UPDATE accesos_vehiculos
       SET fecha_salida = UTC_TIMESTAMP(),
           id_operador_salida = ?,
           id_puerta_salida = ?,
           id_turno_salida = ?
       WHERE id_acceso = ?`,
      [idOperador, idPuerta, idTurno, acceso.id_acceso],
    );

    await auditar(conn, {
      idUsuario: idOperador,
      login: req.user?.usuario_login,
      accion: "salida",
      detalle: `Vehículo ${v.placa} salió de celda ${acceso.celda}`,
      ip: req.ip,
    });

    return {
      status: 200,
      body: {
        id: acceso.id_acceso,
        placa: v.placa,
        tipo: v.tipo,
        celda: acceso.celda,
        accion: "salida",
        ...fechaHoraActual(),
      },
    };
  });
};

// REUBICACIÓN
// ---------------------------------------------------------------------------
export const registrarReubicacion = async (req, res) => {
  const { id_acceso } = req.params ?? {};
  const { id_celda } = req.body ?? {};
  if (!id_acceso) return res.status(400).json({ error: "Acceso requerido" });
  if (!id_celda) return res.status(400).json({ error: "Celda requerida" });

  return ejecutar(res, async (conn) => {
    const [accesos] = await conn.query(
      `SELECT a.id_acceso, a.id_vehiculo, v.placa, v.id_tipo_vehiculo,
              co.codigo AS celda_origen
       FROM accesos_vehiculos a
       INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
       INNER JOIN celdas co ON co.id_celda = a.id_celda
       WHERE a.id_acceso = ? AND a.fecha_salida IS NULL
       LIMIT 1`,
      [id_acceso],
    );
    if (accesos.length === 0)
      throw new ErrorNegocio(
        404,
        "Acceso no encontrado o el vehículo ya salió",
      );
    const acceso = accesos[0];

    const [celdas] = await conn.query(
      `SELECT id_celda, codigo FROM celdas
       WHERE id_celda = ? AND activa = TRUE AND en_mantenimiento = FALSE
         AND id_tipo_vehiculo = ?
       LIMIT 1`,
      [id_celda, acceso.id_tipo_vehiculo],
    );
    if (celdas.length === 0)
      throw new ErrorNegocio(
        400,
        "La celda no existe, no está habilitada o no es del tipo del vehículo",
      );
    const c = celdas[0];

    const [ocupada] = await conn.query(
      `SELECT id_acceso FROM accesos_vehiculos
       WHERE id_celda = ? AND fecha_salida IS NULL LIMIT 1`,
      [c.id_celda],
    );
    if (ocupada.length > 0)
      throw new ErrorNegocio(400, "La celda ya está ocupada");

    const { idOperador } = await operadorYTurno(conn, req.user?.id_usuario);

    await conn.query(
      `UPDATE accesos_vehiculos SET id_celda = ? WHERE id_acceso = ?`,
      [c.id_celda, acceso.id_acceso],
    );

    await auditar(conn, {
      idUsuario: idOperador,
      login: req.user?.usuario_login,
      accion: "reubicacion",
      detalle: `Vehículo ${acceso.placa} reubicado de celda ${acceso.celda_origen} a celda ${c.codigo}`,
      ip: req.ip,
    });

    return {
      status: 200,
      body: {
        id: acceso.id_acceso,
        placa: acceso.placa,
        celda_origen: acceso.celda_origen,
        celda: c.codigo,
        accion: "reubicacion",
      },
    };
  });
};

// HISTORIAL
// ---------------------------------------------------------------------------
export const listarAccesos = async (req, res) => {
  try {
    const page = Math.max(Number.parseInt(req.query.page, 10) || 1, 1);
    const limit = Math.max(
      Math.min(Number.parseInt(req.query.limit, 10) || 20, 100),
      1,
    );
    const offset = (page - 1) * limit;

    const placa = String(req.query.placa ?? "")
      .trim()
      .toUpperCase();
    const celda = String(req.query.celda ?? "")
      .trim()
      .toUpperCase();
    const operador = String(req.query.operador ?? "").trim();
    const estado = String(req.query.estado ?? "")
      .trim()
      .toLowerCase();
    const fechaDesde = String(req.query.fecha_desde ?? "").trim();
    const fechaHasta = String(req.query.fecha_hasta ?? "").trim();

    const conds = [];
    const params = [];

    if (placa) {
      conds.push(`v.placa LIKE ?`);
      params.push(`%${placa}%`);
    }
    if (celda) {
      conds.push(`c.codigo LIKE ?`);
      params.push(`%${celda}%`);
    }
    if (operador) {
      conds.push(
        `(ui.nombres LIKE ? OR ui.apellidos LIKE ? OR us.nombres LIKE ? OR us.apellidos LIKE ?)`,
      );
      const like = `%${operador}%`;
      params.push(like, like, like, like);
    }
    if (estado === "adentro") {
      conds.push(`a.fecha_salida IS NULL`);
      conds.push(
        `a.id_acceso = (SELECT MAX(a2.id_acceso) FROM accesos_vehiculos a2 WHERE a2.id_vehiculo = a.id_vehiculo)`,
      );
    } else if (estado === "fuera") {
      conds.push(`a.fecha_salida IS NOT NULL`);
      conds.push(
        `a.id_acceso = (SELECT MAX(a2.id_acceso) FROM accesos_vehiculos a2 WHERE a2.id_vehiculo = a.id_vehiculo)`,
      );
    }
    if (fechaDesde) {
      conds.push(`DATE(a.fecha_ingreso - INTERVAL 5 HOUR) >= ?`);
      params.push(fechaDesde);
    }
    if (fechaHasta) {
      conds.push(`DATE(a.fecha_ingreso - INTERVAL 5 HOUR) <= ?`);
      params.push(fechaHasta);
    }

    const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";

    const [rows] = await pool.query(
      `SELECT a.id_acceso, v.placa, v.propietario_nombre,
              c.codigo AS celda,
              ui.nombres AS operador_ingreso_nombres,
              ui.apellidos AS operador_ingreso_apellidos,
              us.nombres AS operador_salida_nombres,
              us.apellidos AS operador_salida_apellidos,
              a.fecha_ingreso, a.fecha_salida
       FROM accesos_vehiculos a
       INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
       INNER JOIN celdas c ON c.id_celda = a.id_celda
       INNER JOIN usuarios ui ON ui.id_usuario = a.id_operador_ingreso
       LEFT JOIN usuarios us ON us.id_usuario = a.id_operador_salida
       ${where}
       ORDER BY a.fecha_ingreso DESC
       LIMIT ? OFFSET ?`,
      [...params, limit, offset],
    );

    const [countRows] = await pool.query(
      `SELECT COUNT(*) AS total
       FROM accesos_vehiculos a
       INNER JOIN vehiculos v ON v.id_vehiculo = a.id_vehiculo
       INNER JOIN celdas c ON c.id_celda = a.id_celda
       INNER JOIN usuarios ui ON ui.id_usuario = a.id_operador_ingreso
       LEFT JOIN usuarios us ON us.id_usuario = a.id_operador_salida
       ${where}`,
      params,
    );

    const total = countRows?.[0]?.total ?? 0;

    res.json({ rows, total: Number(total), page, limit });
  } catch (err) {
    console.error(err);
    res
      .status(500)
      .json({ error: "Error al consultar el historial de accesos" });
  }
};

// Controladores de gestión de usuarios (RF1.5, RF1.6, RF1.7, RF1.8 admin).
// Todas las rutas requieren autenticación y, salvo listar/obtener, rol de administrador.

import * as userService from "../services/userServices.js";
import * as authService from "../services/authService.js";
import { validarClave } from "../middleware/validation.js";

/**
 * Re-autenticación del administrador que ejecuta la acción.
 * Valida la `claveAdmin` contra la clave del usuario autenticado (req.user).
 * Devuelve { status, error } si falla (clave faltante o incorrecta);
 * null si la clave es válida.
 */
const verificarClaveAdmin = async (req, claveAdmin) => {
  if (!claveAdmin)
    return { status: 422, error: "Debe confirmar con su clave de administrador" };
  const r = await authService.verificarClaveUsuario({
    usuario_login: req.user.usuario_login,
    clave: claveAdmin,
  });
  // null => clave válida; { status, error } => fallo de verificación.
  // Se devuelve null para que el controlador pueda usar `if (verif)`.
  return r.error ? r : null;
};

/**
 * GET /api/users
 * RF1.5 - Listar y buscar usuarios con paginación.
 */
export const listar = async (req, res) => {
  const { search, rol, estado, page, limit } = req.query;
  const resultado = await userService.listarUsuarios({
    search,
    rol,
    estado,
    page,
    limit,
  });
  res.json(resultado);
};

/**
 * GET /api/users/:id
 * Obtener un usuario por id.
 */
export const obtener = async (req, res) => {
  const resultado = await userService.obtenerUsuario(Number(req.params.id));
  res
    .status(resultado.status)
    .json(resultado.error ? { error: resultado.error } : resultado.body);
};

/**
 * PUT /api/users/:id
 * RF1.6 - Editar datos y cambiar rol (solo administrador).
 */
export const actualizar = async (req, res) => {
  const id = Number(req.params.id);
  // El estado se cambia por PATCH /estado, no por aquí.
  // claveAdmin se usa para re-autenticar al admin, no se persiste en el usuario.
  const { estado: _ignorado, claveAdmin, ...datos } = req.body ?? {};
  // Re-autenticación: el admin debe confirmar su clave antes de modificar datos.
  const verif = await verificarClaveAdmin(req, claveAdmin);
  if (verif) return res.status(verif.status).json({ error: verif.error });
  // Evita que el admin se quite el rol a sí mismo y se bloquee
  if (id === req.user.id_usuario && datos.rol && datos.rol !== req.user.rol) {
    return res.status(400).json({ error: "No puede cambiar su propio rol" });
  }
  const resultado = await userService.editarUsuario(id, datos);
  res
    .status(resultado.status)
    .json(resultado.error ? { error: resultado.error } : resultado.body);
};

/**
 * PATCH /api/users/:id/estado
 * RF1.7 - Activar o desactivar un usuario (solo administrador).
 */
export const cambiarEstado = async (req, res) => {
  const id = Number(req.params.id);
  const { estado } = req.body ?? {};
  if (id === req.user.id_usuario && estado === "inactivo") {
    return res.status(400).json({ error: "No puede desactivarse a sí mismo" });
  }
  const resultado = await userService.cambiarEstadoUsuario(id, estado);
  res
    .status(resultado.status)
    .json(resultado.error ? { error: resultado.error } : resultado.body);
};

/**
 * PATCH /api/users/:id/password
 * RF1.8 - Restablecer la clave de otro usuario (solo administrador).
 */
export const restablecerPassword = async (req, res) => {
  const { clave, claveAdmin } = req.body ?? {};
  const errorClave = validarClave(clave);
  if (errorClave) return res.status(400).json({ error: errorClave });
  // Re-autenticación: el admin debe confirmar su clave antes de cambiar la de otro.
  const verif = await verificarClaveAdmin(req, claveAdmin);
  if (verif) return res.status(verif.status).json({ error: verif.error });
  const resultado = await authService.restablecerClave({
    idUsuario: Number(req.params.id),
    claveNueva: clave,
  });
  res
    .status(resultado.status)
    .json(resultado.error ? { error: resultado.error } : resultado.body);
};

export default {
  listar,
  obtener,
  actualizar,
  cambiarEstado,
  restablecerPassword,
};

import { query } from "../config/db.js";

/**
 * GET /api/vehiculos/:placa - Devuelve lo que necesita la pantalla de ingreso/salida.
 */
export const buscarVehiculoPorPlaca = async (req, res) => {
  try {
    const formato = validarPlaca(req.params.placa);
    if (!formato.valida) {
      return res.status(400).json({ error: formato.error });
    }

    const [v] = await query(
      `SELECT v.id_vehiculo, v.placa, v.propietario_nombre,
              v.modelo, v.nombre_modelo, v.color,
              
              tv.codigo AS tipo_codigo, tv.nombre AS tipo, tv.tarifa_mensual
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       WHERE v.placa = ? AND v.activo = TRUE
       LIMIT 1`,
      [formato.placa],
    );
    if (!v) return res.status(404).json({ error: "Vehículo no encontrado" });

    const [accesoAbierto] = await query(
      `SELECT id_acceso FROM accesos_vehiculos
       WHERE id_vehiculo = ? AND fecha_salida IS NULL LIMIT 1`,
      [v.id_vehiculo],
    );

    // Estado derivado: fecha_fin vs HOY en Bogotá (UTC-5), consistente con
    // movimientoController. Así un vehículo no aparece "En mora" 5 horas
    // antes de que termine realmente su mensualidad en hora local.
    const [mensualidad] = await query(
      `SELECT (fecha_fin >= DATE(UTC_TIMESTAMP() - INTERVAL 5 HOUR)) AS vigente
       FROM mensualidades
       WHERE id_vehiculo = ? AND estado = 'activa'
       ORDER BY fecha_fin DESC LIMIT 1`,
      [v.id_vehiculo],
    );

    let estadoMensualidad = "Sin mensualidad";
    if (mensualidad) {
      estadoMensualidad = mensualidad.vigente ? "Al día" : "En mora";
    }

    res.json({
      id: v.id_vehiculo,
      placa: v.placa,
      estado: accesoAbierto ? "Adentro" : "Fuera",
      mensualidad: v.tarifa_mensual,
      tipo: v.tipo,
      tipoCodigo: v.tipo_codigo,
      modelo: v.modelo ?? "",
      nombreModelo: v.nombre_modelo ?? "",
      color: v.color ?? "",

      usuario: v.propietario_nombre,
      estadoMensualidad,
    });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Error al consultar el vehículo" });
  }
};

/**
 * GET /api/vehiculos - Listar y buscar vehículos y propietarios.
 * Filtros: q (placa, documento o nombre), tipo, activo. Paginación.
 * RF2.3 - Consultar vehículos y propietarios por placa, documento o nombre.
 */
export const listarVehiculos = async (req, res) => {
  try {
    const { q, tipo, activo, page = 1, limit = 10 } = req.query;
    const p = Math.max(Number.parseInt(page, 10) || 1, 1);
    const l = Math.max(Math.min(Number.parseInt(limit, 10) || 10, 100), 1);
    const offset = (p - 1) * l;

    const conds = [];
    const params = [];

    if (q) {
      conds.push(
        `(v.placa LIKE ? OR v.propietario_documento LIKE ? OR v.propietario_nombre LIKE ?)`,
      );
      const s = `%${q}%`;
      params.push(s, s, s);
    }
    if (tipo === "carro" || tipo === "moto") {
      conds.push(
        `v.id_tipo_vehiculo = (SELECT id_tipo_vehiculo FROM tipos_vehiculos WHERE codigo = ? LIMIT 1)`,
      );
      params.push(tipo);
    }
    if (activo !== undefined) {
      conds.push(`v.activo = ?`);
      params.push(activo === "true" ? 1 : 0);
    }

    const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";

    const rows = await query(
      `SELECT v.id_vehiculo, v.placa, v.color, v.modelo, v.nombre_modelo,
              v.propietario_nombre, v.propietario_tipo_documento,
              v.propietario_documento, v.propietario_telefono,
              v.propietario_email, v.activo,
              tv.nombre AS tipo, tv.codigo AS tipo_codigo
       FROM vehiculos v
       INNER JOIN tipos_vehiculos tv ON tv.id_tipo_vehiculo = v.id_tipo_vehiculo
       ${where}
       ORDER BY v.fecha_registro DESC
       LIMIT ? OFFSET ?`,
      [...params, l, offset],
    );

    const countRows = await query(
      `SELECT COUNT(*) AS total FROM vehiculos v ${where}`,
      params,
    );

    res.json({
      rows,
      total: Number(countRows[0]?.total ?? 0),
      page: p,
      limit: l,
    });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Error al listar los vehículos" });
  }
};

/**
 * POST /api/vehiculos - Registrar un vehículo con datos del propietario.
 * RF2.1 - placa, tipo, color, año, nombre modelo, propietario (nombre, tipo y número
 *         de documento, teléfono, correo).
 * RF2.2 - placa única y entre 5 y 8 caracteres (BD lo valida con CHECK y UNIQUE).
 */
export const crearVehiculo = async (req, res) => {
  try {
    const {
      id_tipo_vehiculo,
      placa,
      color,
      modelo,
      nombre_modelo,
      propietario_nombre,
      propietario_tipo_documento,
      propietario_documento,
      propietario_telefono,
      propietario_email,
    } = req.body ?? {};

    const formato = validarPlaca(placa);
    if (!formato.valida) {
      return res.status(400).json({ error: formato.error });
    }

    const obligatorios = [
      id_tipo_vehiculo,
      placa,
      color,
      modelo,
      nombre_modelo,
      propietario_nombre,
      propietario_documento,
    ];
    if (obligatorios.some((v) => v === undefined || v === null || v === "")) {
      return res.status(400).json({
        error:
          "Todos los campos obligatorios del vehículo y propietario son requeridos",
      });
    }

    // Verificar que el tipo de vehículo exista.
    const tipos = await query(
      `SELECT id_tipo_vehiculo, codigo FROM tipos_vehiculos WHERE id_tipo_vehiculo = ? LIMIT 1`,
      [id_tipo_vehiculo],
    );
    if (tipos.length === 0) {
      return res.status(400).json({ error: "Tipo de vehículo inválido" });
    }
    // La placa debe corresponder al tipo elegido
    const formatoTipo = validarPlaca(placa, tipos[0].codigo);
    if (!formatoTipo.valida) {
      return res.status(400).json({ error: formatoTipo.error });
    }

    const r = await query(
      `INSERT INTO vehiculos
         (id_tipo_vehiculo, placa, color, modelo, nombre_modelo,
          propietario_nombre, propietario_tipo_documento, propietario_documento,
          propietario_telefono, propietario_email, activo)
       VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, NULL, TRUE)`,
      [
        id_tipo_vehiculo,
        formato.placa,
        color,
        modelo,
        nombre_modelo,
        propietario_nombre,
        propietario_tipo_documento,
        propietario_documento,
        propietario_telefono ?? null,
        propietario_email ?? null,
      ],
    );
    res.status(201).json({ id_vehiculo: r.insertId, placa: formato.placa });
  } catch (err) {
    if (err.code === "ER_DUP_ENTRY") {
      return res
        .status(409)
        .json({ error: "Ya existe un vehículo con esa placa" });
    }
    console.error(err);
    res.status(500).json({ error: "Error al registrar el vehículo" });
  }
};

/**
 * PUT /api/vehiculos/:placa - Editar los datos del vehículo y del propietario.
 * RF2.4.
 */
export const actualizarVehiculo = async (req, res) => {
  try {
    const formato = validarPlaca(req.params.placa);
    if (!formato.valida) {
      return res.status(400).json({ error: formato.error });
    }

    const {
      color,
      modelo,
      nombre_modelo,
      propietario_nombre,
      propietario_tipo_documento,
      propietario_documento,
      propietario_telefono,
      propietario_email,
      activo,
    } = req.body ?? {};

    const [v] = await query(
      `SELECT id_vehiculo FROM vehiculos WHERE placa = ? LIMIT 1`,
      [formato.placa],
    );
    if (!v) {
      return res.status(404).json({ error: "Vehículo no encontrado" });
    }

    const sets = [];
    const params = [];
    const mapeo = {
      color,
      modelo,
      nombre_modelo,
      propietario_nombre,
      propietario_tipo_documento,
      propietario_documento,
      propietario_telefono,
      propietario_email,
    };
    for (const [campo, valor] of Object.entries(mapeo)) {
      if (valor !== undefined && valor !== null) {
        sets.push(`${campo} = ?`);
        params.push(valor);
      }
    }
    if (activo !== undefined) {
      sets.push(`activo = ?`);
      params.push(activo === true || activo === "true" ? 1 : 0);
    }
    if (sets.length === 0) {
      return res.status(400).json({ error: "No hay campos para actualizar" });
    }

    params.push(formato.placa);
    await query(
      `UPDATE vehiculos SET ${sets.join(", ")} WHERE placa = ?`,
      params,
    );
    res.json({ mensaje: "Vehículo actualizado correctamente" });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Error al actualizar el vehículo" });
  }
};

 * RF2.5: No se permite si el vehículo está dentro del parqueadero.

 */

      return res.status(400).json({ error: formato.error });

    if (activo === undefined) {

      `SELECT id_vehiculo FROM vehiculos WHERE placa = ? LIMIT 1`,
      [formato.placa],
    );
    if (!v) {
      return res.status(404).json({ error: "Vehículo no encontrado" });
    }

    // RF2.5: no se permite desactivar si el vehículo está dentro del parqueadero.
    if (activo === false || activo === "false") {

        formato.placa,
      ]);
      return res.json({
        mensaje: "Vehículo desactivado correctamente",
      });
    }

    await query(`UPDATE vehiculos SET activo = TRUE WHERE placa = ?`, [
      formato.placa,
    ]);
    res.json({ mensaje: "Vehículo activado correctamente" });
  } catch (err) {

// Autenticación JWT + autorización por estado de usuario.
// - autenticar: valida el token Bearer, carga el usuario desde la BD y lo deja
//   en req.user (id_usuario, usuario_login, rol, nombres, apellidos, nombreCompleto, estado).
// - generarToken / verificarToken: helpers para firmar y validar JWT.
// Se usa en las rutas que requieren sesión (usuarios, celdas, vehículos, movimientos).

import { query } from "../config/db.js";
import jwt from "jsonwebtoken";
import crypto from "node:crypto";
import * as revokedTokenRepository from "../repositories/revokedTokenRepository.js";

const JWT_SECRET = process.env.JWT_SECRET;
const JWT_EXPIRES_IN = process.env.JWT_EXPIRES_IN || "8h";

if (!JWT_SECRET) {
  throw new Error(
    "Falta la variable de entorno JWT_SECRET. Revisa backend/.env (modelo en backend/.env.example).",
  );
}

/**
 * Firma un payload y devuelve el token JWT.
 * @param {object} payload - Datos mínimos del usuario (no incluir datos sensibles).
 * @returns {string}
 */
export const generarToken = (payload) => {
  const jti = crypto.randomUUID();
  return jwt.sign({ id_usuario: payload, jti }, JWT_SECRET, {
    expiresIn: JWT_EXPIRES_IN,
  });
};

/**
 * Verifica y decodifica un token JWT.
 * @param {string} token
 * @returns {object} payload decodificado
 */
export const verificarToken = (token) => jwt.verify(token, JWT_SECRET);

/**
 * Middleware de autenticación obligatoria.
 * Requiere header: Authorization: Bearer <token>
 */
export const autenticar = async (req, res, next) => {
  try {
    const authHeader = req.headers.authorization || "";
    const partes = authHeader.split(" ");
    if (
      partes.length !== 2 ||
      partes[0].toLowerCase() !== "bearer" ||
      !partes[1]
    ) {
      return res.status(401).json({ error: "Token de acceso requerido" });
    }

    const decoded = verificarToken(partes[1]);

    if (decoded.jti && (await revokedTokenRepository.estaRevocado(decoded.jti))) {
      return res.status(401).json({ error: "Token revocado o sesión cerrada" });
    }

    const usuarios = await query(
      `SELECT id_usuario, usuario_login, rol, nombres, apellidos, estado, ultimo_acceso
       FROM usuarios
       WHERE id_usuario = ?`,
      [decoded.id_usuario],
    );

    if (usuarios.length === 0) {
      return res.status(401).json({ error: "Usuario no encontrado" });
    }

    const u = usuarios[0];
    if (u.estado !== "activo") {
      return res
        .status(403)
        .json({ error: "Usuario inactivo. No puede iniciar sesión." });
    }

    req.user = {
      id_usuario: u.id_usuario,
      usuario_login: u.usuario_login,
      rol: u.rol,
      nombres: u.nombres,
      apellidos: u.apellidos,
      nombreCompleto: `${u.nombres} ${u.apellidos}`,
      estado: u.estado,
    };

    next();
  } catch (err) {
    if (err.name === "TokenExpiredError") {
      return res
        .status(401)
        .json({ error: "Sesión expirada. Inicie sesión de nuevo." });
    }
    if (err.name === "JsonWebTokenError") {
      return res.status(401).json({ error: "Token inválido" });
    }
    next(err);
  }
};

/**
 * Middleware opcional: si hay token válido carga el usuario, si no, continúa sin req.user.
 * Útil para rutas públicas que quieren personalizar si hay sesión.
 */
export const opcional = async (req, res, next) => {
  try {
    const authHeader = req.headers.authorization || "";
    const partes = authHeader.split(" ");
    if (
      partes.length === 2 &&
      partes[0].toLowerCase() === "bearer" &&
      partes[1]
    ) {
      const decoded = verificarToken(partes[1]);
      const usuarios = await query(
        `SELECT id_usuario, usuario_login, rol, nombres, apellidos, email, telefono, estado, ultimo_acceso
        FROM usuarios WHERE id_usuario = ?`,
        [decoded.id_usuario],
      );
      if (usuarios.length > 0 && usuarios[0].estado === "activo") {
        const u = usuarios[0];
        req.user = {
          id_usuario: u.id_usuario,
          usuario_login: u.usuario_login,
          rol: u.rol,
          nombres: u.nombres,
          apellidos: u.apellidos,
          nombreCompleto: `${u.nombres} ${u.apellidos}`,
          email: u.email,
          telefono: u.telefono,
          estado: u.estado,
        };
      }
    }
    next();
  } catch {
    next();
  }
};

export default { autenticar, opcional, generarToken, verificarToken };

// Helpers de validación de cuerpo de solicitud para las rutas de usuarios.
// No se agregan nuevas dependencias: se valida de forma manual y clara.

export const REQUIRED_USER_FIELDS = [
  "rol",
  "tipo_documento",
  "documento",
  "nombres",
  "apellidos",
  "usuario_login",
  "clave",
];

export const VALID_ROLES = ["administrador", "operador"];
export const VALID_TIPOS_DOCUMENTO = ["cc", "ce", "nit", "pasaporte"];

/**
 * Valida los campos obligatorios de un registro/actualización de usuario.
 * @param {object} body
 * @returns {null | string} null si es válido, mensaje de error si no.
 */
export const validarDatosUsuario = (body, { requiereClave = true } = {}) => {
  if (!body || typeof body !== "object") return "Cuerpo de solicitud inválido";

  const obligatorios = requiereClave
    ? REQUIRED_USER_FIELDS
    : REQUIRED_USER_FIELDS.filter((c) => c !== "clave");

  for (const campo of obligatorios) {
    const valor = body[campo];
    if (valor === undefined || valor === null || valor === "") {
      return `El campo "${campo}" es obligatorio`;
    }
  }
  if (!VALID_ROLES.includes(body.rol)) {
    return `Rol inválido. Debe ser uno de: ${VALID_ROLES.join(", ")}`;
  }
  if (!VALID_TIPOS_DOCUMENTO.includes(body.tipo_documento)) {
    return `Tipo de documento inválido. Debe ser uno de: ${VALID_TIPOS_DOCUMENTO.join(", ")}`;
  }
  if (String(body.documento).length < 5 || String(body.documento).length > 20) {
    return "El documento debe tener entre 5 y 20 caracteres";
  }
  if (String(body.usuario_login).length < 3) {
    return "El usuario de acceso debe tener al menos 3 caracteres";
  }
  if (requiereClave && String(body.clave).length < 4) {
    return "La clave debe tener al menos 4 caracteres";
  }
  if (body.email && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(String(body.email))) {
    return "El correo electrónico no tiene un formato válido";
  }
  return null;
};

/**
 * Valida que una nueva clave cumpla el mínimo.
 * @param {string} clave
 * @returns {null | string}
 */
export const validarClave = (clave) => {
  if (!clave || String(clave).length < 4) {
    return "La clave debe tener al menos 4 caracteres";
  }
  return null;
};

export default {
  validarDatosUsuario,
  validarClave,
  REQUIRED_USER_FIELDS,
  VALID_ROLES,
  VALID_TIPOS_DOCUMENTO,
};

 * @returns {object} { rows, total }
 */
export const listar = async ({
  search = "",
  rol = "",
  estado = "",
  page = 1,
  limit = 10,
} = {}) => {
  const p = Number.parseInt(page, 10) || 1;
  const l = Number.parseInt(limit, 10) || 10;

  }
  if (rol) {
    conds.push(`rol = ?`);
    params.push(rol);
  }
  if (estado) {
    conds.push(`estado = ?`);
    params.push(estado);
  }

  const where = conds.length ? `WHERE ${conds.join(" AND ")}` : "";

  const rows = await query(
    `SELECT id_usuario, rol, tipo_documento, documento, nombres, apellidos,
            telefono, email, usuario_login, estado, ultimo_acceso,
            sesion_activa, fecha_sesion_activa, fecha_registro
     FROM usuarios
     ${where}
     ORDER BY fecha_registro DESC
     LIMIT ? OFFSET ?`,
    [...params, l, offset],
  );

  const countRows = await query(
    `SELECT COUNT(*) AS total FROM usuarios ${where}`,
    params,
  );

  return { rows, total: Number(countRows[0]?.total ?? 0), page: p, limit: l };
};

/**
 * Actualiza los datos de un usuario (sin tocar la clave).
 * Campos admitidos: rol, tipo_documento, documento, nombres, apellidos,
 * telefono, email, usuario_login, estado.
 * @returns {boolean} true si se actualizó al menos una fila.
 */
export const actualizar = async (id_usuario, campos) => {
  const permitidos = [
    "rol",
    "tipo_documento",
    "documento",
    "nombres",
    "apellidos",
    "telefono",
    "email",
    "usuario_login",
    "estado",
  ];
  const sets = [];
  const params = [];
  for (const campo of permitidos) {
    if (campo in campos) {
      let valor = campos[campo];
      if ((campo === "telefono" || campo === "email") && valor === "")
        valor = null;
      sets.push(`${campo} = ?`);
      params.push(valor);
    }
  }
  if (sets.length === 0) return false;
  params.push(id_usuario);
  const r = await query(
    `UPDATE usuarios SET ${sets.join(", ")} WHERE id_usuario = ?`,
    params,
  );
  return r.affectedRows > 0;
};

};

/**
 * Cuenta intentos fallidos de un usuario_login y/o IP en una ventana de tiempo.
 * @param {object} opts - { usuario_login, ip_address, minutos }
 * @returns {number}
 */
export const contarFallidosRecientes = async ({
  usuario_login = null,
  ip_address = null,
  minutos = 15,
} = {}) => {
  const conds = [];
  const params = [];
  if (usuario_login) {
    conds.push(`usuario_login = ?`);
    params.push(usuario_login);
  }
  if (ip_address) {
    conds.push(`ip_address = ?`);
    params.push(ip_address);
  }
  conds.push(`exitoso = 0`);
  conds.push(`fecha_intento >= DATE_SUB(UTC_TIMESTAMP(), INTERVAL ? MINUTE)`);
  params.push(minutos);

  const where = conds.join(" AND ");
  const rows = await query(
    `SELECT COUNT(*) AS total FROM login_attempts WHERE ${where}`,
    params,
  );
  return Number(rows[0]?.total ?? 0);
};

    const vencida = new Date(hoy);
    vencida.setDate(vencida.getDate() - 10);

    const plan = [
      ...[1, 2, 3, 4, 5].map((n) => [placaCarro(n), fin, 250000]),
      [placaCarro(6), vencida, 250000],
      ...[1, 2, 3, 4, 5, 6, 7, 8].map((n) => [placaMoto(n), fin, 100000]),
      [placaMoto(9), vencida, 100000],
    ];
    const mensualidades = plan.map(([placa, fechaFin, valor]) => [
      idPorPlaca[placa],
      idOperador,
      ymd(inicio),
      ymd(fechaFin),
      valor,
      "activa",
    ]);
    await conn.query(
      `INSERT INTO mensualidades
         (id_vehiculo, id_usuario_registro, fecha_inicio, fecha_fin, valor, estado)
       VALUES ?`,
      [mensualidades],
    );
    console.log(`Mensualidades creadas: ${mensualidades.length}`);

    await conn.commit();
    console.log("Seed completado.");
  } catch (err) {
    await conn.rollback();
    console.error("Error durante el seed:", err.message);
    process.exitCode = 1;
  } finally {
    conn.release();
    await pool.end();
  }
}

// Lógica de negocio de autenticación: registro, login, cambio/restablecimiento de clave,
// control de intentos fallidos (fuerza bruta) y registro de último acceso.
// Usa bcryptjs para cifrar claves y jsonwebtoken para los tokens de acceso.

import bcrypt from "bcryptjs";
import { generarToken, verificarToken } from "../middleware/authMiddleware.js";
import * as userRepository from "../repositories/userRepository.js";
import * as refreshTokenRepository from "../repositories/refreshTokenRepository.js";
import * as revokedTokenRepository from "../repositories/revokedTokenRepository.js";
import * as auditRepository from "../repositories/auditRepository.js";
import { query } from "../config/db.js";

const MAX_INTENTOS_FALLIDOS = 5;
const VENTANA_INTENTOS_MINUTOS = 15;

const obtenerIp = (req) => {
  const forwarded = req.headers["x-forwarded-for"];
  if (forwarded) return forwarded.split(",")[0].trim();
  return req.ip || req.connection.remoteAddress || "desconocida";
};

const errorAuth = () => ({ status: 401, error: "Usuario o clave incorrectos" });

export const login = async (req, { usuario_login: loginCrudo, clave }) => {
  loginCrudo = String(loginCrudo ?? "")
    .trim()
    .slice(0, 40);

  if (!loginCrudo || !clave) {
    return { status: 400, error: "Usuario y clave son obligatorios" };
  }
  const ip = obtenerIp(req);
  const fallidosUsuario = await userRepository.contarFallidosRecientes({
    usuario_login: loginCrudo,
    minutos: VENTANA_INTENTOS_MINUTOS,
  });
  const fallidosIp = await userRepository.contarFallidosRecientes({
    ip_address: ip,
    minutos: VENTANA_INTENTOS_MINUTOS,
  });
  if (
    fallidosUsuario >= MAX_INTENTOS_FALLIDOS ||
    fallidosIp >= MAX_INTENTOS_FALLIDOS
  ) {
    await userRepository.registrarIntento({
      usuario_login: loginCrudo,
      exitoso: false,
      ip_address: ip,
    });
    return {
      status: 423,
      error:
        "Acceso bloqueado temporalmente por múltiples intentos fallidos. Intente más tarde.",
    };
  }

  const usuario = await userRepository.findByLogin(loginCrudo);
  if (!usuario) {
    await userRepository.registrarIntento({
      usuario_login: loginCrudo,
      exitoso: false,
      ip_address: ip,
    });
    return errorAuth();
  }

  if (usuario.estado !== "activo") {
    await userRepository.registrarIntento({
      usuario_login: loginCrudo,
      exitoso: false,
      ip_address: ip,
    });
    return {
      status: 403,
      error: "Usuario inactivo. No puede iniciar sesión.",
    };
  }

  const coincide = await bcrypt.compare(String(clave), usuario.clave_hash);
  if (!coincide) {
    await userRepository.registrarIntento({
      usuario_login: loginCrudo,
      exitoso: false,
      ip_address: ip,
    });
    return errorAuth();
  }

  // Éxito: registramos intento exitoso, actualizamos último acceso y activamos sesión.
  await userRepository.registrarIntento({
    usuario_login: loginCrudo,
    exitoso: true,
    ip_address: ip,
  });
  await userRepository.registrarUltimoAcceso(usuario.id_usuario);
  await userRepository.registrarSesionActiva(usuario.id_usuario);
  const token = generarToken(usuario.id_usuario);
  const refreshToken = await refreshTokenRepository.crearRefreshToken(
    usuario.id_usuario,
  );
  await auditRepository.registrarAudit({
    id_usuario: usuario.id_usuario,
    usuario_login: usuario.usuario_login,
    accion: "LOGIN",
    recurso: "auth",
    detalle: "Inicio de sesión exitoso",
    ip_address: ip,
  });
  return {
    status: 200,
    body: {
      token,
      refresh_token: refreshToken,
      usuario: {
        id_usuario: usuario.id_usuario,
        usuario_login: usuario.usuario_login,
        rol: usuario.rol,
        nombres: usuario.nombres,
        apellidos: usuario.apellidos,
        nombreCompleto: `${usuario.nombres} ${usuario.apellidos}`,
        estado: usuario.estado,
      },
    },
  };
};

export const registrar = async (datos) => {
  const {
    rol,
    tipo_documento,
    documento,
    nombres,
    apellidos,
    telefono,
    email,
    usuario_login,
    clave,
  } = datos;

  if (String(documento).length < 5 || String(documento).length > 20) {
    return {
      status: 400,
      error: "El documento debe tener entre 5 y 20 caracteres",
    };
  }
  if (String(clave).length < 4) {
    return { status: 400, error: "La clave debe tener al menos 4 caracteres" };
  }

  const duplicado = await userRepository.findDuplicate({
    tipo_documento,
    documento,
    usuario_login,
    email: email || undefined,
  });
  if (duplicado) {
    let campo = "";
    if (
      duplicado.tipo_documento === tipo_documento &&
      duplicado.documento === documento
    )
      campo = "documento";
    else if (duplicado.usuario_login === usuario_login)
      campo = "usuario de acceso";
    else if (email && duplicado.email === email) campo = "correo";
    return {
      status: 409,
      error: `Ya existe un usuario registrado con ese ${campo}.`,
    };
  }

  const clave_hash = await bcrypt.hash(String(clave), 10);

  const { insertId } = await userRepository.create({
    rol,
    tipo_documento,
    documento,
    nombres,
    apellidos,
    telefono,
    email,
    usuario_login,
    clave_hash,
  });

  const creado = await userRepository.findById(insertId);
  return {
    status: 201,
    body: {
      id_usuario: creado.id_usuario,
      usuario_login: creado.usuario_login,
      rol: creado.rol,
      nombres: creado.nombres,
      apellidos: creado.apellidos,
      email: creado.email,
    },
  };
};

export const restablecerClave = async ({ idUsuario, claveNueva }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (!usuario) {
    return { status: 404, error: "Usuario no encontrado" };
  }

  const clave_hash = await bcrypt.hash(String(claveNueva), 10);
  await userRepository.cambiarClave(idUsuario, clave_hash);
  return {
    status: 200,
    body: {
      mensaje: `Clave restablecida para el usuario ${usuario.usuario_login}`,
    },
  };
};

// Re-autenticación: valida la clave del usuario identificado por usuario_login.
// Se usa para confirmar que el administrador que realiza cambios en otros
// usuarios (p. ej. restablecer clave o editar datos) sea quien está autenticado
// y no una sesión dejada abierta.
export const verificarClaveUsuario = async ({ usuario_login, clave }) => {
  const usuario = await userRepository.findByLogin(usuario_login);
  if (!usuario) return { status: 404, error: "Usuario no encontrado" };
  const coincide = await bcrypt.compare(String(clave), usuario.clave_hash);
  if (!coincide) return { status: 400, error: "La clave es incorrecta" };
  return { status: 200, body: { ok: true } };
};

export const logout = async ({ idUsuario, token }) => {
  const usuario = await userRepository.findById(idUsuario);
  if (token) {
    try {
      const decoded = verificarToken(token);
      if (decoded?.jti && decoded?.exp) {
        await revokedTokenRepository.revocarToken({
          jti: decoded.jti,
          id_usuario: idUsuario,
          expires_at: new Date(decoded.exp * 1000),
        });
      }
    } catch (e) {
      console.log("LOGOUT revoke error", e.message);
    }
  }
  await refreshTokenRepository.revocarRefreshTokensUsuario(idUsuario);
  await query(
    `UPDATE usuarios SET sesion_activa = FALSE, fecha_sesion_activa = NULL WHERE id_usuario = ?`,
    [idUsuario],
  );
  await auditRepository.registrarAudit({
    id_usuario: idUsuario,
    usuario_login: usuario?.usuario_login ?? null,
    accion: "LOGOUT",
    recurso: "auth",
    detalle: "Cierre de sesión",
    ip_address: "desconocida",
  });
  return { status: 200, body: { ok: true } };
};
export const refresh = async ({ refresh_token }) => {
  if (!refresh_token) {
    return { status: 400, error: "Refresh token requerido" };
  }
  const row = await refreshTokenRepository.validarRefreshToken(refresh_token);
  if (!row) {
    return { status: 401, error: "Refresh token inválido o expirado" };
  }
  // Rotar: revocar el anterior y emitir uno nuevo
  await refreshTokenRepository.revocarRefreshToken(refresh_token);
  const newRefresh = await refreshTokenRepository.crearRefreshToken(
    row.id_usuario,
  );
  const usuario = await userRepository.findById(row.id_usuario);
  if (!usuario || usuario.estado !== "activo") {
    return { status: 403, error: "Usuario inactivo" };
  }
  const token = generarToken(usuario.id_usuario);
  return {
    status: 200,
    body: {
      token,
      refresh_token: newRefresh,
      usuario: {
        id_usuario: usuario.id_usuario,
        usuario_login: usuario.usuario_login,
        rol: usuario.rol,
        nombres: usuario.nombres,
        apellidos: usuario.apellidos,
        nombreCompleto: `${usuario.nombres} ${usuario.apellidos}`,
        estado: usuario.estado,
      },
    },
  };
};

// backend/src/validators/placa.js
// Validacion de placas colombianas (espejo de frontend/src/validators/placa.js).
//   - Carro: 3 letras + 3 numeros          -> ABC123  (ABC-123)
//   - Moto:  3 letras + 2 numeros + letra  -> ABC12C  (ABC-12C)
// La placa se normaliza a mayusculas, sin espacios ni guiones.

export const FORMATOS_POR_TIPO = {
  carro: /^([A-Z]{3})-?([0-9]{3})$/,
  moto: /^([A-Z]{3})-?([0-9]{2})([A-Z])$/,
};

export const FORMATOS = [FORMATOS_POR_TIPO.carro, FORMATOS_POR_TIPO.moto];

export const normalizarPlaca = (placa) =>
  String(placa ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");

export const esPlacaValida = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) return false;
  if (tipo && FORMATOS_POR_TIPO[tipo]) return FORMATOS_POR_TIPO[tipo].test(p);
  return FORMATOS.some((re) => re.test(p));
};

/** @returns {{ valida: boolean, placa: string, tipo: string|null, error: string|null }} */
export const validarPlaca = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) {
    return { valida: false, placa: p, tipo, error: "La placa es obligatoria" };
  }

  if (tipo && FORMATOS_POR_TIPO[tipo]) {
    if (!FORMATOS_POR_TIPO[tipo].test(p)) {
      return {
        valida: false,
        placa: p,
        tipo,
        error:
          tipo === "moto"
            ? "Formato de placa inválido para moto. Ejemplo: ABC12C"
            : "Formato de placa inválido para carro. Ejemplo: ABC123",
      };
    }
    return { valida: true, placa: p, tipo, error: null };
  }

  if (!FORMATOS.some((re) => re.test(p))) {
    return {
      valida: false,
      placa: p,
      tipo,
      error:
        "Formato de placa inválido. Ejemplo: ABC123 (carro) o ABC12C (moto)",
    };
  }

  const tipoDetectado = FORMATOS_POR_TIPO.moto.test(p) ? "moto" : "carro";
  return { valida: true, placa: p, tipo: tipoDetectado, error: null };
};

import { Navigate, useLocation } from "react-router-dom";
import { useAuth } from "../features/auth/context/AuthContext";

/** Exige sesión; con `roles` además exige uno de esos roles. */
export default function ProtectedRoute({ roles, children }) {
  const { isLoggedIn, loading, rol } = useAuth();
  const location = useLocation();

  // Asegura que `roles` siempre sea un arreglo para evitar errores de tipo
  // si se pasa un string o un valor indefinido.
  const allowedRoles = Array.isArray(roles) ? roles : [];

  if (loading) return <p style={{ padding: 40 }}>Cargando…</p>;
  if (!isLoggedIn)
    return <Navigate to="/login" replace state={{ from: location }} />;
  if (allowedRoles.length > 0 && !allowedRoles.includes(rol))
    return <Navigate to="/dashboard" replace />;
  return children;
}

// frontend/src/Components/ingreso-salida/FormularioIngreso.jsx
// Tarjeta "Ingresar". Vistas: idle -> resultado -> confirmado.
import { useState, useRef, useEffect } from "react";
import {
  buscarVehiculo,
  obtenerCeldasDisponibles,
  registrarMovimiento,
} from "../../services/api";
import { validarPlaca } from "../../validators/placa";
import AlertaPlaca from "./AlertaPlaca.jsx";
import PanelVehiculo from "./PanelVehiculo.jsx";
import PanelMovimiento from "./PanelMovimiento.jsx";

export default function FormularioIngreso() {
  const [placa, setPlaca] = useState("");
  const [vista, setVista] = useState("idle"); // idle | resultado | confirmado
  const [vehiculo, setVehiculo] = useState(null);
  const [celdas, setCeldas] = useState([]); // [{ id_celda, codigo, ... }]
  const [celdaSeleccionada, setCeldaSeleccionada] = useState(null);
  const [movimiento, setMovimiento] = useState(null);
  const [error, setError] = useState("");
  const [alerta, setAlerta] = useState(null); // { tipo, mensaje }
  const timerRef = useRef(null);

  const resetTimer = () => {
    if (timerRef.current) clearTimeout(timerRef.current);
    if (vista !== "idle" || alerta !== null) {
      timerRef.current = setTimeout(() => {
        handleLimpiar();
      }, 35000);
    }
  };

  useEffect(() => {
    resetTimer();
    return () => {
      if (timerRef.current) clearTimeout(timerRef.current);
    };
  }, [vista, alerta]);

  const handleBuscar = async () => {
    setError("");
    setAlerta(null);
    if (!placa.trim()) {
      setAlerta({ tipo: "campo-vacio", mensaje: "Ingresa una placa." });
      return;
    }
    // Misma regla que el backend. Carro: ABC123 / Moto: ABC12C
    const validacion = validarPlaca(placa);
    if (!validacion.valida) {
      setAlerta({ tipo: "formato-invalido", mensaje: validacion.error });
      return;
    }
    setPlaca(validacion.placa);

    try {
      const encontrado = await buscarVehiculo(validacion.placa);

      if (encontrado.estado === "Adentro") {
        setAlerta({
          tipo: "ya-procesada",
          mensaje: "Esta placa ya está adentro, no se puede ingresar de nuevo.",
        });
        return;
      }

      // Sin mensualidad vigente: se muestra el vehiculo pero se bloquea el ingreso
      if (
        encontrado.estadoMensualidad === "En mora" ||
        encontrado.estadoMensualidad === "Sin mensualidad"
      ) {
        setAlerta({
          tipo: "ingreso-bloqueado",
          mensaje: `La placa ${encontrado.placa} no puede ingresar. Mensualidad: ${encontrado.estadoMensualidad}.`,
        });
        setVehiculo(encontrado);
        setVista("resultado");
        return;
      }

      // Solo celdas libres del mismo tipo del vehiculo
      const disponibles = await obtenerCeldasDisponibles(encontrado.tipoCodigo);
      if (disponibles.length === 0) {
        setError("No hay celdas disponibles para este tipo de vehículo");
        return;
      }
      setVehiculo(encontrado);
      setCeldas(disponibles);
      setCeldaSeleccionada(null);
      setVista("resultado");
    } catch (err) {
      if (err.status === 404) {
        setAlerta({
          tipo: "no-registrada",
          mensaje: `La placa ${validacion.placa} no está registrada en el sistema.`,
        });
      } else {
        setError(err.message);
      }
    }
  };

  const handleIngresar = async () => {
    if (!celdaSeleccionada) {
      setError("Selecciona una celda");
      return;
    }
    setError("");
    try {
      const mov = await registrarMovimiento({
        placa: vehiculo.placa,
        celda: celdaSeleccionada,
        tipo: "entrada",
      });
      setMovimiento(mov);
      setVista("confirmado");
    } catch (err) {
      // 403: el backend bloquea el ingreso si la mensualidad no esta vigente
      if (err.status === 403) {
        setAlerta({
          tipo: "ingreso-bloqueado",
          mensaje: `No se puede registrar el ingreso: ${err.message}.`,
        });
      } else {
        setError(err.message);
      }
    }
  };

  const handleLimpiar = () => {
    setPlaca("");
    setVehiculo(null);
    setCeldas([]);
    setCeldaSeleccionada(null);
    setMovimiento(null);
    setError("");
    setAlerta(null);
    setVista("idle");
  };

  const bloqueado = alerta?.tipo === "ingreso-bloqueado";

  return (
    <div className="Consulta-card">

// Tarjeta "Salir". Vistas: idle -> resultado -> confirmado.
import { useState, useRef, useEffect } from "react";
import { buscarVehiculo, registrarMovimiento } from "../../services/api";
import { validarPlaca } from "../../validators/placa";
import AlertaPlaca from "./AlertaPlaca.jsx";
import PanelVehiculo from "./PanelVehiculo.jsx";
import PanelMovimiento from "./PanelMovimiento.jsx";

export default function FormularioSalida() {
  const [placa, setPlaca] = useState("");
  const [vista, setVista] = useState("idle"); // idle | resultado | confirmado
  const [vehiculo, setVehiculo] = useState(null);
  const [movimiento, setMovimiento] = useState(null);
  const [error, setError] = useState("");
  const [alerta, setAlerta] = useState(null); // { tipo, mensaje }
  const timerRef = useRef(null);

  const resetTimer = () => {
    if (timerRef.current) clearTimeout(timerRef.current);
    if (vista !== "idle" || alerta !== null) {
      timerRef.current = setTimeout(() => {
        handleLimpiar();
      }, 35000);
    }
  };

  useEffect(() => {
    resetTimer();
    return () => {
      if (timerRef.current) clearTimeout(timerRef.current);
    };
  }, [vista, alerta]);

  const handleBuscar = async () => {
    setError("");
    setAlerta(null);
    if (!placa.trim()) {
      setAlerta({ tipo: "campo-vacio", mensaje: "Ingresa una placa." });
      return;
    }
    const validacion = validarPlaca(placa);
    if (!validacion.valida) {
      setAlerta({ tipo: "formato-invalido", mensaje: validacion.error });
      return;
    }
    setPlaca(validacion.placa);

    try {
      const encontrado = await buscarVehiculo(validacion.placa);
      if (encontrado.estado !== "Adentro") {
        setAlerta({
          tipo: "ya-procesada",
          mensaje: "Esta placa ya está afuera, no puede salir nuevamente.",
        });
        return;
      }
      setVehiculo(encontrado);
      setVista("resultado");
    } catch (err) {
      if (err.status === 404) {
        setAlerta({
          tipo: "no-registrada",
          mensaje: `La placa ${validacion.placa} no está registrada en el sistema.`,
        });
      } else {
        setError(err.message);
      }
    }
  };

  const handleSalir = async () => {
    setError("");
    try {
      const mov = await registrarMovimiento({
        placa: vehiculo.placa,
        tipo: "salida",
      });
      setMovimiento(mov);
      setVista("confirmado");
    } catch (err) {
      setError(err.message);
    }
  };

  const handleLimpiar = () => {
    setPlaca("");
    setVehiculo(null);
    setMovimiento(null);
    setError("");
    setAlerta(null);
    setVista("idle");
  };

  return (
    <div className="Consulta-card">
      <h2 className="Consulta-titulo">Salir</h2>

      <div className="Consulta-input-row">
        <input
          type="text"
          className="Consulta-input"
          placeholder="Inserte placa de vehículo"
          value={placa}
          onChange={(e) => setPlaca(e.target.value.toUpperCase())}
          onKeyDown={(e) => e.key === "Enter" && handleBuscar()}
          disabled={vista !== "idle"}
        />
        <button
          className="Consulta-btn-buscar"
          onClick={handleBuscar}
          disabled={vista !== "idle"}
        >
          Buscar
        </button>
      </div>

      {error && <p className="Error">{error}</p>}
      <AlertaPlaca alerta={alerta} />

      {vista === "resultado" && vehiculo && (
        <>
          <PanelVehiculo vehiculo={vehiculo} />
          <div className="Consulta-acciones">
            <button className="Consulta-btn-salir" onClick={handleSalir}>
              Salir
            </button>
            <button className="Consulta-btn-limpiar" onClick={handleLimpiar}>
              Limpiar
            </button>
          </div>
        </>
      )}

      {vista === "confirmado" && movimiento && (
        <>
          <PanelMovimiento movimiento={movimiento} />
          <div className="Consulta-acciones">
            <button className="Consulta-btn-limpiar" onClick={handleLimpiar}>
              Nueva salida
            </button>
          </div>
        </>
      )}
    </div>
  );
}

import {
  createContext,
  useContext,
  useEffect,
  useMemo,
  useState,
  useCallback,
} from "react";
import {
  login as apiLogin,
  logout as apiLogout,
  me,
  getToken,
  setToken,
  getRefreshToken,
  setRefreshToken,
  refreshToken as apiRefresh,
} from "../../../services/api";

const USER_KEY = "ac_user";

const AuthContext = createContext({
  isLoggedIn: false,
  loading: false,
  usuario: null,
  rol: null,
  error: null,
  login: async () => {},
  logout: () => {},
  manejarError: () => null,
  clearError: () => {},
});

export const useAuth = () => useContext(AuthContext);

const guardarUsuario = (u) =>
  u
    ? localStorage.setItem(USER_KEY, JSON.stringify(u))
    : localStorage.removeItem(USER_KEY);

export function AuthProvider({ children }) {
  const [usuario, setUsuario] = useState(() => {
    if (!getToken()) return null;
    try {
      return JSON.parse(localStorage.getItem(USER_KEY));
    } catch {
      return null;
    }
  });
  const [loading, setLoading] = useState(() => Boolean(getToken()));
  const [error, setError] = useState(null);

  // Función para manejar errores HTTP con mensajes apropiados
  const manejarError = useCallback((error) => {
    if (error.status === 401) {
      // Sesión expirada o credenciales incorrectas
      setToken(null);
      localStorage.removeItem("ac_token");
      window.dispatchEvent(new Event("auth:expired"));
      setError(
        "Credenciales incorrectas. Por favor, inicie sesión nuevamente.",
      );
      setLoading(false);
      return "/login"; // Indica que debe navegar al login
    } else if (error.status === 403) {
      setError("No tiene permiso para acceder a este recurso.");
      setLoading(false);
      return null;
    } else if (error.status === 404) {
      setError("El recurso solicitado no existe.");
      setLoading(false);
      return null;
    } else if (error.status === 422) {
      // Validación de datos - el error.message contiene los detalles
      setError(error.message || "Datos de validación incorrectos.");
      setLoading(false);
      return null;
    } else if (error.status === 500) {
      setError("Error interno del servidor. Por favor, intente más tarde.");
      setLoading(false);
      return null;
    } else {
      // Error genérico
      setError(error.message || "Error inesperado");
      setLoading(false);
      return null;
    }
  }, []);

  const clearError = useCallback(() => setError(null), []);

  // Al cargar la app, valida el token y refresca los datos del usuario
  useEffect(() => {
    if (!getToken()) {
      setLoading(false);
      return;
    }
    me()
      .then((u) => {
        setUsuario(u);
        guardarUsuario(u);
      })
      .catch((err) => {
        if (err.status === 401 || err.status === 403) {
          setToken(null);
          guardarUsuario(null);
          setUsuario(null);
        }
      })
      .finally(() => setLoading(false));
  }, []);

  // Token vencido en cualquier petición → volver al login
  useEffect(() => {
    const alExpirar = () => {
      guardarUsuario(null);
      setUsuario(null);
    };
    window.addEventListener("auth:expired", alExpirar);
    return () => window.removeEventListener("auth:expired", alExpirar);
  }, []);

  const login = useCallback(async (usuario_login, clave) => {
    setError(null);
    const data = await apiLogin(usuario_login, clave);
    setToken(data.token);
    setRefreshToken(data.refresh_token);
    guardarUsuario(data.usuario);
    setUsuario(data.usuario);
    return data.usuario;
  }, []);

  const logout = useCallback(async () => {
    // 1. Intenta avisar al backend con los tokens aún vigentes para que
    //    revoque el jti del access y todos los refresh del usuario.
    try {
      await apiLogout();
    } catch {
      // Ignorar errores del servidor en el logout.
    }
    // 2. Limpieza local SIEMPRE, incluso si el servidor falló.
    guardarUsuario(null);
    setUsuario(null);
    setError(null);
    setToken(null);
    setRefreshToken(null);
  }, []);

  const value = useMemo(
    () => ({
      usuario,
      rol: usuario?.rol ?? null,
      isLoggedIn: Boolean(usuario),
      loading,
      error,
      login,
      logout,
      manejarError,
      clearError,
    }),
    [usuario, loading, error, login, logout, manejarError, clearError],
  );

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export default AuthContext;

  const { isLoggedIn, loading, login, manejarError } = useAuth();
  const navigate = useNavigate();
  const [form, setForm] = useState({ usuario_login: "", clave: "" });
  const [error, setError] = useState("");
  const [enviando, setEnviando] = useState(false);

  if (!loading && isLoggedIn) return <Navigate to="/dashboard" replace />;

  const cambiar = (e) => setForm({ ...form, [e.target.name]: e.target.value });

  const enviar = async (e) => {
    e.preventDefault();
    setEnviando(true);
    setError("");

    try {
      const usuario = await login(form.usuario_login.trim(), form.clave);
      if (usuario) {
        navigate("/dashboard", { replace: true });

      // pero el mensaje al usuario se toma del error real del backend.
      manejarError(err);
      setError(err.message || "Error en el login");
    } finally {
      setEnviando(false);

      <form className="Login-card" onSubmit={enviar}>

        <input
          id="clave"
          name="clave"
          type="password"
          value={form.clave}
          onChange={cambiar}

        <button type="submit" disabled={enviando}>

          {campo("apellidos", "Apellidos", { required: true, maxLength: 80 })}
          {campo("telefono", "Teléfono", { maxLength: 20 })}
          {campo("email", "Correo", { type: "email", maxLength: 120 })}

import { useCallback, useEffect, useState } from "react";
import { useNavigate } from "react-router-dom";
import { useAuth } from "../../auth/context/AuthContext";
import {
  listarUsuarios,
  cambiarEstadoUsuario,
  restablecerClaveUsuario,
  verifyPassword,
} from "../../../services/api";
import {
  Dialog,
  DialogTitle,
  DialogContent,
  DialogActions,
} from "@mui/material";
import "../../../pages/Gestion.css";

const LIMITE = 10;

export default function UserListPage() {
  const { usuario } = useAuth();
  const navigate = useNavigate();
  const [filtros, setFiltros] = useState({ search: "", rol: "", estado: "" });
  const [aplicados, setAplicados] = useState(filtros);
  const [page, setPage] = useState(1);
  const [data, setData] = useState({ rows: [], total: 0 });
  const [msg, setMsg] = useState(null);

  // Diálogo de restablecimiento de clave: 1) confirmar admin → 2) nueva clave.
  const [modal, setModal] = useState({
    abierto: false,
    usuario: null,
    paso: 1,
    adminClave: "",
    nueva: "",
    confirmar: "",
    error: "",
    enviando: false,
  });

  // Re-autenticación ANTES de navegar al formulario de edición.
  // Es una medida de seguridad (defensa en profundidad): se verifica la
  // identidad del admin antes de exponer el formulario que modificará
  // datos de otro usuario. El backend vuelve a validar claveAdmin al
  // aplicar el cambio (segunda capa).
  const [editConfirm, setEditConfirm] = useState({
    abierto: false,
    usuario: null,
    adminClave: "",
    error: "",
    enviando: false,
  });

  // Re-autenticación ANTES de crear un nuevo usuario.
  const [nuevoConfirm, setNuevoConfirm] = useState({
    abierto: false,
    adminClave: "",
    error: "",
    enviando: false,
  });

  const cargar = useCallback(async () => {
    try {
      setData(await listarUsuarios({ ...aplicados, page, limit: LIMITE }));
    } catch (e) {
      setMsg({ tipo: "error", texto: e.message });
    }
  }, [aplicados, page]);

  useEffect(() => {
    cargar();
  }, [cargar]);

  useEffect(() => {
    const intervalo = setInterval(cargar, 5000);
    const alVolver = () => {
      if (document.visibilityState === "visible") cargar();
    };
    document.addEventListener("visibilitychange", alVolver);
    return () => {
      clearInterval(intervalo);
      document.removeEventListener("visibilitychange", alVolver);
    };
  }, [cargar]);

  const buscar = (e) => {
    e.preventDefault();
    setPage(1);
    setAplicados(filtros);
  };

  const accion = async (fn, okTexto) => {
    try {
      await fn();
      setMsg({ tipo: "ok", texto: okTexto });
      cargar();
    } catch (e) {
      setMsg({ tipo: "error", texto: e.message });
    }
  };

  const alternarEstado = (u) =>
    accion(
      () =>
        cambiarEstadoUsuario(
          u.id_usuario,
          u.estado === "activo" ? "inactivo" : "activo",
        ),
      `Usuario ${u.estado === "activo" ? "desactivado" : "activado"}`,
    );

  const abrirClave = (u) =>
    setModal({
      abierto: true,
      usuario: u,
      paso: 1,
      adminClave: "",
      nueva: "",
      confirmar: "",
      error: "",
      enviando: false,
    });

  const cerrarClave = () =>
    setModal((m) => ({ ...m, abierto: false, error: "" }));

  // ── Editar: re-autenticación previa (1ª capa) ─────────────────────────
  const abrirEditar = (u) =>
    setEditConfirm({
      abierto: true,
      usuario: u,
      adminClave: "",
      error: "",
      enviando: false,
    });

  const cerrarEditar = () =>
    setEditConfirm((m) => ({ ...m, abierto: false, error: "" }));

  const confirmarEditar = async () => {
    setEditConfirm((m) => ({ ...m, enviando: true, error: "" }));
    try {
      await verifyPassword(editConfirm.adminClave);
      cerrarEditar();
      navigate(`/users/${editConfirm.usuario.id_usuario}/edit`);
    } catch (e) {
      setEditConfirm((m) => ({ ...m, error: e.message }));
    } finally {
      setEditConfirm((m) => ({ ...m, enviando: false }));
    }
  };

  // ── Nuevo usuario: re-autenticación previa ────────────────────────────
  const abrirNuevoUsuario = () =>
    setNuevoConfirm({
      abierto: true,
      adminClave: "",
      error: "",
      enviando: false,
    });

  const cerrarNuevo = () =>
    setNuevoConfirm((m) => ({ ...m, abierto: false, error: "" }));

  const confirmarNuevo = async () => {
    setNuevoConfirm((m) => ({ ...m, enviando: true, error: "" }));
    try {
      await verifyPassword(nuevoConfirm.adminClave);
      cerrarNuevo();
      navigate("/users/new");
    } catch (e) {
      setNuevoConfirm((m) => ({ ...m, error: e.message }));
    } finally {
      setNuevoConfirm((m) => ({ ...m, enviando: false }));
    }
  };

  // ── Restablecer clave: paso 1 (verificar admin) ───────────────────────
  const confirmarAdmin = async () => {
    setModal((m) => ({ ...m, enviando: true, error: "" }));
    try {
      await verifyPassword(modal.adminClave);
      setModal((m) => ({ ...m, paso: 2, error: "" }));
    } catch (e) {
      setModal((m) => ({ ...m, error: e.message }));
    } finally {
      setModal((m) => ({ ...m, enviando: false }));
    }
  };

  // ── Restablecer clave: paso 2 (enviar nueva) ──────────────────────────
  const guardarClave = async () => {
    if (modal.nueva.length < 4) {
      setModal((m) => ({
        ...m,
        error: "La clave debe tener al menos 4 caracteres",
      }));
      return;
    }
    if (modal.nueva !== modal.confirmar) {
      setModal((m) => ({ ...m, error: "Las claves no coinciden" }));
      return;
    }
    setModal((m) => ({ ...m, enviando: true, error: "" }));
    try {
      await restablecerClaveUsuario(
        modal.usuario.id_usuario,
        modal.nueva,
        modal.adminClave,
      );
      setMsg({ tipo: "ok", texto: "Clave restablecida" });
      cerrarClave();
      cargar();
    } catch (e) {
      setModal((m) => ({ ...m, error: e.message }));
    } finally {
      setModal((m) => ({ ...m, enviando: false }));
    }
  };

  const paginas = Math.max(Math.ceil(data.total / LIMITE), 1);

  const estaConectado = (u) => Boolean(u?.sesion_activa);

  return (
    <div className="Page">
      <h2>Usuarios</h2>
      {msg && <p className={`Msg Msg-${msg.tipo}`}>{msg.texto}</p>}

      <form className="Toolbar" onSubmit={buscar}>
        <input
          className="Input"
          placeholder="Nombre, documento o usuario"
          value={filtros.search}
          onChange={(e) => setFiltros({ ...filtros, search: e.target.value })}
        />
        <select
          className="Select"
          value={filtros.rol}
          onChange={(e) => setFiltros({ ...filtros, rol: e.target.value })}
        >
          <option value="">Todos los roles</option>
          <option value="administrador">Administrador</option>
          <option value="operador">Operador</option>
        </select>
        <select
          className="Select"
          value={filtros.estado}
          onChange={(e) => setFiltros({ ...filtros, estado: e.target.value })}
        >
          <option value="">Todos los estados</option>
          <option value="activo">Activo</option>
          <option value="inactivo">Inactivo</option>
        </select>
        <button className="Btn" type="submit">
          Buscar
        </button>
        {/* type="button": evita disparar el submit del form de búsqueda */}
        <button
          type="button"
          className="Btn Btn--primary"
          onClick={abrirNuevoUsuario}
        >
          Nuevo usuario
        </button>
      </form>

      <div className="Card Tabla-wrap">
        <table className="Tabla">
          <thead>
            <tr>
              <th>Usuario</th>
              <th>Nombre</th>
              <th>Rol</th>
              <th>Estado</th>
              <th>Último acceso</th>
              <th>Acciones</th>
            </tr>
          </thead>
          <tbody>
            {data.rows.length === 0 && (
              <tr>
                <td colSpan={6}>Sin resultados</td>
              </tr>
            )}
            {data.rows.map((u) => {
              if (!u) return null;
              const esYo = u.id_usuario === usuario?.id_usuario;
              return (
                <tr key={u.id_usuario}>
                  <td>{u.usuario_login}</td>
                  <td>
                    {u.nombres} {u.apellidos}
                  </td>
                  <td style={{ textTransform: "capitalize" }}>{u.rol}</td>
                  <td>
                    <span
                      className={`Badge ${
                        estaConectado(u) ? "Badge--libre" : "Badge--inactiva"
                      }`}
                      style={{ minWidth: "115px", textAlign: "center" }}
                    >
                      {estaConectado(u) ? "Conectado" : "Desconectado"}
                    </span>
                  </td>
                  <td>
                    {u.ultimo_acceso
                      ? new Date(u.ultimo_acceso).toLocaleString("es-CO")
                      : "—"}
                  </td>
                  <td>
                    <div className="Tabla-acciones">
                      {/* Editar abre diálogo de re-autenticación */}
                      <button
                        type="button"
                        className="Btn Btn--sm"
                        onClick={() => abrirEditar(u)}
                      >
                        Editar
                      </button>
                      <button
                        type="button"
                        className="Btn Btn--sm"
                        onClick={() => abrirClave(u)}
                      >
                        Clave
                      </button>
                      <button
                        type="button"
                        className={`Btn Btn--sm ${
                          u.estado === "activo" ? "Btn--danger" : "Btn--success"
                        }`}
                        style={{ minWidth: "110px" }}
                        disabled={esYo}
                        onClick={() => alternarEstado(u)}
                      >
                        {u.estado === "activo" ? "Desactivar" : "Activar"}
                      </button>
                    </div>
                  </td>
                </tr>
              );
            })}
          </tbody>
        </table>

        <div className="Paginacion">
          <button
            type="button"
            className="Btn Btn--sm"
            disabled={page <= 1}
            onClick={() => setPage(page - 1)}
          >
            Anterior
          </button>
          <span>
            Página {page} de {paginas} ({data.total} usuarios)
          </span>
          <button
            type="button"
            className="Btn Btn--sm"
            disabled={page >= paginas}
            onClick={() => setPage(page + 1)}
          >
            Siguiente
          </button>
        </div>

        {/* ===== Diálogo: restablecer clave (2 pasos) ===== */}
        <Dialog
          open={modal.abierto}
          onClose={cerrarClave}
          maxWidth="xs"
          fullWidth
        >
          <DialogTitle>
            Cambiar clave de {modal.usuario?.usuario_login}
          </DialogTitle>
          <DialogContent>
            {modal.paso === 1 ? (
              <>
                <p>Confirme con su clave de administrador:</p>
                <input
                  className="Input"
                  type="password"
                  placeholder="Clave de administrador"
                  value={modal.adminClave}
                  onChange={(e) =>
                    setModal((m) => ({ ...m, adminClave: e.target.value }))
                  }
                  disabled={modal.enviando}
                  style={{ width: "100%" }}
                />
              </>
            ) : (
              <>
                <p>Nueva clave para {modal.usuario?.usuario_login}:</p>

            </p>

// backend/src/HistorialAccesos.jsx
import { useCallback, useEffect, useState } from "react";
import { listarAccesos } from "../services/api";
import "../pages/Gestion.css";

const LIMITE = 20;

function fmt(fecha) {
  if (!fecha) return "-";
  return new Date(fecha).toLocaleString("es-CO");
}

export default function HistorialAccesos() {
  const [filtros, setFiltros] = useState({
    placa: "",
    celda: "",
    operador: "",
    estado: "",
    fecha_desde: "",
    fecha_hasta: "",
  });
  const [aplicados, setAplicados] = useState(filtros);
  const [page, setPage] = useState(1);
  const [data, setData] = useState({ rows: [], total: 0 });

  const cargar = useCallback(async () => {
    try {
      setData(await listarAccesos({ ...aplicados, page, limit: LIMITE }));
    } catch (e) {
      console.error(e);
    }
  }, [aplicados, page]);

  useEffect(() => {
    cargar();
    const intervalo = setInterval(cargar, 5000);
    const alVolver = () => {
      if (document.visibilityState === "visible") cargar();
    };
    document.addEventListener("visibilitychange", alVolver);
    return () => {
      clearInterval(intervalo);
      document.removeEventListener("visibilitychange", alVolver);
    };
  }, [cargar]);

  useEffect(() => {
    const t = setTimeout(() => {
      setPage(1);
      setAplicados(filtros);
    }, 300);
    return () => clearTimeout(t);
  }, [filtros]);

  const buscar = (e) => {
    if (e) e.preventDefault();
    setPage(1);
    setAplicados(filtros);
  };

  const limpiar = () => {
    setFiltros({
      placa: "",
      celda: "",
      operador: "",
      estado: "",
      fecha_desde: "",
      fecha_hasta: "",
    });
  };

  const paginas = Math.max(Math.ceil(data.total / LIMITE), 1);

  return (
    <div className="Page">
      <h2>Historial de accesos</h2>

      <form className="Toolbar" onSubmit={buscar}>
        <input
          className="Input"
          placeholder="Placa"
          value={filtros.placa}
          style={{ textTransform: "uppercase" }}
          onChange={(e) =>
            setFiltros({ ...filtros, placa: e.target.value.toUpperCase() })
          }
        />
        <input
          className="Input"
          placeholder="Celda"
          value={filtros.celda}
          style={{ textTransform: "uppercase" }}
          onChange={(e) =>
            setFiltros({ ...filtros, celda: e.target.value.toUpperCase() })
          }
        />
        <input
          className="Input"
          placeholder="Operador"
          value={filtros.operador}
          onChange={(e) => setFiltros({ ...filtros, operador: e.target.value })}
        />
        <select
          className="Select"
          value={filtros.estado}
          onChange={(e) => setFiltros({ ...filtros, estado: e.target.value })}
        >
          <option value="">Todos</option>
          <option value="adentro">Adentro</option>
          <option value="fuera">Fuera</option>
        </select>
        <div style={{ display: "flex", gap: "8px", alignItems: "center" }}>
          <input
            className="Input"
            type="date"
            value={filtros.fecha_desde}
            onChange={(e) =>
              setFiltros({ ...filtros, fecha_desde: e.target.value })
            }
          />
          <input
            className="Input"
            type="date"
            value={filtros.fecha_hasta}
            onChange={(e) =>
              setFiltros({ ...filtros, fecha_hasta: e.target.value })
            }
          />
        </div>
        <button className="Btn Btn--primary" type="submit">
          Buscar
        </button>
        <button type="button" className="Btn" onClick={limpiar}>
          Limpiar
        </button>
      </form>

      <div className="Card Tabla-wrap">
        <table className="Tabla">
          <thead>
            <tr>
              <th>Placa</th>
              <th>Propietario</th>
              <th>Celda</th>
              <th>Operador ingreso</th>
              <th>Fecha/hora ingreso</th>
              <th>Operador salida</th>
              <th>Fecha/hora salida</th>
            </tr>
          </thead>
          <tbody>
            {data.rows.length === 0 && (
              <tr>
                <td colSpan={7}>Sin registros</td>
              </tr>
            )}
            {data.rows.map((a) => (
              <tr key={a.id_acceso}>
                <td>{a.placa}</td>
                <td>{a.propietario_nombre}</td>
                <td>{a.celda}</td>
                <td>
                  {a.operador_ingreso_nombres} {a.operador_ingreso_apellidos}
                </td>
                <td>{fmt(a.fecha_ingreso)}</td>
                <td>
                  {a.operador_salida_nombres
                    ? `${a.operador_salida_nombres} ${a.operador_salida_apellidos}`
                    : "-"}
                </td>
                <td>{fmt(a.fecha_salida)}</td>
              </tr>
            ))}
          </tbody>
        </table>
        <div className="Paginacion">
          <button
            className="Btn Btn--sm"
            disabled={page <= 1}
            onClick={() => setPage(page - 1)}
          >
            Anterior
          </button>
          <span>
            Pagina {page} de {paginas} ({data.total} registros)
          </span>
          <button
            className="Btn Btn--sm"
            disabled={page >= paginas}
            onClick={() => setPage(page + 1)}
          >
            Siguiente
          </button>
        </div>
      </div>
    </div>
  );
}

// Cliente HTTP del backend con JWT y refresh automático.
import { normalizarPlaca } from "../validators/placa";

const API = import.meta.env.VITE_API_URL ?? "http://localhost:3000/api";
const TOKEN_KEY = "ac_token";
const REFRESH_KEY = "ac_refresh";

export const getToken = () => localStorage.getItem(TOKEN_KEY);
export const setToken = (t) =>
  t ? localStorage.setItem(TOKEN_KEY, t) : localStorage.removeItem(TOKEN_KEY);
export const getRefreshToken = () => localStorage.getItem(REFRESH_KEY);
export const setRefreshToken = (t) =>
  t
    ? localStorage.setItem(REFRESH_KEY, t)
    : localStorage.removeItem(REFRESH_KEY);

const json = (method, body) => ({
  method,
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(body),
});

const qs = (obj = {}) => {
  const p = new URLSearchParams();
  Object.entries(obj).forEach(([k, v]) => {
    if (v !== undefined && v !== null && v !== "") p.set(k, v);
  });
  const s = p.toString();
  return s ? `?${s}` : "";
};

/**
 * Intenta renovar el access token usando el refresh token guardado.
 * - Serializa las llamadas concurrentes: si 5 peticiones reciben 401 a la
 *   vez, solo se hace un POST /auth/refresh y las 5 esperan el mismo
 *   resultado. Evita rotaciones cruzadas que invaliden el refresh token.
 * - Si el refresh falla, limpia ambos tokens y avisa a AuthContext.
 */
let refreshEnCurso = null;

const refrescarAccessToken = () => {
  if (refreshEnCurso) return refreshEnCurso;

  refreshEnCurso = (async () => {
    const refresh_token = getRefreshToken();
    if (!refresh_token) {
      throw Object.assign(new Error("No hay refresh token"), { status: 401 });
    }
    const res = await fetch(`${API}/auth/refresh`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ refresh_token }),
    }).catch(() => {
      throw Object.assign(new Error("No se pudo conectar con el servidor"), {
        status: 0,
      });
    });
    if (!res.ok) {
      throw Object.assign(new Error("Refresh token inválido o expirado"), {
        status: res.status,
      });
    }
    const data = await res.json();
    setToken(data.token);
    setRefreshToken(data.refresh_token);
    return data.token;
  })();

  return refreshEnCurso.finally(() => {
    refreshEnCurso = null;
  });
};

async function pedir(url, opciones = {}, auth = true) {
  const headers = { ...(opciones.headers || {}) };
  if (auth) {
    const token = getToken();
    if (token) headers.Authorization = `Bearer ${token}`;
  }

  let res;
  try {
    res = await fetch(url, { ...opciones, headers });
  } catch {
    throw new Error("No se pudo conectar con el servidor");
  }

  // 401 en ruta autenticada + hay refresh guardado → intentar renovar y
  // reintentar UNA sola vez. `auth=true` evita reintentar el propio
  // /auth/refresh o /auth/login (que se llaman con auth=false).
  if (res.status === 401 && auth && getRefreshToken()) {
    try {
      const nuevoToken = await refrescarAccessToken();
      headers.Authorization = `Bearer ${nuevoToken}`;
      res = await fetch(url, { ...opciones, headers });
    } catch {
      setToken(null);
      setRefreshToken(null);
      window.dispatchEvent(new Event("auth:expired"));
      const data = await res.json().catch(() => ({}));
      const err = new Error(
        data.error || "Sesión expirada. Inicie sesión de nuevo.",
      );
      err.status = 401;
      throw err;
    }
  }

  const data = await res.json().catch(() => ({}));
  if (!res.ok) {
    const errorMessages = {
      401: "Credenciales incorrectas. Por favor, inicie sesión nuevamente.",
      403: "No tiene permiso para acceder a este recurso.",
      404: "El recurso solicitado no existe.",
      422: "Datos de validación incorrectos. Verifique la información ingresada.",
      500: "Error interno del servidor. Por favor, intente más tarde.",
    };
    if (res.status === 401 && auth) {
      setToken(null);
      setRefreshToken(null);
      window.dispatchEvent(new Event("auth:expired"));
    }
    const errorMessage =
      data.error || errorMessages[res.status] || "Error en la solicitud";
    const error = new Error(errorMessage);
    error.status = res.status;
    throw error;
  }
  return data;
}

// frontend/src/validators/placa.js
// Espejo de backend/src/validators/placa.js: da respuesta inmediata al usuario
// sin gastar una peticion.
//   - Carro: 3 letras + 3 numeros          -> ABC123  (ABC-123)
//   - Moto:  3 letras + 2 numeros + letra  -> ABC12C  (ABC-12C)

export const FORMATOS_POR_TIPO = {
  carro: /^([A-Z]{3})-?([0-9]{3})$/,
  moto: /^([A-Z]{3})-?([0-9]{2})([A-Z])$/,
};

export const FORMATOS = [FORMATOS_POR_TIPO.carro, FORMATOS_POR_TIPO.moto];

/** Normaliza una placa: mayusculas, sin espacios y sin guiones. */
export const normalizarPlaca = (placa) =>
  String(placa ?? "")
    .trim()
    .toUpperCase()
    .replace(/[\s-]/g, "");

/** @returns {{ valida: boolean, placa: string, tipo: string|null, error: string|null }} */
export const validarPlaca = (placa, tipo = null) => {
  const p = normalizarPlaca(placa);
  if (!p) {
    return { valida: false, placa: p, tipo, error: "La placa es obligatoria" };
  }

  if (tipo && FORMATOS_POR_TIPO[tipo]) {
    if (!FORMATOS_POR_TIPO[tipo].test(p)) {
      return {
        valida: false,
        placa: p,
        tipo,
        error:
          tipo === "moto"
            ? "Formato de placa inválido para moto. Ejemplo: ABC12C"
            : "Formato de placa inválido para carro. Ejemplo: ABC123",
      };
    }
    return { valida: true, placa: p, tipo, error: null };
  }

  if (!FORMATOS.some((re) => re.test(p))) {
    return {
      valida: false,
      placa: p,
      tipo,
      error: "Formato inválido. Ejemplo: ABC123 (carro) o ABC12C (moto)",
    };
  }

  const tipoDetectado = FORMATOS_POR_TIPO.moto.test(p) ? "moto" : "carro";
  return { valida: true, placa: p, tipo: tipoDetectado, error: null };
};
